04b · 蜂蜜黄油味「声纹测试」20 秒加长版 ​

阶段 4 · 互动感官片 20 秒变体 ｜ 2026-08-23 ｜ 9:16 竖屏 ｜ 12 秒主版的加长版本

结论先行 ​

12 秒主版的强度来自「密度」：0.9 秒出第一声、4.2 秒内跑完 A / B / C、8 秒出头揭晓反转。直接按比例拉长每一镜，只会稀释这份密度，反而更弱。

所以 20 秒版不碰前半段（00:00–08.7 秒基本沿用 12 秒版），把多出来的约 8 秒全部放到反转之后，做成两件事：

  1. 证明反转：慢放三条波形 + 同一个断面，把「答案：都是」从一句玩笑变成产品证据。
  2. 邀请参与：加宽作答停留、新增评论区钩子、给落版更多呼吸，把「看完」升级成「评论 + 下一条」。
text
前半（0–8.7s）基本不变：出题 → A → B → C → 作答 → remix → 答案
后半（8.7–20s）新增：慢放证据 → 一种脆 → 续拍钩子 → 落版

零新增关键帧：全部复用既有的 10 张关键帧和 4 段动态素材，只改剪辑、后期波形、文案和声音节拍。

与 12 秒版的关系 ​

维度12 秒主版本 20 秒加长版
创意命题「哪一声是蜂蜜黄油味？答案：都是」不变
前半（0–8.7s）出题 → A/B/C → 作答 → remix → 答案基本不变，仅作答窗口加宽
后半（8.7s–尾）证据 + 落版快速收尾（约 3.9s）证明 + 参与钩子 + 落版（约 11.3s）

前 6.0 秒不加模型音乐

视频模型如自动生成声音，一律只作动作同步参考，不进入正式混音。A / B / C 的最终声音在 05 · 声音与剪辑 独立完成。20 秒版新增的 08–10 段仍沿用这一规则，续拍钩子故意只留 room tone，不放音乐。

逐镜执行 ​

镜头 01、02、03、04、07 与 12 秒版完全一致，执行见 04 · 分镜。这里只写有改动和新增的镜头。

05 · 作答（加宽） ​

项目执行
输入KF05 + A / B / C 最终声音
方式后期动效，不做视频生成
运动三条波形以相同缩放从左向右播放一次，中央产品不动
改动作答窗口由 1.2s 加宽到 1.8s；5.2 秒叠加一句「答案发在评论区」小字，不额外做动画
重点给观众真实的比较与输入时间，不催答案
废片装饰性假波形、某选项被提前高亮、文字遮挡产品

08 · 证据·慢放对比 ​

项目执行
输入KF08 + DV02 / DV03 / DV04 各 2–4 帧静帧回环
方式后期合成，不做视频生成
运动KF08 断面轻微回正；三条真实波形（A / B / C）在下方一排并列，各自挂一帧对应动作的慢放叠影
重点三条声音的差异来自「动作与数量」，不是口味；同一个 M0 断面证明是同一款产品
废片波形是装饰假波形、慢放帧与动作不对应、字幕抢在 09 之前出现

09 · 收束·同一种脆 ​

项目执行
输入KF05 静帧 + 最干净的一条主咔嚓
方式静帧后期，不生成
运动画面锁定；只在文案出现时切进一声单独的、最干净的主咔嚓
重点把反转落回正向产品主张（酥脆），而不是让人以为被戏弄
废片重复使用 A / B / C 原声、文案超过一行、出现蜂蜜滴淋或黄油块暗示

10 · 续拍钩子 ​

项目执行
输入KF05 静帧
方式静帧后期，轻提示音 + room tone
运动画面锁定，无音乐
重点用真实问题邀请评论，不预设答案、不伪造评论
废片出现假评论截图、出现「最脆/全网最响」等绝对化用词、钩子时间过长让观众以为片已结束

11 · 落版（加宽） ​

项目执行
输入KF09 + 客户确认包装工程文件
方式静帧后期合成；数字推近不超过 2%
改动落版由 1.7s 加宽到 3.6s，品牌、口味与核心文案分层出现，各自至少保留 1.2s
重点包装正面准确、三根 P0 产品构图稳定、最后一声接回片头形成循环
废片模型重绘包装、logo 或中文漂移、碎屑遮字、最后仍有动态变形

复用与新增资产 ​

资产来源本 20 秒版用途
KF01–KF0902 · 关键帧全部复用
DV02 / DV03 / DV04 / DV0803 · Demo 预览02/03/04/06 直接复用；DV08 兼作 08 慢放底
P0 身份母版 / M0 断面通过审核后补路径身份与断面约束不变
包装工程文件客户确认终稿仅 11 落版后期合成

本页零新增关键帧、零新增视频生成。 20 秒版的全部增量都在剪辑节奏、后期波形、文案分层和声音节拍上。

自省：答案时点后移的风险 ​

20 秒版把答案从 8.1 秒推到 8.7–9.6 秒揭晓，仍落在短视频前 10 秒反转的窗口内，但比 12 秒版更晚。06 · 发布与验收 的 A/B 测试 C / D 版本（5.5s 早揭晓 vs 8.2s 晚揭晓）已经提示：答案时点直接影响重播与完播。

因此 20 秒版需单独跑一次答案早 / 晚对照。若晚揭晓拖累完播，优先压缩 05 作答或 08 慢放，把答案前移，而不是砍掉 09 收束和 10 续拍钩子这两处真正的新增价值。

可压缩缓冲区：10 续拍钩子（3.7s）与 11 落版（3.6s）是全片最可压缩的两段。若投放数据要求收短，可剪成约 15 秒中间版——保留到 09 收束后直接落版，砍掉续拍钩子。

本步审核 ​

  • [ ] 前半 0–8.7s 与 12 秒版节奏一致，0.9 秒出第一声、4.2 秒内完成 A / B / C 不被破坏
  • [ ] 后半新增的 08–10 只复用既有关键帧，没有为加长而新增生成或改变产品身份
  • [ ] A / B / C 使用同一 P0 产品身份，动作与最终声音严格同步
  • [ ] 三条波形由最终采用的声音生成，不是装饰性假波形
  • [ ] 续拍钩子只做真实提问，不伪造评论、不预设结果
  • [ ] 落版品牌、口味与核心文案清晰保留 1.2 秒以上，最后一声可自然循环回片头
  • [ ] 全片无蜂蜜滴淋、黄油包裹、油光，无绝对化与营养功效表述
  • [ ] 包装只使用客户确认的蜂蜜黄油味终稿物料
