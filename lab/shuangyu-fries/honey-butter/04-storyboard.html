04 · 分镜 ​

正式 AI 视频执行稿 ｜ 12 秒 / 9:16 ｜ 关键帧与 Demo 方向通过后使用

执行前提 ​

正式分镜不再重新讨论创意方向。进入本页前必须满足：

  1. 01 · 创意 已通过；
  2. 02 · 关键帧 的 P0 和本镜首尾帧已通过；
  3. 03 · Demo 预览 已确认节奏，并记录需要修正的动作；
  4. Demo 中的假包装、临时文字、平台水印和随机音频均未被当作正式资产。

12 秒时间线 ​

时间镜头画面与动作生成 / 后期屏幕文字
00:00.0–00:00.901 · 出题杯装产品局部占下半部，三根薯条脆竖向露出KF01 数字推近；包装与问题后期合成戴耳机。哪一声是蜂蜜黄油味？
00:00.9–00:01.902 · A 声纹单根产品从中央折断KF02A / B 图生视频A
00:01.9–00:03.003 · B 声纹两根产品先后折断KF03A / B 图生视频B
00:03.0–00:04.204 · C 声纹人物下半脸局部咬下一小段KF04A / B 图生视频C
00:04.2–00:05.405 · 作答中央产品静止，三条波形纵向并列KF05 + 后期真实波形你选哪一声？
00:05.4–00:08.106 · remixA、B、C、断面四个动作按四拍重组复用镜头 02–04、08，不新生成复合动作无
00:08.1–00:09.007 · 答案三条波形合一，画面停住复用 KF05，后期动效答案：都是。
00:09.0–00:10.308 · 证据断面轻转，焦点从外表面移到断口KF08 图生视频味道听不见，脆可以。
00:10.3–00:12.009 · 落版终稿包装、三根产品和少量碎屑稳定落版KF09 + 包装后期合成双宇食品 · 薯条脆 / 蜂蜜黄油味

前 4.2 秒不加模型音乐

视频模型如自动生成声音，一律只作动作同步参考，不进入正式混音。A / B / C 的最终声音在 05 · 声音与剪辑 独立完成。

统一生成标准 ​

  • 每个动态镜头只使用本镜通过审核的首尾帧，不把 P0 直接当成所有镜头首帧。
  • 统一 9:16，同一分辨率、奶油白 / 自然浅金 / 少量黑色的色彩体系。
  • P0 只锁定外观身份；M0 只锁定断面。不得继承参考图的背景、机位和手部。
  • 一镜一个主动作；主体运动时相机锁定，焦点转移时主体不再增加动作。
  • 包装、中文、logo、A / B / C、波形和字幕全部后期添加。
  • 所有 Prompt 末尾排除文字、水印、UI、产品变形、油膜、蜂蜜液体和黄油块。

镜头 01 · 出题 ​

项目执行
输入KF01 + 客户确认的包装工程文件
方式静帧后期，不做视频生成
运动全画面数字推近 2%，包装和产品之间无相对漂移
重点第一帧同时看见口味身份和完整问题
废片模型包装、伪文字、杯体变形、开场动画过多导致 0.9 秒读不完

包装只在后期合成到 KF01 的预留位置。问题第一帧完整出现，不做逐字动画。

镜头 02 · A 声纹 / 单根折断 ​

项目执行
输入KF02A + KF02B + P0 + M0
方式首尾帧图生视频
动作窗口1.0 秒；0.15 秒静止后只断一次
相机锁定微距，不推拉、不环绕、不变焦
重点单根、中央断裂、短而清楚；长度与粗细守恒
废片弯曲、反复折断、断口愈合、碎屑爆炸、额外产品或手指

正式生成沿用 Demo DV02 的结构化 Prompt，并只加入 Demo 审核记录中的单项修正。一次只改动作、物理或镜头中的一层。

镜头 03 · B 声纹 / 双根折断 ​

项目执行
输入KF03A + KF03B + P0 + M0
方式首尾帧图生视频
动作窗口1.1 秒；上方先断，下方延迟 20–60ms
相机与镜头 02 相同的固定机位和白平衡
重点两根始终分离，形成比 A 更厚的视觉层次
废片两根融合、完全镜像同步、第三根出现、断口和碎屑完全复制

正式生成沿用 Demo DV03，保留自然微时差，不用复制镜头 02 再叠一层。

镜头 04 · C 声纹 / 咬下 ​

项目执行
输入KF04A + KF04B + P0 + M0
方式首尾帧图生视频
动作窗口1.2 秒；唇前停 0.2 秒后完成一次咬下
相机固定侧面近景，只保留下半脸
重点同一人物、同一产品、自然闭合，不展示口腔细节
废片完整人脸、嘴部变形、额外牙齿、产品穿模、夸张咀嚼

正式生成沿用 Demo DV04。若连续三轮人体稳定性仍不通过，按关键帧页的失败回退改为产品碰撞声纹，不继续消耗次数硬修嘴部。

镜头 05 · 作答界面 ​

项目执行
输入KF05 + A / B / C 最终声音
方式后期动效，不做视频生成
运动三条波形以相同缩放从左向右播放一次，中央产品不动
重点选项权重一致，停顿至少 1 秒
废片装饰性假波形、某个选项被提前高亮、波形比例不一致

镜头 06 · 声纹 remix ​

不让视频模型一次生成四个动作。后期按以下节拍重组正式镜头：

text
第 1 拍：镜头 02，取断裂前后各 4–6 帧
第 2 拍：镜头 03，取两根刚刚错开的一刻
第 3 拍：镜头 04，取咬下动作完成的一刻
第 4 拍：镜头 08，焦点抵达断面的时刻

四拍之间只用硬切或动作匹配，不加发光圆环、闪白、速度模糊和魔法粒子转场。

镜头 07 · 答案 ​

复用 KF05。三条真实波形在 4–6 帧内收束成一条，静音 0.1 秒后出现「答案：都是。」；不做综艺爆炸字效，不解释规则。

镜头 08 · 断面证据 ​

项目执行
输入KF08 + P0 + M0
方式单帧图生视频
动作窗口1.3 秒；产品轻转小于 12°，焦点只移动一次
相机100mm 微距机位锁定
重点先见干爽表面，再清楚看见有依据的真实断面
废片相机环绕、主体大角度旋转、孔洞放大、面包纤维、油光或液体

正式生成沿用 Demo DV08，最终至少有 0.5 秒断面清晰停留。

镜头 09 · 产品落版 ​

项目执行
输入KF09 + 客户确认包装工程文件
方式静帧后期合成；可做不超过 2% 的数字推近
重点包装正面准确、三根 P0 产品构图稳定、文字清楚保留 1.2 秒以上
废片模型重绘包装、logo 或中文漂移、碎屑遮字、最后仍有动态变形

最后一声咔嚓发生在 11.6 秒，视觉层保持稳定，用声音尾部接回第一帧。

正式生成顺序 ​

顺序任务通过后进入
1镜头 02 单根折断镜头 03 双根折断
2镜头 03 双根折断镜头 04 咬下
3镜头 04 咬下镜头 08 断面
4镜头 08 断面01 / 05 / 07 / 09 后期版式
5九镜无声粗剪声音与剪辑

本步审核 ​

  • [ ] 每个动态镜头都使用本镜关键帧，不从文本直接盲生成
  • [ ] Demo 反馈已经逐项写入对应镜头，未整体重写已通过部分
  • [ ] 02、03、04、08 各自只有一个主动作
  • [ ] P0 产品形态和 M0 断面在所有镜头中保持一致
  • [ ] 包装、中文、logo、波形和字幕全部由后期完成
  • [ ] 九镜无声粗剪精确为 12.0 秒，节奏通过后才进入声音制作
