# 知识库导读

这是一份关于「用 AI 做创意广告」的实操笔记。它的目标不是解释 AI 的原理，而是回答一个具体问题：

> 客户给了一句 brief，怎么在三天内交出一支能看的广告片 / 一组能上架的主图？

## 内容是怎么组织的

四个板块，对应做一支广告的四种需求：

| 板块 | 回答什么问题 | 什么时候看 |
|---|---|---|
| [创意方法论](/method/) | 这活儿整体该怎么推？ | 接到 brief，还没动手时 |
| [Prompt 模板库](/prompts/) | 这一句具体怎么写？ | 已经知道要什么，卡在措辞上 |
| [工具地图](/tools/) | 用哪个工具？ | 选型阶段，或现有工具做不出效果时 |
| [案例拆解](/cases/) | 别人是怎么做的？ | 没思路，想找参照 |

方法论是**骨**，Prompt 是**肉**，工具是**手**，案例是**镜子**。

## 内容的可信度分级

不是所有内容的确定性都一样。文中会用三种标记区分：

::: tip 稳定
经过验证、短期内不会变的判断。比如「镜头语言的词表」「创意流程的阶段划分」。
:::

::: warning 易变
和具体工具、具体版本绑定的信息。比如「某模型的最大时长」。这类内容标注了「以官网为准」，看到时请自行核实。
:::

::: info 待补充
留白，等实战经验填进来。点进去有写作模板，照着填即可。
:::
