# VF 薯条脆 · 片型可行性分析

::: warning 这是教学演示内容
配合 [案例 04 · VF 工艺薯条脆](/cases/case-04-vf-fries-crisp) 阅读。回答的是那个案例**动手之前**的问题：这个产品到底该拍什么类型的片子。

产品设定与合规判断沿用案例 04，**不是真实客户项目的复盘**。
:::

> **一句话**：片型不是选出来的，是被产品条件**排除**到只剩一两个的。

---

## 为什么要单独做这一步

案例 04 直接从「客户要讲工艺」跳到了分镜。实际项目里中间还有一步：**确认「讲工艺」应该长成什么形态的片子**。

这一步做错，后面全白做。它比 [Big Idea](/method/big-idea) 更靠前——Big Idea 决定「说什么」，片型决定「用什么容器装」。容器错了，再好的内容也漏出来。

通用的片型清单、创意手法层和选型排除法，见 [片型图谱：这支片子该长什么样](/method/ad-formats)。**本篇是那套方法在一个具体产品上的完整落地**，两篇对照着读价值最大。

::: tip 判断顺序
产品条件 → 排除不可行的片型 → 剩下的里选投放场景匹配的 → 才轮到想创意。

**不是**先想一个好创意，再找地方放。
:::

---

## ① 产品条件盘点

动手评估片型之前，先把这个产品的硬条件列清楚。**每一条都会否掉某些片型。**

| 维度 | VF 薯条脆的情况 | 对片型的影响 |
|---|---|---|
| **差异化落在哪一层** | 工艺层（VF 真空低温油炸） | 口味层、品牌层都没东西可说，片子必须能承载"过程" |
| **感官抓手** | 只有「脆」 | 见下方专门说明，这是最容易被忽略的一条 |
| **决策链路** | 电商详情页 = 说服型决策 | 需要"给理由"，不是纯情绪煽动 |
| **产品体量** | 单品、低客单价休闲零食 | 撑不起品牌故事片的体量 |
| **合规敏感度** | 高——食品广告 + 工艺宣称双重约束 | 直接否掉两类片型，见 ③ |
| **AI 适配度** | 长板明显、短板也明显 | 长板：工艺内部、微观结构；短板：包装文字、真人表演 |

### 那条最容易被忽略的：这个产品没有「热」

[案例 03](/cases/case-03-fries-social) 总结的食欲感四要素是**热气、质感对比、油脂光泽、动作**。四条里热气最强——热=刚做好=新鲜。

但薯条脆是**预包装常温零食**。

| 食欲要素 | 快餐现炸薯条 | VF 薯条脆 |
|---|---|---|
| 热气 | ✅ 核心抓手 | ❌ **不存在** |
| 质感对比（断面） | ✅ 外脆内软 | ✅ 蜂窝气孔，且更独特 |
| 油脂光泽 | ✅ | ⚠️ 弱，且不宜强调（往油上引不利） |
| 动作（蘸取、拿起） | ✅ 蘸番茄酱 | ⚠️ 弱，袋装零食没有标志性动作 |

::: danger 这个差异决定了不能照抄案例 03
四要素里**两条失效、一条不宜用**，只剩「质感对比」一条完好。

如果直接套用案例 03 的拍法，你会拍出一支"少了一半信息量"的食欲片——观众说不上哪里不对，就是不馋。

**同品类不等于同拍法。**薯条和薯条脆看着像，感官条件完全是两回事。
:::

补偿方案：**把声音提到视觉同等的位置**。没有热气可看，但「脆」是可听的。片与片碰撞的清脆声、掰断的干脆响、咀嚼的碎裂声——这些在案例 03 里是加分项，在这里是**必需项**。

## ② 片型逐一评估

| 片型 | 适配度 | 一句话结论 |
|---|---|---|
| **工艺解构片** | ★★★★★ | 唯一能承载差异化的形态，且 AI 优势最大 |
| **感官 ASMR 片** | ★★★☆☆ | 可做，但要改造——靠声音补上失效的热气 |
| **对比片** | ✕ | 法律风险，不是创意选择 |
| **代言人口播 / 达人测评** | ✕ | 合规 + AI 短板双重踩雷 |
| **品牌情感故事片** | ✕ | 体量不匹配，观众也没耐心 |

下面逐条展开。

---

### ★★★★★ 工艺解构片

**这是案例 04 实际采用的路线。**理由是三层叠加，不是单一原因：

| 理由 | 说明 |
|---|---|
| **它的差异化只有工艺** | 薯条脆品类高度同质化，VF 是唯一能拿出来说的东西。不讲工艺，这支片子就没有内容 |
| **核心画面实拍不到** | 真空罐内部、水分汽化、蜂窝断面——实拍要么不可能要么极贵，**AI 在这类画面上相对优势最大** |
| **匹配投放场景** | 电商详情页要的是"说服"。原料→工艺→结果→产品 的骨架比讲故事更有效 |

**唯一的强约束**：只展示做法，不展示好处。

「更健康」「低脂」「非油炸」「0 负担」全是红线。展示过程，让消费者自己下结论——**你替他下的结论他不信，他自己下的结论他才信**。完整的合规边界见 [案例 04 的限制条件](/cases/case-04-vf-fries-crisp)。

::: tip 为什么这个片型在 AI 时代性价比特别高
放在五年前，工艺解构片是**最贵**的片型之一——要么进车间实拍（设备封闭，根本拍不到），要么做三维动画（周期以月计）。

现在它变成了**最便宜**的片型之一。这个成本结构的翻转，是"技术卖点类产品该不该拍工艺片"这个问题在今天有了新答案的原因。
:::

---

### ★★★☆☆ 感官 ASMR 片

可以做，但**必须改造**，不能照搬 [案例 03](/cases/case-03-fries-social)。

| 改造点 | 怎么改 |
|---|---|
| 热气失效 | 删掉所有蒸汽镜头。硬加热气反而穿帮——袋装零食冒热气不合理 |
| 声音升级为主角 | 音效不是配的，是**拍的**。碰撞声、断裂声、咀嚼碎裂声，每一条单独设计 |
| 断面成为唯一视觉核心 | 蜂窝气孔透光比普通薯条的粉质断面**更独特**，这是它的优势，要吃透 |
| 补一个动作 | 袋装零食缺标志性动作，可用"倒出""抓取""片片叠落"顶上 |

::: warning 一个反直觉的结论
感官片对这个产品来说，**不能单独存在**。

原因：纯感官片讲不了工艺，而工艺是它唯一的差异化。观众看完只知道"这玩意儿看着挺脆"——但市面上所有薯片都脆，你没有给出选你的理由。

所以它只能是**组合拳里的一半**，见 ④。
:::

---

### ✕ 对比片

客户最常提的诉求，**也是必须挡回去的那个**。

左边传统油炸、右边 VF——这个结构效果确实好，但直接对比同类产品容易构成**贬低同类**，在广告法下有明确风险。

::: danger 这是法律问题，不是创意问题
和客户沟通时要说清楚这个定性。说成"我觉得效果不好"会被推翻，说成"这条有法律风险，我们不能做"才站得住。

**替代方案**：只展示自己的工艺，不出现任何参照物。观众的对比是在他自己脑子里完成的——**而且他自己脑补的对比，比你摆在屏幕上的更有说服力**。
:::

---

### ✕ 代言人口播 / 达人测评

两个问题叠加，任何一个单独都足以否掉：

| 问题 | 说明 |
|---|---|
| **合规** | 口播讲工艺，一张嘴就容易滑向"更健康""比油炸的好"。真人说出来比字幕更像"承诺"，风险更高 |
| **AI 短板** | 真人表演、口型同步、微表情——这是生成模型目前最弱的一环，见 [人物代言](/prompts/spokesperson) |

::: tip 如果客户坚持要真人
这一类**不要用 AI 做**。真人出镜的内容，找真人拍，成本反而更低、风险更小。

AI 广告的能力边界要诚实划出来。硬用 AI 做真人口播，是拿自己的短板去打别人的长板。
:::

---

### ✕ 品牌情感故事片

三个不匹配：

- **体量不匹配**：低客单价单品，情感故事片的制作成本回不来
- **注意力不匹配**：信息流里没人为一袋薯片看完 60 秒的故事
- **阶段不匹配**：品牌片是有品牌资产之后的事，一个靠工艺切入市场的新品，先把"为什么值得买"讲清楚

::: tip 什么时候可以做
等这个产品跑出量、要建立品类心智的时候。**现在做，是在正确的事情上抢错了时机。**
:::

---

## ③ 合规是片型筛子，不是最后一道检查

注意上面五个片型里，**有两个是被合规直接否掉的**，而不是被创意质量否掉的。

这是工艺类食品项目和普通项目最大的结构差异：

```
普通项目：  想创意 → 选片型 → 做出来 → 法务检查 → 小改
工艺食品：  合规边界 → 排除片型 → 在剩下的里想创意 → 法务复核
                ↑
          它在最前面，不在最后面
```

::: warning 把合规放在最后会怎样
你会做出一支很好的对比片，然后在法务环节被整个砍掉——**不是改文案能救的那种砍掉，是重做**。

案例 04 的工期里，四天有整整一天花在核查和审校上，不产出任何画面。这个成本必须计入报价，否则你是在免费做法务工作。
:::

## ④ 推荐组合拳：详情页 + 种草

单独任何一支都有缺口。**两支配合投放，缺口互补**：

| | 工艺解构片 | 感官 ASMR 片 |
|---|---|---|
| **投放位** | 电商详情页 | 抖音 / 小红书信息流 |
| **时长** | 20 秒 | 8–10 秒 |
| **回答的问题** | 为什么值得买 | 想吃 |
| **观众状态** | 已经点进来了，愿意看理由 | 刷到的，只给你两秒 |
| **开头** | 原料入场 | **直接上断面透光**，不要铺垫 |
| **结尾** | 包装 + 工艺字幕 | 包装一闪，不解释 |

::: tip 两支片子共用素材
断面镜头、成品掉落镜头两支都要用。**一次生成，两处使用**——这是降低生成成本最直接的办法。

排期上先做工艺片（要求更高、返工更多），感官片从它的素材里剪，能省掉大半工作量。
:::

## ⑤ 各片型的分镜取向

选定片型之后，分镜的走向也就定了。三条取向差异最大的：

| | 工艺解构片 | 感官 ASMR 片 |
|---|---|---|
| **结构骨架** | 原料 → 工艺 → 结果 → 产品（线性因果） | 强 → 更强 → 最强（感官递增，无叙事） |
| **第一个镜头** | 可以铺垫，但别用抽象概念镜开场 | 必须是全片最馋的一镜 |
| **色调** | 冷调（工艺段）转暖调（成品段） | 全程暖调，不做冷暖变化 |
| **声音** | 环境音为主，安静，衬托"精密" | **ASMR 音效为主，是主角不是配角** |
| **节奏** | 慢，升格多 | 快切，但每一镜都是升格素材 |
| **字幕** | 需要——概念镜头单独看看不懂 | 尽量不要，画面自己说话 |

::: warning 概念镜头不要放在最前面
案例 04 的复盘结论：镜头 2（悬浮的负压隐喻）放在第 3 秒，观众会困惑几秒钟，不知道在看什么。

**先给一个能看懂的画面建立上下文，再上抽象表达。**这一条对工艺片是通用的——工艺片天然要用隐喻，而隐喻需要上下文才成立。
:::

## ⑥ 判断清单

下次拿到一个"工艺不一样"的产品，按这个顺序过一遍：

1. **差异化落在哪一层？** 口味层 / 工艺层 / 品牌层——决定片子要承载什么
2. **感官要素还剩几条？** 逐条核对热、质感、光泽、动作。**失效的不要硬拍**
3. **合规先砍一轮。** 对比结构、健康暗示、功效宣称——先把不能做的划掉
4. **AI 长短板对一遍。** 拍不到的画面 = 长板；真人、文字、精确渐变 = 短板，见 [选型决策树](/tools/decision-tree)
5. **投放场景决定时长和开头。** 详情页可以铺垫，信息流不行
6. **剩下的片型不止一个？** 做组合拳，共用素材

---

## 可复用套路

1. **片型是排除出来的，不是选出来的。**先用产品条件和合规边界砍掉不可行的，剩下的往往只有一两个。这比"头脑风暴各种可能性"高效得多。

2. **同品类不等于同拍法。**薯条和薯条脆看着是一类东西，但一个有热气一个没有，食欲感的抓手完全不同。**逐条核对感官要素，不要凭品类印象套模板。**

3. **合规在工艺类项目里是筛子，不是检查项。**它决定哪些片型不能做，必须放在最前面。放在最后，被砍掉的不是文案而是整支片子。

4. **AI 让工艺片从最贵变成最便宜。**过去要进车间或做三维动画，现在生成就行。**成本结构变了，片型的性价比排序也要跟着变**——这是需要重新评估的，不能沿用旧经验。

5. **单支片子有缺口时，考虑组合拳而不是硬塞。**感官片讲不了工艺，工艺片不够馋——不要试图用一支片子解决两个问题，那会变成两头不到岸。**两支片子共用素材，成本增加有限。**

6. **AI 做不好的，就不要用 AI 做。**真人口播这类内容，找真人拍成本更低风险更小。**诚实划出能力边界，比硬撑更专业。**
