# 案例 08 · 蜜雪冰城 × 可灵「意想不到雪王」（逆向拆解）

> **一句话**：品牌交付的不是一支片子，而是**一个让用户自己生产片子的工具**——这是 [片型图谱](/method/ad-formats) 十一种片型之外的物种。

::: warning 先说清楚这篇的性质
这是对**公开营销活动的逆向拆解**，不是项目复盘。

- 信息来源为行业媒体报道与平台公开信息，**未参与项目**，也未获取任何制作记录。
- 传播数据为**平台 / 品牌方对外口径**，未经第三方核实。曝光量类指标通常口径宽松，见 ③。
- 涉及的品牌形象、IP 与平台名称仅用于指称分析对象，权利归各自权利人所有。
:::

::: danger 时间说明
活动时间为 **2025 年 8 月**，**不是最新案例**。

之所以仍然值得单开一篇：**它是本站收录的案例里唯一一个「产出物不是广告片」的**。这个形态上的差异，比时间新旧重要得多。
:::

| | |
|---|---|
| 品类 | 现制茶饮 |
| 交付形态 | **AI 特效模板**（不是广告片） |
| 投放渠道 | 快手 |
| 生成引擎 | 可灵 AI |
| 参与形式 | 用户上传照片 → 自动生成雪王入镜的短视频 |
| 传播 | 话题曝光 10 亿+、社交互动 77.1 万（口径） |

---

## ① 它的产出物是什么

先把形态说清楚，因为这决定了后面所有分析。

**普通广告的交付链条**：

```
品牌 → 创意 → 制作 → 一支片子 → 投放 → 用户观看
```

**这个案例的交付链条**：

```
品牌 → 创意 → 制作 → 一个特效模板 → 用户使用 → N 支片子 → 用户自己传播
```

用户上传一张自己的照片，AI「理解」照片里的场景，自动把雪王合成进去，生成一段个性化的小剧情——雪王和用户的宠物互动、雪王出现在用户的旅行照里。

::: tip 差别不在技术，在交付物的位置
品牌做完的那一刻，**片子还不存在**。

它做完的是**生产片子的能力**，内容由用户填。这与所有传统片型的根本区别在于：**创意的最后一公里交给了用户**，而品牌控制的是那个"容器"。
:::

---

## ② 为什么这个玩法能成立：一个技术前提

这是本篇最值得记的一条，**而且它是技术判断，不是营销判断**。

这套玩法的核心技术难点是：**在成千上万张完全不可控的用户照片里，把同一个品牌形象合成进去，还得每次都长得一样。**

按 [品牌一致性控制](/method/brand-consistency) 的分析，这是 AI 最容易翻车的地方。**那它为什么能成？**

因为雪王这个 IP 恰好具备三个特征：

| 特征 | 为什么关键 |
|---|---|
| **卡通形象** | 没有真人的微表情和口型问题——[AI 目前最弱的一环](/prompts/spokesperson)直接绕过 |
| **造型极简** | 白色胖身体 + 王冠 + 权杖。**结构越简单，AI 画错的余地越小** |
| **辨识度极高** | 就算比例略有偏差，观众也一眼认得出。**容错率高** |

::: warning 这条前提决定了谁能抄、谁不能抄
把雪王换成下面任何一个，这套玩法立刻崩掉：

| 换成 | 会发生什么 |
|---|---|
| 真人代言人 | 脸崩、表情僵硬，观众一眼出戏 |
| 有 logo 的实体产品 | logo 变形、包装文字乱码——[所有图像工具的共同短板](/tools/landscape) |
| 结构复杂的吉祥物 | 细节越多，跨次生成的漂移越明显 |

**结论：这个案例的可复制性，取决于你的品牌有没有一个「简单到 AI 画不坏」的视觉符号。**

绝大多数品牌没有。**所以这篇拆解的价值，一半在于说清楚「你大概率抄不了」。**
:::

## ③ 传播数据怎么看

公开口径：话题曝光 10 亿+，社交互动 77.1 万，话题登上平台热榜。同期该 IP 在另一平台的共创计划也公布了 7 天 12 万+ UGC 作品的数据。

::: danger 曝光量是最不该直接引用的指标
**一、口径极宽。**「话题曝光」通常统计的是话题页的浏览总量，包含大量非目标人群的滑过。10 亿这个量级，和「10 亿人看了广告」完全是两回事。

**二、互动率才是真信号。**曝光 10 亿 / 互动 77.1 万，**互动率约 0.077%**。这个数字本身不难看（话题类活动的常见区间），但它说明：**绝大多数曝光是路过，不是参与。**

**三、UGC 作品数是这类活动最硬的指标。**因为它需要用户完成「上传照片 → 等待生成 → 发布」的完整动作，注水难度远高于浏览量。**看这类案例时，优先找作品数，其次找互动数，最后才看曝光。**
:::

## ④ 三层结构：谁出了什么

这个玩法能跑起来，靠的是三方各出一块，缺一不可：

| 角色 | 出什么 | 换个说法 |
|---|---|---|
| **品牌** | IP 形象、创意规则、活动预算 | 出「主角」 |
| **平台 / 工具方** | 生成能力、特效入口、流量位 | 出「机器」 |
| **用户** | 素材（自己的照片）、创意（怎么玩）、传播 | 出「内容和嗓门」 |

::: tip 品牌真正让渡的东西
**是创意控制权。**

传统广告里，画面每一帧都是品牌审过的。这个玩法里，用户拿雪王去干什么，品牌事先不知道。

这是**用可控性换参与度**——一笔明确的交易，做之前要想清楚愿不愿意换。
:::

## ⑤ 这类玩法独有的风险

::: danger 用户生成的内容挂在你的品牌名下
这是普通广告完全没有的风险类型：

1. **不当内容**。用户可能上传不适宜的照片，生成的内容仍带着你的品牌形象和话题标签。
2. **形象损伤**。IP 被用于品牌不希望关联的语境，事后难以撤回。
3. **肖像与隐私**。用户上传的照片里可能有他人肖像。**授权链条是否清晰，是活动上线前必须与平台确认的事项**，参见 [人物代言的边界](/prompts/spokesperson)。
4. **审核成本**。作品量越大，人工审核越不可能覆盖。**「12 万+ 作品」意味着人工是看不完的。**

**开放共创的活动，风控预案必须在上线前做好，不能等出事再补。**
:::

## ⑥ 可复用套路

1. **先看自己有没有「AI 画不坏」的视觉符号。**卡通、简单、高辨识度——三条缺一条，这个玩法的成功率就大幅下降。

2. **产出物可以不是片子。**「做一支广告」和「做一个让用户做广告的工具」是两条不同的路。后者省的不是制作费，是**传播费**——用户替你分发。

3. **看这类案例的数据，先找 UGC 作品数。**曝光量口径最宽，作品数最难注水。

4. **用可控性换参与度，是笔要算清的交易。**品牌调性严肃、法务尺度紧的品类，这笔交易多半不划算。

5. **风控预案要在上线前做。**作品量一大，人工审核就失效了。

## 对本站片型图谱的影响

::: info 需要新增一个维度
[片型图谱](/method/ad-formats) 现在的十一种片型，**全部假设「品牌产出的是内容」**。

这个案例说明还有另一类：**品牌产出的是生产内容的工具。**

这不是第十二种片型——**它和那十一种不在同一个层级上**，是一个更前置的分叉：

```
品牌要交付什么？
├── 内容 ──→ 走片型图谱的十一种
└── 工具 ──→ 特效模板、共创玩法（本案例）
```

这个分叉应该加在片型图谱的最前面，**在「选片型」之前先问「做内容还是做工具」**。

**暂不改动那一页**——这个判断目前只有一个案例支撑，等再看到两三个同类案例，确认它是一个稳定的类别而不是偶发玩法，再动结构。
:::
