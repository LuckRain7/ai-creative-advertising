# 拆解模板

所有案例按同一个格式写，四段。统一格式的好处是横向可比——看多了能看出规律。

## 四段结构

| 段 | 回答 | 重点 |
|---|---|---|
| **① 创意点** | 说了什么？为什么这么说？ | 洞察 → Big Idea 的推导过程 |
| **② 生成链路** | 怎么做出来的？ | 每一步的输入、工具、输出 |
| **③ 关键 Prompt** | 具体敲了什么？ | 只放起决定作用的那几条 |
| **④ 可复用套路** | 下次能抄什么？ | 抽象出来的方法，不是具体内容 |

## 每段写什么

### ① 创意点

- **背景**：什么产品、什么人群、什么渠道、什么限制
- **洞察**：找到的那条心理，一句话
- **Big Idea**：一句话
- **为什么是它**：淘汰掉的方向以及淘汰的理由

::: tip 淘汰理由比入选理由更值钱
"为什么否掉 B 方案"记录的是判断标准，下次遇到类似情况能直接复用。而"为什么选 A"往往只是事后合理化。
:::

### ② 生成链路

画出流程，每一步交代四件事：

```
步骤 → 输入是什么 → 用什么工具 → 输出是什么
```

同时记录三个数字：

- **总生成条数 / 最终采用条数**（出片率）
- **各环节耗时**
- **返工点**：哪一步返工了，为什么

### ③ 关键 Prompt

**只放起决定作用的那几条**，不要把所有 Prompt 都贴上来——贴多了没人看。

每条按 [Prompt 卡片格式](/templates/prompt-card) 写，并额外说明：**它解决了这个项目里的什么具体问题。**

### ④ 可复用套路

这一段是整篇的价值所在。抽象层级要够高：

| ❌ 太具体（不可复用） | ✅ 可复用 |
|---|---|
| 用了 `暗调暖色 + 侧逆光` | 饮料类产品，把光源放在瓶身后方能让液体透亮，这比调色重要 |
| 第 3 个镜头重做了 8 次 | 有液体流动的镜头废片率最高，排期时给它留双倍时间 |
| slogan 定的是「XXX」 | 对比型 slogan 在这个人群里比陈述型更容易过审 |

判断标准：**这条经验换个产品、换个客户还成立吗？**成立才写进这一段。
