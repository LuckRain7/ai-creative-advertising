# 案例 04 · VF 工艺薯条脆

::: warning 这是教学演示案例
用于展示**看不见的工艺怎么变成看得见的画面**，以及技术卖点的合规边界。**不是真实客户项目的复盘**，数字为基于典型情况的合理估计。

文中涉及的工艺原理为通用食品工程常识，具体产品的工艺参数请以技术方提供的资料为准。
:::

> **一句话**：卖工艺的广告，最大的敌人不是画面不好看，是**说错话**。

|---|---|
| 品类 | 预包装休闲零食 · VF 薯条脆 |

| 投放渠道 | 电商详情页 + 社媒种草 |

## ① 创意点

### 背景

一款采用 VF 工艺（Vacuum Frying，真空低温油炸）的薯条脆，包装零食，走电商渠道。

客户的诉求很直接：**「我们的工艺不一样，要把这个讲出来。」**

### 先搞清楚 VF 到底是什么

做这类项目，**第一件事不是想创意，是把技术搞懂**。搞不懂就只能写空话，或者写错话。

VF 的基本原理（通用食品工程常识）：

| 环节 | 发生了什么 |
|---|---|
| 抽真空 | 罐内形成负压环境 |
| 沸点降低 | 负压下油和水的沸点都下降 |
| 低温脱水 | 因此可以在比常压油炸低得多的温度下完成脱水 |
| 形成多孔结构 | 水分快速汽化留下气孔，这是酥脆的来源 |
| 离心脱油 | 出料后甩掉表面附着的油 |

**关键推论**：低温意味着原料的色泽和风味物质受热破坏更少——所以 VF 产品往往能保留接近原料本身的颜色。

::: danger 这里有一个必须诚实面对的事实
**VF 是油炸，不是非油炸。**

它是"真空低温油炸"，工艺路径仍然是油炸，成品仍然含油。把 VF 宣传成「非油炸」是虚假宣传。

这一条要在项目一开始就跟客户对齐。有些客户会希望你往「非油炸」的方向靠——这时候要顶住。**这不是创意问题，是法律问题。**
:::

### 限制条件（这个项目最重的部分）

| 不能说 | 为什么 |
|---|---|
| 非油炸 | 事实错误，VF 就是油炸 |
| 更健康 / 低脂 / 0 负担 | 营养声称（如「低脂」）在国标下有明确的量化门槛，须产品实测达标并按规范标示才能用。不是想说就能说 |
| 吃了不长胖 / 适合减肥 | 功效宣称，普通食品不得涉及 |
| 任何疾病相关表述 | 食品广告的绝对红线 |
| 「减少有害物质」类表述 | 即便有科学依据，在广告里说会被认定为暗示健康功效 |

::: warning 关于最后一条
高温油炸淀粉类食品会产生一些高温副产物，低温工艺理论上有助于减少——这是真实的食品科学。

**但知道不等于能说。**在广告里提这件事，等于暗示「我们的更安全」，这属于健康功效暗示，风险很高，还容易被认定为贬低同类产品。

**放进知识储备，不放进文案。**这个分寸感是做工艺类广告的基本功。
:::

### 洞察

消费者对「油炸」有本能的抗拒，但又抵挡不住脆的东西。这个矛盾一直存在。

VF 的价值恰好落在这条缝里——但**不能直接把这层价值说出来**（说出来就是健康宣称）。

### Big Idea

> **不说工艺的好处，只展示工艺的做法。**

这是本案例最核心的判断。

「更健康」是**结论**——违规、且消费者不信。
「我们在负压环境下用低温炸了它」是**事实**——合规、可展示、且消费者会自己得出结论。

::: tip 这条能迁移到所有技术卖点类项目
冻干、冷压、慢烘、低温萃取……凡是「工艺不一样」的产品，都适用同一个策略：

**展示过程，让消费者自己下结论。**你替他下结论，既违规又不可信；他自己下的结论，他才信。
:::

### 淘汰掉的方向与理由

| 方向 | 淘汰理由 |
|---|---|
| 「0 负担的轻食零食」 | 功效暗示，合规风险高。且「0 负担」是典型的擦边表述，平台审核也未必过 |
| 「妈妈放心的选择」 | 用信任转移的方式暗示健康，绕了个弯还是同一个问题 |
| 「还原土豆本味」 | 方向没错，但太平淡，且「本味」几乎无法视觉化 |
| 「对比传统油炸」的对照结构 | **风险最高的一个。**直接对比容易构成贬低同类产品，在广告法下有明确风险 |

**最后一条值得展开**：客户最初想要的就是对比结构（左边传统、右边 VF）。这个诉求要挡回去——不是因为效果不好，是因为它把一个创意问题变成了法务问题。

替代方案：只展示自己的工艺，不出现任何参照物。观众的对比是在他自己脑子里完成的。

## ② 生成链路

### 这个项目里 AI 承担的角色变了

前三个案例里，AI 做的是「把能拍的东西拍出来」。这个项目不一样：

**核心画面全都是实拍不可能拍到的。**

| 要展示的 | 实拍可行性 |
|---|---|
| 真空罐内部的油炸过程 | 不可行——设备封闭、负压环境，没有观察窗 |
| 薯条脆断面的蜂窝气孔结构 | 需要电镜，成本极高且画面不美观 |
| 水分从组织中汽化逸出 | 微观尺度，拍不到 |
| 温度差异的视觉表达 | 抽象概念，无实物 |

::: tip AI 在广告里最被低估的价值
不是「拍得更好」，而是**「拍得到拍不到的东西」**。

案例 03 展示的是 AI 拍真实食物的弱点（容易塑料感）。这个案例正好相反——**越是现实中不存在的画面，AI 的相对优势越大**，因为没有真实参照物去比对，观众也无从挑剔。

技术类、工艺类、原理类的内容，是 AI 广告目前性价比最高的应用场景之一。
:::

### 流程

```
① 技术理解 + 事实核查（人 + 技术方确认）  ← 本案例特有
   ↓
② 工艺原理 → 视觉隐喻的转化（人）
   ↓
③ 概念视觉生成：拍不到的画面（图像模型）
   ↓
④ 质感镜头：断面、气孔（图像模型，微距）
   ↓
⑤ 包装实拍 + 合成（实拍 + 设计软件）
   ↓
⑥ 合规审校（人 / 法务）  ← 本案例特有
```

第 ① 步和第 ⑥ 步是前三个案例没有的。**卖感官的广告不需要它们，卖技术主张的广告必须有。**

### 工艺原理 → 视觉隐喻

这一步是创意的实际发生处。把技术语言翻译成画面语言：

| 技术事实 | 视觉隐喻 | 落到哪个镜头 |
|---|---|---|
| 负压环境 | 悬浮、静止、无重力感的空间 | 镜头 2 |
| 低温 | 冷色调、缓慢、无剧烈翻腾 | 镜头 3 |
| 水分汽化 | 细密气泡从内部缓慢逸出 | 镜头 3 |
| 多孔结构 | 蜂窝状断面，光从孔隙穿过 | 镜头 5 |
| 保留原色 | 高饱和的自然黄色 | 全片 |

::: warning 隐喻要基于事实，不能为了好看编造
「负压 → 悬浮感」是合理的视觉转化，因为它传达的是"环境不同"这个真实信息。

但如果画一个"分子被温柔地包裹起来"之类的画面，就是在编造一个不存在的机制——这叫伪科学包装，既不诚实，也经不起懂行的人推敲。

**判断标准：这个画面对应的技术事实，能不能在技术资料里找到出处？**找不到就别画。
:::

### 分镜表（20 秒，7 镜）

| # | 时长 | 景别 | 主体与动作 | 光 | 备注 |
|---|---|---|---|---|---|
| 1 | 0–3s | 特写 | 新鲜土豆切片落在金属台面 | 侧逆光 | 交代原料 |
| 2 | 3–6s | 中景 | 切片悬浮在暗色空间中，静止无重力 | 冷调轮廓光 | **负压的隐喻** |
| 3 | 6–10s | 微距 | 细密气泡从切片内部缓慢逸出 | 逆光，气泡被点亮 | **核心镜头** |
| 4 | 10–12s | 特写 | 色泽从生土豆的浅白转为金黄 | 转暖色 | 保留原色 |
| 5 | 12–15s | 微距 | 掰断，断面蜂窝气孔清晰，光从孔隙穿过 | 强逆光 | **酥脆的证据** |
| 6 | 15–18s | 特写 | 成品堆叠，自然掉落 | 暖侧逆光 | 食欲感 |
| 7 | 18–20s | 中景 | 包装袋，字幕出 | 柔和产品光 | 实拍合成 |

**结构逻辑**：原料 → 工艺 → 结果 → 产品。这是工艺类广告的标准骨架，比讲故事更适合详情页场景。

### 数字

| 项 | 值 |
|---|---|
| 总生成 / 采用 | 约 80 条 / 11 条（视频 5 条 + 静图 6 张） |
| 技术理解与核查 | 约 1 天 |
| 概念视觉 | 约 1 天 |
| 质感与合成 | 约 1 天 |

四天里有**整整一天**花在核查和审校上，不产出任何画面。

## ③ 关键 Prompt

### Prompt 1 · 镜头 2 真空环境（拍不到的画面）

**适用场景**
把抽象的物理环境转化为可感知的画面。
**不适用**：需要写实还原真实设备的场合——这是隐喻，不是纪实。

**可复制 Prompt**

```
一片薄薄的生土豆切片静止悬浮在深色的虚空中，周围没有任何支撑物，
切片边缘极其清晰，环境中有极细微的悬浮颗粒同样静止不动，

概念科学可视化，暗调，冷色调偏青蓝，极简，
100mm 微距镜头，极浅景深 f/2.8，平视机位，
单一冷白色轮廓光从右后方勾勒切片边缘，背景为纯粹的深黑，
竖版 9:16，高细节，画面干净

负向：文字、水印、油、液体、翻腾、气泡、多个物体、杂乱背景
```

**参数说明**

| 关键词 | 在控制什么 | 想改效果时 |
|---|---|---|
| 静止悬浮 + 没有支撑物 | **负压的核心视觉表达。**悬浮传达"环境不寻常" | 想更强烈可加"时间凝固" |
| 悬浮颗粒同样静止 | 强化"整个空间都静止"，比只有主体悬浮更有说服力 | —— |
| 冷色调偏青蓝 | 低温的色彩编码，和镜头 4 的转暖形成呼应 | —— |
| 翻腾、气泡（负向） | **这一镜要的是"静"。**有气泡就变成了常规油炸的画面，隐喻失效 | —— |

**常见翻车点**

- **画成了真实的油锅**。模型看到"土豆"「炸」会默认给你翻滚的油锅——那正是要避开的画面。所以 Prompt 里完全不提油和炸，只描述悬浮状态。
- **加了太多科技元素**。数据流、光效、粒子特效——一加就变成劣质科技广告。**极简是这一镜的关键。**
- **观众看不懂**。这一镜单独看确实抽象，它依赖后面镜头的上下文，以及字幕的一句说明。**概念镜头不能孤立存在。**

### Prompt 2 · 镜头 5 蜂窝断面（酥脆的物证）

**适用场景**
用微观结构为「酥脆」提供视觉证据。这是全片说服力最强的一镜。

**可复制 Prompt**

```
一片薯条脆被掰成两半，断面正对镜头，
断面呈现不规则的蜂窝状多孔结构，孔隙大小不均，
强烈的逆光从断面背后穿过孔隙，形成明亮的透光点，

食品微距摄影，暖金色调，轻微胶片颗粒，
100mm 微距镜头，极浅景深，平视机位，
强逆光，光线穿透孔隙，边缘有明亮轮廓，背景压暗虚化，
竖版 9:16，超高细节，真实食物质感

负向：文字、水印、塑料感、规则的孔洞、蜂巢图案、完美对称、CGI 感
```

**参数说明**

| 关键词 | 在控制什么 | 想改效果时 |
|---|---|---|
| **孔隙大小不均** | **本条最关键。**不写的话模型会画出规整的蜂巢图案，一看就假 | 想更真实加"孔壁厚薄不一" |
| 光线穿透孔隙 | 透光是"多孔"最直观的证明，比单纯展示孔洞有力得多 | 想更戏剧化就加"背景纯黑" |
| 规则的孔洞 / 蜂巢图案（负向） | 模型对"蜂窝"的默认理解是六边形蜂巢——**必须排除** | —— |
| 完美对称（负向） | 同 [案例 03](/cases/case-03-fries-social) 的结论：完美即虚假 | —— |

**常见翻车点**

- **画成了标准蜂巢**。「蜂窝状」这个词会触发六边形规则结构，那是蜜蜂做的，不是油炸做的。**必须显式排除，并强调"不规则""大小不均"。**
- **孔隙结构不符合物理**。孔太大、壁太薄，看起来像泡沫塑料。多生成几版，挑结构合理的。
- **过度美化**。这一镜的说服力来自"真实"，修得太漂亮反而失效。

### Prompt 3 · 镜头 7 包装产品（走合成路线）

**适用场景**
成品包装出镜。

**做法**

按 [选型决策树 A1](/tools/decision-tree#a1-产品必须精确还原吗)——**包装袋有 logo、有印刷文字、有精确的配色，不能生成。**

```
链路：包装实拍（或用设计源文件做 3D 渲染）
      → AI 生成背景与光环境
      → 设计软件合成 + 加字幕
```

**背景的 Prompt**

```
一个空的浅色木质台面，背景是柔和虚化的暖色环境，画面中央大面积留白，

食品广告摄影，暖色调，轻微胶片颗粒，
50mm 镜头，浅景深 f/2.8，微俯机位，
柔和的侧逆光从右后方打来，台面有自然的光影过渡，
竖版 9:16，高细节

负向：文字、水印、任何产品、任何包装、杂乱物品
```

**参数说明**

| 关键词 | 作用 |
|---|---|
| 中央大面积留白 | 给合成的包装留位置 |
| 任何产品 / 任何包装（负向） | 不排除的话模型会自己放个包装袋进去，合成时要多一道去除 |

**常见翻车点**

**试图让 AI 画出包装上的文字。**生成的中文必然是乱码，英文也常错。包装一律走实拍或渲染，这一步没有捷径。

## 附 · 用 Gemini 直接生成视频的完整提示词

上面 ③ 里的 Prompt 是**给图像模型用的**，关键词堆砌式。如果你要把这七个镜头直接丢给 Gemini 出视频，得换一种写法——照搬过去效果会明显打折。

### 三个必须知道的结构差异

Gemini 的视频生成（Veo 系列）和 Midjourney 那类图像模型，提示词的吃法不一样：

| | 图像模型（前面 ③ 的写法） | Gemini / Veo |
|---|---|---|
| **句式** | 关键词用逗号堆叠 | **完整的描述性句子**，像在跟摄影师讲戏 |
| **否定** | 在正文里写「负向：文字、水印」 | **单独填 negative prompt 字段**，正文里不要出现否定词 |
| **音频** | 无 | Veo 3 系列**原生生成音效与环境音**，提示词里可以直接描述声音 |

::: danger 第二条最容易踩坑
在 Veo 的主提示词里写「不要有文字」「没有人物」这类否定句，**反而可能把这些元素引进来**——模型会注意到「文字」这个词本身。

否定内容一律填到单独的 negative prompt 输入框里，只写名词，不写「不要」。这是 Google 官方提示词指南里明确说明的用法。

下面每条我都把 negative prompt 单独列出来了，**别把它粘进正文**。
:::

::: warning 具体功能以官网为准
Veo 的版本、可用时长、分辨率、是否支持音频、negative prompt 的入口位置，各渠道（Gemini App / Google AI Studio / Vertex AI）不同且更新频繁。这里给的是**提示词写法**，不是操作步骤。
:::

### 先看清楚：七条里有三条纯文生视频做不出来

在你逐条粘贴之前，先知道哪些能成、哪些不能——省得白烧额度。

| 镜头 | 纯文生视频可行性 | 说明 |
|---|---|---|
| 1 · 切片落下 | ✅ 可行 | 简单单一动作 |
| 2 · 悬浮静止 | ✅ 可行 | 「静止」对模型是舒适区 |
| 3 · 气泡逸出 | ⚠️ 勉强 | 液体/气泡是弱项，废片率高，多生成 |
| 4 · 色泽转变 | ❌ **不可行** | 渐变过程，模型控不住，见下方替代方案 |
| 5 · 掰断 | ❌ **不可行** | 形变不可逆，必须首尾帧，见 [案例 03](/cases/case-03-fries-social#prompt-2-·-镜头-3-掰断-首尾帧控制) |
| 6 · 成品掉落 | ✅ 可行 | 多物体但动作单一 |
| 7 · 包装出镜 | ❌ **不可行** | 包装有 logo 和文字，必须实拍合成 |

**四条能直接生成，三条需要别的做法。**这个比例在工艺类项目里算正常——越是有精确要求的镜头，越不能交给纯文生视频。

### 镜头 1 · 原料入场（3 秒）

```
一片薄薄的生土豆切片以慢动作落到拉丝不锈钢台面上，轻微弹跳后静止。
极特写微距镜头，浅景深，镜头保持完全静止不动。
强烈的侧逆光从右后方打来，勾勒出切片边缘，光线透过薄片显出半透明的质感。
高端食品广告摄影风格，暖金色调，背景是压暗的深色环境，画面干净。
细腻的胶片颗粒质感，真实照片般的写实感。

声音：土豆片落在金属台面上一声轻脆的接触声，安静的室内环境音，没有配乐。
```

**Negative prompt**（填到单独的输入框）

```
text, watermark, logo, hands, multiple slices, cluttered background, plastic look, CGI, cartoon
```

**这条在控制什么**：用慢动作 + 微距建立「郑重对待原料」的基调。侧逆光透出薄片的半透明感，是这一镜唯一的技术要求。

::: details 英文版本（响应通常更稳）
```
A single thin slice of raw potato falls in slow motion onto a brushed stainless steel surface, bouncing softly once before settling. Extreme close-up macro shot, shallow depth of field, camera completely static. Strong side-backlight from the rear right rims the edge of the slice, light passing through it revealing a translucent thinness. High-end food commercial cinematography, warm golden tone, dark moody background, clean composition. Fine film grain, photorealistic.

Audio: one soft crisp impact of potato on metal, quiet room tone, no music.
```
:::

### 镜头 2 · 负压隐喻（3 秒）

```
一片生土豆切片静止悬浮在一片纯粹的深黑虚空中，下方没有任何支撑物，
周围有极细微的悬浮颗粒，同样凝固在空中一动不动，整个空间像时间被按下了暂停。
中景微距镜头，极浅景深，镜头极其缓慢地向前推近。
一道冷白色的轮廓光从右后方勾勒出切片的边缘，背景是纯粹的深黑。
概念科学可视化风格，冷调偏青蓝，极简，画面中只有这一个主体。

声音：低沉的环境嗡鸣，几乎无声，营造真空般的寂静。
```

**Negative prompt**

```
text, watermark, oil, liquid, bubbling, boiling, splashing, multiple objects, busy background, sci-fi HUD, glowing particles, lens flare
```

**这条在控制什么**：全片的概念核心。**关键是「静」**——一旦出现油、气泡、翻腾，负压的隐喻立刻垮掉变成普通油锅，所以 negative prompt 里把这些全排除了。「悬浮颗粒同样静止」这句比只让主体悬浮更有说服力。

::: details 英文版本
```
A single thin slice of raw potato hangs perfectly still, suspended in a pure black void with nothing supporting it. Tiny particles float around it, equally frozen in place, as if time itself has stopped. Medium macro shot, very shallow depth of field, camera pushes in extremely slowly. A single cold white rim light from the rear right traces the edge of the slice against the pure black background. Conceptual scientific visualization style, cool cyan-blue tone, minimalist, one subject only.

Audio: a low ambient hum, near silence, a vacuum-like stillness.
```
:::

### 镜头 3 · 水分汽化（4 秒）· 核心镜头

```
极致微距镜头，一片土豆切片的表面，细密的小气泡从切片内部缓慢地向外逸出，
气泡一颗一颗地形成、膨胀、离开表面，整个过程非常缓慢，像升格慢镜头。
镜头保持静止，极浅景深，只有切片表面的一小块区域是清晰的。
强烈的逆光从背后穿过，每一颗气泡都被光点亮，呈现出半透明的亮点，背景压暗成深色。
科学微距摄影风格，冷调转向暖调的过渡，真实的物理质感，细腻的胶片颗粒。

声音：极其轻微的细密气泡声，缓慢而有节奏，没有配乐。
```

**Negative prompt**

```
text, watermark, violent boiling, splashing oil, fast motion, large bubbles, foam, soap suds, CGI, cartoon
```

**这条在控制什么**：全片说服力的来源——**看得见的脱水过程**。三个要点：气泡要小而密（大气泡=沸腾=高温，与低温工艺矛盾）、要慢、要逆光点亮。

::: warning 这一镜废片率最高
气泡的物理行为是视频模型的弱项（和 [案例 01](/cases/case-01-beverage-tvc) 的气泡镜头同类问题）。常见翻车：气泡凭空出现又消失、往下走、或者突然变成剧烈沸腾。

**多生成，排期留双倍时间。**如果反复不成，退一步用图像模型生成一张气泡静帧，再走图生视频，可控性会好很多。
:::

::: details 英文版本
```
Extreme macro shot of the surface of a potato slice. Fine, tiny bubbles emerge slowly from within the slice, each one forming, expanding and releasing from the surface in extreme slow motion. The camera stays perfectly still with very shallow depth of field, only a small patch of the surface in focus. Strong backlight passes through from behind, illuminating each bubble as a translucent bright point against a darkened background. Scientific macro cinematography, cool tone shifting toward warm, realistic physical texture, fine film grain.

Audio: very faint fine bubbling, slow and rhythmic, no music.
```
:::

### 镜头 4 · 色泽转变（2 秒）❌ 纯文生做不出来

**为什么不行**：这一镜要的是同一个物体在时间上的颜色渐变。视频模型控不住渐变的起点和终点——它会变过头、变不够、或者中途反复。

**替代方案（推荐）**：用图像模型生成**两张**图——生土豆的浅白色一张、成品的金黄色一张，构图完全一致——然后走**首尾帧控制**：

```
【首尾帧模式】
[首帧：浅白色的土豆切片] → [尾帧：金黄色的成品切片]

切片的颜色从浅白色缓慢地转变为温暖的金黄色，形状和位置保持完全不变，
镜头静止，光线保持一致。
```

**Negative prompt**

```
shape change, movement, position shift, camera motion, text, watermark
```

**更省事的替代方案**：这一镜其实可以**在剪辑阶段做**——同一张静帧素材，用调色关键帧把色相从浅白推到金黄，两秒钟的镜头，五分钟就做完了，且完全可控。

::: tip 一个通用判断
**能在后期两分钟做完的效果，不要花两小时去生成。**

颜色变化、简单的缩放推拉、亮度渐变、叠化转场——这些交给剪辑软件比交给视频模型又快又准。视频模型的额度应该花在后期做不出来的东西上（真实的物理运动、复杂的光影变化）。
:::

### 镜头 5 · 蜂窝断面（3 秒）❌ 纯文生做不出来

**为什么不行**：掰断是不可逆形变，纯文生视频会出现「断了又愈合」「两截比原来长」。完整说明见 [案例 03 的首尾帧方案](/cases/case-03-fries-social#prompt-2-·-镜头-3-掰断-首尾帧控制)。

**替代方案**：先用 ③ 里的 [Prompt 2](#prompt-2-·-镜头-5-蜂窝断面-酥脆的物证) 生成一张满意的断面静图作为**尾帧**，再生成一张完整薯条脆的**首帧**，走首尾帧模式：

```
【首尾帧模式】
[首帧：完整的一片薯条脆] → [尾帧：掰成两半，断面朝向镜头]

薯条脆被缓慢地掰成两半，断面转向镜头，
强烈的逆光穿过断面的孔隙形成明亮的透光点，
除此之外画面其余部分保持静止。

声音：一声清脆的断裂声，干燥而清晰，随后是安静。
```

**Negative prompt**

```
healing, reassembling, extra pieces, changing size, fast motion, camera cut, deformed fingers, text, watermark
```

::: tip 尾帧决定成败
先把**尾帧**（断面那张）调到满意，再回头做首帧。断面的孔隙结构是这一镜的全部价值，首帧只是个起点。

生成断面静图时记得排除 `regular holes, honeycomb pattern, hexagonal` —— 模型对「蜂窝」的默认理解是六边形蜂巢，那是蜜蜂做的，不是油炸做的。
:::

### 镜头 6 · 成品掉落（3 秒）

```
一堆金黄色的薯条脆片从画面上方缓缓落下，堆叠在浅色木质台面上，
片与片之间自然地叠压、轻微滑动后静止，每一片的形状和色泽都略有不同，
边缘不规则，表面有深浅不一的金黄色斑点。
特写镜头，浅景深，慢动作，镜头保持静止。
温暖的侧逆光从右后方打来，片与片的边缘被光勾出明亮的轮廓，背景虚化压暗。
高端食品广告摄影，暖金色调，细腻的胶片颗粒，真实的食物质感。

声音：薯条脆片相互碰撞的清脆声响，干燥、轻盈、有层次，没有配乐。
```

**Negative prompt**

```
text, watermark, packaging, uniform shapes, identical pieces, perfect symmetry, plastic look, wax look, CGI, soggy, oily surface
```

**这条在控制什么**：食欲感的落点。**关键是「每一片都略有不同」「边缘不规则」「斑点深浅不一」**——这是 [案例 03](/cases/case-03-fries-social) 得出的核心结论：完美即虚假。negative prompt 里排除 `uniform shapes, identical pieces` 就是同一个道理。

::: details 英文版本
```
A pile of golden potato crisps falls gently from above onto a light wooden surface, the pieces overlapping and sliding slightly before settling. Each piece has a slightly different shape and colour, with irregular edges and uneven golden-brown speckles across the surface. Close-up shot, shallow depth of field, slow motion, camera static. Warm side-backlight from the rear right rims the edges of the pieces with bright outlines, background darkened and blurred. High-end food commercial cinematography, warm golden tone, fine film grain, realistic food texture.

Audio: crisp dry clatter of the pieces landing against each other, light and layered, no music.
```
:::

### 镜头 7 · 包装出镜（2 秒）❌ 不要生成

包装袋有 logo、有印刷文字、有精确的品牌配色。**生成模型画不对，也不该让它画。**

**做法**：用 ③ 的 [Prompt 3](#prompt-3-·-镜头-7-包装产品-走合成路线) 生成一个**空台面背景**，包装用实拍或设计源文件渲染，最后在设计软件里合成 + 加字幕。

如果这一镜需要轻微的动态（比如缓慢推近），有两个办法：

1. **在剪辑软件里做**——静态合成图 + 关键帧缩放，两分钟搞定，完全可控（同镜头 4 的判断）
2. 让 Gemini 只生成**空背景的动态**（光影缓慢变化），再把包装合成上去——但这需要跟踪，通常不划算

---

### 一个建议的执行顺序

::: tip 先跑通全片，再抠单镜
1. **先把能生成的四条（1、2、3、6）各出一版**，拼起来看整体调性对不对
2. 调性对了，再回头挑质量不达标的重做
3. 镜头 4、5、7 走各自的替代方案
4. 全部达标后，关键镜头（2、3）多生成 2–3 个备选留给剪辑

不要在镜头 1 上死磕到完美再做镜头 2——很容易出现「每个镜头都好看，串起来不像一支片子」。这条在 [完整链路 SOP](/method/workflow-sop#_5-生成) 里说过，这里再强调一次，因为它是最常被违反的一条。
:::

### 跨镜头一致性怎么保

这七条里，我把风格描述**分散写进了每条的正文**（暖金色调、细腻胶片颗粒、浅景深、侧逆光），而不是像 ③ 那样抽成一个独立的「风格包」段落——因为 Veo 吃的是连贯句子，硬塞一段关键词会破坏句式。

代价是一致性更难保。三个对策：

1. **风格句子逐字复制。**「高端食品广告摄影，暖金色调，细腻的胶片颗粒，真实的食物质感」这一句在每条里保持完全一致，不要换同义词。
2. **镜头 2 是例外**——它是冷调概念镜头，色调本来就该和其余不同，靠镜头 4 完成冷暖过渡。
3. **兜底靠调色。**AI 素材的色温漂移是常态，全片套同一个 LUT 能救回大部分。见 [工具地图](/tools/landscape#_5-剪辑与后期)。

## ④ 可复用套路

1. **AI 最大的优势是拍得到拍不到的东西。**工艺内部、微观结构、抽象原理、时间尺度——这些实拍要么不可能要么极贵，AI 反而擅长。**技术类、工艺类内容是 AI 广告目前性价比最高的场景之一。**这一条和 [案例 03](/cases/case-03-fries-social) 正好互补：拍真实食物 AI 有短板，拍不存在的画面 AI 有长板。

2. **卖工艺就展示做法，不要展示好处。**「更健康」是结论——违规且不可信；「我们在负压下低温炸了它」是事实——合规、可展示，且消费者会自己得出结论。**你替他下的结论他不信，他自己下的结论他才信。**这条能迁移到所有技术卖点类项目。

3. **做工艺类项目，第一件事是把技术搞懂。**搞不懂只能写空话或写错话。**要到技术方的资料，看懂了再动手。**这一步省不掉。

4. **视觉隐喻必须能追溯到技术事实。**判断标准：这个画面对应的原理，能不能在技术资料里找到出处？找不到就别画——那叫伪科学包装。

5. **工期里要留出核查与审校的时间，并计入报价。**感官类项目不需要，技术主张类项目必须有。这个案例四天里有一整天不产出画面。不预留，你就是在免费做法务工作。

6. **对比结构要慎用。**直接对比同类产品容易构成贬低，是法律风险不是创意选择。**只展示自己，让对比发生在观众脑子里。**

7. **「知道」和「能说」是两回事。**有科学依据的事实，在广告语境下也可能因为构成健康暗示而不能说。这个分寸感是做食品广告的基本功。

8. **能在后期两分钟做完的效果，不要花两小时去生成。**颜色渐变、缩放推拉、亮度变化、叠化转场——交给剪辑软件又快又准且完全可控。视频模型的额度应该花在后期做不出来的东西上（真实的物理运动、复杂光影）。这个案例的镜头 4 就是典型：与其反复生成色泽转变，不如一张静帧加两个调色关键帧。

9. **动手前先分类哪些镜头能纯生成、哪些不能。**这个案例七个镜头里有三个纯文生视频做不出来（渐变、形变、带文字的包装）。**先分类再开工，能省掉大量白烧的额度。**判断依据：涉及不可逆形变、精确渐变、品牌文字的，都不要指望纯文生视频。

## 如果重做一次

**镜头 2（悬浮）和镜头 3（气泡）的顺序应该对调。**

现在的顺序是先抽象（悬浮的负压隐喻）再具体（气泡逸出）。实际观看时，观众在第 3 秒看到一个悬浮的土豆片，会有几秒钟的困惑——不知道在看什么。

如果先给具体的气泡逸出（看得懂：在脱水），再给悬浮的空间感（此时已有上下文：哦，是在一个特殊环境里），理解成本会低很多。

**教训：概念镜头不要放在最前面。**先给观众一个能看懂的画面建立上下文，再上抽象表达。这一条和 [案例 01](/cases/case-01-beverage-tvc)、[案例 03](/cases/case-03-fries-social) 的「砍掉铺垫」不冲突——铺垫是无信息量的过渡，而上下文是理解的前提，两者要分清。
