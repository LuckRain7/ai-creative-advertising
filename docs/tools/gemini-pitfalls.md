## 一、三类生成质量坑（已被专题覆盖，这里只点题）

动手前记住三句话，细节去专题看：

1. **时长是最大的错觉**：很多人以为能一次出几十秒，实际单次生成很有限（主流多在 5~10 秒量级，以你当前套餐为准）。长片必须拆镜、分镜生成、后期拼。→ [控制视频时长](/tools/gemini-video-duration)
2. **角色一致性是广告片的头号盲点**：同一主角贯穿多镜，纯文本反复生必漂。可靠做法是「资产解耦定型 → 单镜头静态关键帧 → 图生视频」，而不是用同一张参考图死锁所有分镜首帧。→ [跨镜头一致性](/tools/gemini-shot-consistency)
3. **品牌字、口号、Logo 别指望 AI 写对**：尤其中文，生成里文字乱码是常态。正确姿势是「净版生成 + 后期平面跟踪贴标」。→ [包装文字不崩](/tools/gemini-packaging-logo)

## 二、平台与账号边界（专题未覆盖，本文新增）

这类坑不在 Prompt 里，而在「能不能用、用完能不能商用」：

- **地区可用性**：视频生成能力并非所有地区 / 账号类型都开放，企业版、教育版账号可能被锁功能。
- **订阅额度**：免费档与付费档可用额度差异大，超额需等下个周期，具体档位以官网为准。
- **内容审核**：真实人物（尤其名人 / 政治人物）、暴力血腥、色情、版权角色会被拒；连「模仿某风格」的描述都可能触发误判。
- **SynthID 隐形水印**：生成内容带不可见数字水印，肉眼看不出来，但可能影响某些平台的内容审核或 AI 检测判定。
- **负面提示词支持偏弱**：App 端对精细 negative prompt 的支持有限，与其写「不要 XX」，不如换措辞正面规避。→ [排除项写法](/tools/gemini-negative-tokens)

> 以上边界随时变动，动手前以官网和账号后台实际状态为准。

## 三、三条总是成立的工作方式

参数和档位会变，但这三件事在可预见的范围内不会变：

1. **单镜短、分镜拆、后期拼**。单次生成短是现状，不是缺陷；把它当成「每镜一个素材」而不是「一次出全片」。
2. **角色锁死走「先图后视频」**。先出静态关键帧（图模型），再图生视频，能最大程度压住漂移。→ [跨镜头一致性](/tools/gemini-shot-consistency) · [首帧与首尾帧](/tools/gemini-first-last-frame)
3. **品牌元素交给后期**。AI 负责画面和质感，Logo、口号、排版文字一律后期套件，永不指望生成端写对。
