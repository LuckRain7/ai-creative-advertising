# 工具地图

工具是链路上的零件，不是这件事的主角。所以这个板块放在 [方法论](/method/) 和 [Prompt 库](/prompts/) 的后面。

## 本板块内容

| 文章 | 用于 |
|---|---|
| [全景对照表](/tools/landscape) | 搞清楚有哪几类工具、各自负责什么 |
| [选型决策树](/tools/decision-tree) | 按预算和交付形态，快速定下用哪套 |

## 关于内容准确性的说明

::: warning 这个板块的内容易变，请自行核实
AI 工具的迭代速度以周计。因此本站的处理原则是：

**写**：工具的定位、擅长什么、不擅长什么、适合谁 —— 这类判断相对稳定。

**不写**：价格、订阅档位、单次生成时长上限、分辨率上限、并发数、有没有某个具体功能 —— 这类信息随时变化，写死了反而误导。

看到需要具体数字的地方，请以官网为准。
:::

## 一个反常识的建议

**别急着换工具。**

主流工具之间的能力差距，远小于使用者之间的差距。同一个模型，会拆分镜的人和不会的人，产出差一个量级。

判断标准：如果你的问题是「出来的东西很廉价」，那是 [Prompt 结构](/prompts/structure) 的问题，换工具解决不了；如果你的问题是「这个效果这个工具根本做不出来」（比如需要精确控制的运镜、特定的时长），那才是工具的问题。
