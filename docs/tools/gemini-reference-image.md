> 提问：用参考图控制构图时，图应该给到什么精度，才能既约束住构图、又不把一个不喜欢的风格也一起锁死？

## 核心原则

控制构图而不污染风格的核心原则是：**「锁定几何透视与体积占位，剥离色彩、材质与光影信息」**。

当参考图包含高饱和度颜色、特定笔触或复杂光影时，模型的潜在空间会强制将这些特征识别为「风格」并一同继承。理想的参考图应当具有**高几何精度、零风格语义**。

## 一、最推荐的 3 种中性参考图形态

### 1. 3D 极简白模 / 几何占位（3D Whitebox / Graybox）—— 工业级首选

- **精度要求**：在 3D 软件（如 Blender / C4D）中用无材质的基础立方体、圆柱或低模人偶摆好机位。
- **效果**：100% 锁定相机焦距、地平线高度、前后景遮挡关系与主体体积，但因没有贴图和颜色，生成的材质与艺术风格完全由 Prompt 掌控。

### 2. 纯净透视线稿 / 空间网格（Clean Wireframe / Line Art）

- **精度要求**：仅保留主体轮廓线与地面透视网格，严禁排线阴影、杂线或素描明暗。
- **效果**：模型只提取边缘结构（Edge Detection），将画面渲染风格的解释权 100% 留给文本提示词。

### 3. 扁平灰度剪影 / 质心色块（Flat Value Silhouette）

- **精度要求**：用黑、白、中性灰三种纯色块画出主体、前景与背景的面积配比。
- **效果**：精准约束视觉重心与画面留白（Negative Space），彻底避免特定色调污染。

## 二、参考图精度与污染风险对照表

| 参考图类型 | 构图约束力 | 风格污染风险 | 适用场景 | 处理建议 |
| --- | --- | --- | --- | --- |
| 真实拍摄照片 / 成品插画 | 强 | 极高（必污染） | 既要构图又要原画质感 | 严禁直接输入；必须经过预处理 |
| 3D 无材质白模 / 灰模 | 极强 | 极低（0% 污染） | 商业产品、复杂场景、精确机位 | 最稳方案，直接作为 ControlNet / 参考底图 |
| 单色线稿（无明暗） | 强 | 极低 | 人物姿态、分镜构图 | 保证线条闭合干净，去除草稿杂线 |
| 草图涂鸦（Scribble） | 弱 | 低 | 概念发散阶段 | 容易产生结构漂移，需提高生图步数 |

## 三、手头只有带风格的参考图时，快速「去风格化」的 3 步处理法

若只能使用现成图片做参考，不要直接喂给模型，先做轻量预处理：

1. **提取结构通道**：使用 Photoshop 或在线工具将图片转为 Canny 边缘线图或 Depth 深度灰度图，只把线图 / 深度图作为参考输入。
2. **压平色彩与明暗**：若必须使用图生图（I2I），先将原图完全去色（Desaturate 转为黑白），并用大画笔将主体内部的复杂纹理涂成单一中性灰。
3. **提示词强权覆盖（Prompt Overpowering）**：在 Prompt 中明确写出与原参考图完全相悖的风格词组（如原图是暖色手绘，Prompt 强写 `ultra-realistic commercial studio lighting, cold blue tone, 8k photo, clean glossy texture`），用高权重文本拉开与参考图风格的差距。
