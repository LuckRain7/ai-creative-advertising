# UGC 仿真风

::: info 待补充
这一页还没有实战 Prompt。下面是已确定的框架和一条必须守住的原则。
:::

## 这一页要解决的问题

信息流里，「看起来像广告」的内容会被直接划走，「看起来像真人分享」的内容完读率高得多。所以有一类需求是：**让 AI 生成的素材看起来不像专业制作的**。

这和其他所有场景的方向是**相反的**——别处在追求质感，这里在主动破坏质感。

## 一条必须守住的原则

::: warning 仿真不等于伪装
做成 UGC 的**视觉风格**是创意手法，但不能让观众**误以为这是真实用户的自发分享**。

具体来说：
- 平台对广告内容有强制标识要求，该标的必须标
- 不能虚构"真实用户"的使用体验和效果反馈
- 不能伪造评论、点赞等社交证据

风格上像素人拍的，和冒充素人说话，是两件事。前者是创意，后者是虚假广告。
:::

## 已知的方向

「不像广告」的视觉特征，大致是这几项的组合：

| 特征 | 对应的 Prompt 方向 |
|---|---|
| 手持晃动 | `手持拍摄，轻微晃动，不稳定` |
| 光线不完美 | `室内混合光源，色温不统一，轻微曝光不足` |
| 构图随意 | `随手拍，构图不居中，主体偏离画面中心` |
| 画质一般 | `手机拍摄，轻微噪点，压缩感` |
| 环境真实 | 背景里有杂物、没收拾的痕迹 |
| 表演不专业 | `素人，不看镜头，表情自然，没有摆拍` |

核心逻辑：**把所有"专业"的参数反过来写。**浅景深改成全景深（手机的默认状态），侧逆光改成顶部的室内灯，干净背景改成有生活痕迹的背景。
