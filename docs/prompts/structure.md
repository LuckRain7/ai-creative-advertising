# Prompt 结构通法

读完这一篇，你不需要背模板，可以自己写任何场景的 Prompt。

## 五段式

一条视觉 Prompt 由五个部分组成，**按重要性从前往后排**。多数模型对靠前的词权重更高。

```
[主体] + [风格] + [镜头] + [光影] + [参数]
```

| 段 | 回答的问题 | 例子 |
|---|---|---|
| **主体** | 画什么？谁在做什么？ | 一瓶琥珀色的威士忌放在深色木桌上，旁边有一块正在融化的冰 |
| **风格** | 什么调性？像什么？ | 高端酒类广告摄影，暗调，胶片质感 |
| **镜头** | 怎么拍？ | 微距，浅景深，f/1.8，平视 |
| **光影** | 光从哪来？什么质感？ | 侧逆光，一束硬光穿过瓶身，背景压暗 |
| **参数** | 技术规格 | 竖版 9:16，高细节 |

完整拼起来：

```
一瓶琥珀色威士忌放在深色木桌上，旁边一块正在融化的冰，
高端酒类广告摄影，暗调，胶片质感，
微距镜头，浅景深，f/1.8，平视机位，
侧逆光，一束硬光穿过瓶身在桌面投下琥珀色光斑，背景压暗，
竖版 9:16，高细节
```

## 每一段怎么写

### 主体：具体，且只描述"能看见的东西"

这是最容易写错的一段。两个原则：

**一、写视觉，不写概念。**

| ❌ 概念 | ✅ 视觉 |
|---|---|
| 温馨的家庭氛围 | 三个人围坐在铺着格纹桌布的餐桌旁，桌上有热汤冒着白汽 |
| 高端大气 | 大理石台面，金属反光，大量留白 |
| 年轻活力 | 穿亮橙色卫衣的人跳起来，头发甩起 |

模型不理解"温馨"，它理解"热汤冒白汽"。**每次你想写形容词的时候，问自己：这个形容词对应的画面是什么？**写那个画面。

**二、控制数量。**

一个画面里写超过三个主要元素，模型会开始丢东西或者把它们糊在一起。想要复杂场景，宁可拆成多张图后期合成。

### 风格：给参照物比给形容词有效

"有质感"没有信息量。有效的写法是给出可对标的**类别**：

```
高端汽车广告摄影 / 北欧极简产品摄影 / 90 年代胶片人像 /
杂志内页编辑摄影 / 电商白底商品图 / 纪录片纪实风格
```

这些词在训练数据里对应大量一致的视觉特征，模型能准确响应。

::: warning 关于模仿具体摄影师或品牌
用在世艺术家或摄影师的名字来指定风格，在多数商业场景下有法律和伦理风险，部分平台的使用条款也明确禁止。**商用项目请用风格类别描述（"暗调静物摄影"），不要用人名。**这不只是合规问题——描述风格特征本身也比蹭名字更可控。
:::

### 镜头：三个关键词就够

- **焦段**：`微距 macro`（产品细节）/ `35mm`（自然视角）/ `85mm 人像`（背景虚化）/ `广角 wide angle`（空间感、有畸变）
- **景深**：`浅景深 shallow depth of field`（虚化背景，显贵）/ `全景深 deep focus`（都清楚，显平）
- **机位**：见 [分镜设计](/method/storyboard) 的机位表

产品广告最常用的组合：**微距 + 浅景深 + 平视或微俯**。

### 光影：质感的主要来源

**这一段最值钱。**同样的主体、同样的风格，光写得好和不写，出来的东西差一个档次。

不写光的后果：模型给你平光，画面像证件照。

最通用的三个写法：

```
侧逆光，主体边缘有一圈亮边，背景压暗
柔和的窗户光从左侧打来，右侧有自然的暗部
黄金时刻的低角度阳光，暖色，长投影
```

### 参数：按平台需求填

- **比例**：`9:16` 竖屏 / `1:1` 方图 / `16:9` 横屏 / `4:5` 社媒
- **质量**：`高细节 highly detailed` / `8K`（不同模型的响应差异很大）
- **负向词**：多数工具支持排除项，产品图常排除 `文字、水印、变形的手、多余的肢体`

::: warning 参数写法因工具而异
具体的参数语法（`--ar 9:16` 还是下拉菜单）、支持哪些参数、上限是多少，各家不同且更新频繁。**以官网为准。**这里给的是"该控制哪些维度"，不是"该敲哪些字符"。
:::

## 视频 Prompt 的差异

视频比图像多一个维度：**时间**。所以五段式要扩成六段：

```
[主体] + [动作] + [风格] + [镜头与运镜] + [光影] + [参数]
```

多出来的**动作**段，有三条规则：

**一、一个镜头只写一个动作。**

> ❌ 她拿起杯子，喝了一口，然后转身走向窗边，推开窗户
> ✅ 她缓慢地拿起杯子送到嘴边

写复合动作，模型会做出诡异的动作混合体。想要连续动作，拆成多个镜头。

**二、动作要慢。**

AI 视频在快速运动上表现很差——肢体会扭曲、物体会变形。**主动写 `缓慢地 slowly`、`轻微地 subtly`。**大幅动作是当前技术的软肋，绕过它。

**三、运镜也只给一个。**

`缓慢推近`可以，`先推近再左移然后上摇`不行。

## 一个实用技巧：把风格段固定下来

做一个项目时，把**风格 + 光影 + 参数**三段写成一个固定的"风格包"，存下来：

```
【本项目风格包】
高端食品广告摄影，暖色调，轻微胶片颗粒，
侧逆光，柔和的轮廓光，背景自然虚化压暗，
竖版 9:16，高细节，无文字
```

之后每个镜头的 Prompt = 主体和动作（每次改）+ 风格包（原样粘贴）。

这是控制跨镜头一致性最简单有效的办法。风格包中途改一个词，整组素材的调性就会飘。

## 调试思路：出图不对时改哪一段

| 症状 | 大概率是哪一段的问题 |
|---|---|
| 画面内容不对，缺东西 | 主体：元素太多，或用了概念词 |
| 内容对，但很廉价 | 光影：没写光，或写了顺光 |
| 很好看，但不是这个调性 | 风格：参照类别给错了 |
| 太平、没重点 | 镜头：没写景深，或景别不对 |
| 视频里动作扭曲 | 动作：写得太快、太复杂 |

**一次只改一段。**同时改三段，出来的结果不知道是哪一处起了作用，等于没调试。
