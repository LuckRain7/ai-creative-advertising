# Prompt 模板库

这个板块的东西是拿来**抄**的，不是拿来读的。

## 统一格式

每条 Prompt 都按四段呈现：

| 段落 | 内容 |
|---|---|
| **适用场景** | 什么情况下用这条，什么情况下别用 |
| **可复制 Prompt** | 代码块，直接复制，方括号 `[]` 处替换成你的内容 |
| **参数说明** | 每个关键词在控制什么，想调整效果该动哪一处 |
| **常见翻车点** | 已知会出问题的地方，以及绕过去的办法 |

## 一条重要提醒

::: warning 别把 Prompt 当咒语
同一条 Prompt 在不同模型、不同版本上的表现差异很大。这里给的是**结构和思路**，不是保证出片的魔法字符串。

正确的用法：理解每一段在控制什么，然后按你的需求改写。照抄不改，效果通常一般——因为它没写你的产品。
:::
