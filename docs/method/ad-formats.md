# 片型图谱：这支片子该长什么样

Big Idea 决定**说什么**，片型决定**用什么容器装**。容器错了，再好的内容也会漏出来。

这一篇是通用的片型查表。想看它在一个具体产品上怎么用，读 [案例 04 附 · 片型可行性分析](/cases/case-04-fries-crisp-formats)——那篇是本篇方法的一次完整落地。

## 它在链路里的位置

```
拆 brief  →  片型可行性  →  找洞察  →  定 Big Idea  →  分镜  →  生成
             ↑
        这一步经常被跳过
```

跳过的后果是：想了一个很漂亮的创意，做到分镜阶段才发现这个形态根本承载不了它，或者合规上根本不能做。

::: tip 一句话
**片型不是选出来的，是被产品条件排除到只剩一两个的。**
:::

## ① 十一种片型速查

| 片型 | 核心是什么 | 典型时长 | AI 适配 |
|---|---|---|---|
| **产品演示片** | 卖点直给，功能可视化 | 15–30s | ★★★★☆ |
| **感官 / ASMR 片** | 放大质感与声音，不讲道理 | 6–15s | ★★★★★ |
| **工艺解构片** | 把看不见的过程视觉化 | 15–45s | ★★★★★ |
| **视觉奇观 / 概念片** | 超现实、变形、不可能的物理 | 15–30s | ★★★★★ |
| **情景短剧** | 用小故事包装使用场景 | 15–60s | ★★★☆☆ |
| **悬念反转片** | 前 3 秒制造疑问，结尾揭晓 | 15–30s | ★★★☆☆ |
| **UGC / 素人分享** | 刻意不精致，换真实感 | 15–30s | ★★★☆☆ |
| **信息型（动态海报 / 清单）** | 不叙事，只做信息密度 | 静态–10s | ★★★★☆ |
| **品牌情感故事片** | 讲价值观，不讲产品 | 60s–3min | ★★☆☆☆ |
| **代言人口播 / 达人测评** | 靠人的可信度背书 | 15–60s | ★☆☆☆☆ |
| **对比片** | 前后对比、同类对比 | 15–30s | ✕ 合规 |

星级是**用 AI 做这一类的相对优势**，不是这一类本身的好坏。对比片的 ✕ 与技术无关，见 ④。

## ② 逐类展开

### A 组 · 产品本体类

镜头里只有产品，没有人。**AI 在这一组的优势最大**——不用处理人脸、口型、表演。

| 片型 | 适合什么产品 | 决定成败的一步 | 常见翻车 |
|---|---|---|---|
| **产品演示** | 功能有可视差异的（清洁、收纳、工具） | 找到那个「一看就懂」的动作 | 把说明书拍成视频，信息全但没人看 |
| **感官 / ASMR** | 食品、饮料、美妆、纺织 | 声音设计，不是画面 | 只做画面不做声音，质感立刻掉一半 |
| **工艺解构** | 差异化在制程里的（食品工艺、材料、芯片） | 找到实拍不到的那个核心画面 | 从展示做法滑向宣称好处，踩合规红线 |

::: tip 感官片的一个硬规矩
音效不是「配」的，是「拍」的。碰撞声、断裂声、咀嚼声，每一条要单独设计。参考 [案例 03 · 快餐薯条社媒短视频](/cases/case-03-fries-social)。
:::

### B 组 · 人出镜类

**这一组是 AI 目前最弱的一环。**真人表演、口型同步、微表情——生成模型在这三件事上还没到能交付的水平。

| 片型 | 靠什么起效 | 用 AI 做的风险 |
|---|---|---|
| **代言人口播** | 权威感、颜值、信任转移 | 口型对不上、微表情僵硬，观众第一眼就出戏 |
| **达人测评** | 「他跟我一样」的同侪信任 | 一旦被看出是 AI，真实感归零，反噬品牌 |
| **UGC / 素人分享** | 粗糙感本身就是可信度 | 相对可做——因为观众对画质的容忍度高 |

::: warning 客户坚持要真人怎么办
**这一类不要用 AI 做。**真人出镜的内容找真人拍，成本反而更低、风险更小。

硬用 AI 做真人口播，是拿自己的短板去打别人的长板。能力边界要诚实划出来。相关限制见 [人物代言](/prompts/spokesperson)、[UGC 仿真风](/prompts/ugc-style)。
:::

### C 组 · 叙事类

有起承转合，考验的是结构不是画面。

| 片型 | 结构 | 门槛在哪 |
|---|---|---|
| **情景短剧** | 场景 → 冲突 → 产品介入 → 解决 | 人物一致性。同一个角色跨镜头会漂 |
| **悬念反转片** | 疑问 → 铺垫 → 揭晓 | 前 3 秒。竖屏信息流里，铺垫没人等 |
| **品牌情感故事片** | 情绪线，产品只在结尾出现 | 体量与阶段。没有品牌资产时做，是在正确的事上抢错时机 |

::: tip 人物一致性的规避办法
不要追求「让 AI 生成一个稳定的角色」，要**把镜头拆到不需要稳定**：背影、手部、局部、快切。改结构比调模型省一个数量级的时间。做法见 [分镜设计](/method/storyboard)。
:::

### D 组 · 其他

| 片型 | 什么时候用 | 注意 |
|---|---|---|
| **视觉奇观 / 概念片** | 产品本身没什么可拍，靠概念取胜 | AI 在这一类的优势是**碾压性**的，因为实拍根本做不出来 |
| **信息型** | 电商详情页、促销节点、榜单 | 不要硬加叙事。它的任务是信息密度不是打动人 |
| **对比片** | ——见下 | 直接对比同类产品有明确法律风险 |

## ③ 创意手法（与片型正交）

片型是容器，手法是装进去的东西。**同一个片型可以用任何一种手法**，不要把这两层混在一起讨论。

| 手法 | 做法 | 风险 |
|---|---|---|
| **夸张放大** | 把一个特性推到荒谬 | 过头会显得假，反而削弱可信度 |
| **类比 / 隐喻** | 用熟悉的解释陌生的 | 类比选错，观众记住喻体忘了产品 |
| **反差与反转** | 先建立预期再打破 | 反转太弱等于没有 |
| **拟人化** | 让产品或抽象概念开口 | 容易滑向幼稚 |
| **问题—解决** | 最古老也最稳的结构 | 也最像广告，观众防备心最高 |
| **幽默 / 自嘲** | 降低防备心 | 品牌调性要撑得住，严肃品类别碰 |
| **重复洗脑** | 牺牲好感度换记忆度 | 效果真实存在，但会消耗品牌资产 |
| **悬念** | 把答案往后放 | 赌观众看完，竖屏里赢面小 |
| **情绪共鸣** | 不说产品，说人的处境 | 共鸣不准就是自我感动 |
| **借势 / 热梗** | 蹭现成的注意力 | 保质期以周计，用完即弃 |

选手法的时候回头看一眼 [Big Idea 的判断清单](/method/big-idea)——手法是为洞察服务的，不是拿来凑数的。

## ④ AI 让性价比排序重新洗牌

这是本篇最需要更新旧经验的一节。

| 片型 | 五年前 | 现在 | 为什么变 |
|---|---|---|---|
| **工艺解构片** | 最贵之一 | 最便宜之一 | 过去要进车间实拍或做三维动画；现在生成就行 |
| **视觉奇观片** | 最贵 | 便宜 | 特效成本坍塌 |
| **品牌情感故事片** | 贵 | 仍然贵 | 贵在剧本和表演，AI 省不掉 |
| **代言人口播** | 便宜 | 仍然便宜（找真人） | AI 做反而更贵——返工次数不可控 |

::: warning 不要沿用旧的片型性价比直觉
「工艺片太贵，我们做不起」这句话在今天已经不成立。成本结构变了，**哪个片型划算这件事必须重新评估一遍**，不能凭经验排序。
:::

### 合规是筛子，不是最后一道检查

对比片被否掉，与创意质量和技术能力都无关。直接对比同类产品容易构成**贬低同类**，在广告法下有明确风险。

```
普通项目：  想创意 → 选片型 → 做出来 → 法务检查 → 小改
高敏品类：  合规边界 → 排除片型 → 在剩下的里想创意 → 法务复核
```

食品功效、医疗、金融、化妆品功效——这些品类必须走第二条路。放在最后检查，被砍掉的不是文案，是整支片子。

::: tip 对比片的替代方案
只展示自己，不出现任何参照物。**观众自己脑补的对比，比你摆在屏幕上的更有说服力。**
:::

## ⑤ 怎么选：排除法四步

不要头脑风暴各种可能性，要做减法。

**第一步：列产品硬条件。**每一条都会否掉某些片型。

| 维度 | 要问的问题 |
|---|---|
| 差异化在哪 | 感官？工艺？功能？价格？——决定内容有没有得讲 |
| 核心画面能不能实拍 | 实拍不到的，正是 AI 的机会 |
| 客单价与体量 | 决定制作预算的天花板 |
| 合规敏感度 | 高敏品类先划红线 |
| 品牌阶段 | 新品讲「为什么值得买」，成熟品牌才讲价值观 |

**第二步：用合规砍一遍。**先砍，别等做完。

**第三步：在剩下的里按投放场景挑。**

| 投放场景 | 要什么 | 优先片型 |
|---|---|---|
| 电商详情页 | 说服 | 工艺解构、产品演示、信息型 |
| 短视频信息流 | 3 秒抓人 | 感官 ASMR、悬念反转、UGC |
| 品牌官宣 / 发布会 | 调性 | 视觉奇观、品牌情感故事 |
| 私域 / 社群 | 可信 | UGC、达人测评 |

**第四步：剩下不止一个？做组合拳。**

::: tip 组合拳共用素材
一支工艺解构片 + 一支感官短片，可以共用同一批生成素材，只是剪辑取向不同。**成本增量远小于两支片子。**

典型分工：感官片负责在信息流里拦人，工艺片负责在详情页里说服。案例 04 走的就是这个组合。
:::

## 三个常见误区

**误区一：按「哪个片型看起来高级」排序。**
片型没有高低，只有匹不匹配。品牌情感故事片放在一个新品上，是浪费。

**误区二：先想创意再挑片型。**
顺序反了。创意得在容器里长，容器定了创意才有边界——**没有边界的创意想不完，也落不了地。**

**误区三：把 AI 的短板硬扛过去。**
人出镜类扛不过去。与其花三天调口型，不如换片型或者找真人。
