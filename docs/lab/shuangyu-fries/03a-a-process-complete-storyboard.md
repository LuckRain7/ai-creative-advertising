## 本轮反馈

> 客户看过 A 片 demo 后提出：注意制作细节、节奏调整与制作完整性，重点体现**真空、低温、油炸、脱水、脱脂**。

这条反馈不是局部精修意见，而是叙事重心调整：v1 以「原薯鲜切 → 脆」为主，工艺藏在中段；v2 改为让观众完整看懂 VF 工艺，再用成品断面与咔嚓声收束结果。

::: warning 「脱脂」的执行口径
客户原话保留为「脱脂」，但成片字幕使用 **「离心脱油」**。

「离心脱油」描述可见工序；「脱脂」容易被理解为脂肪含量声称。除非客户补充本产品工艺确认与检测依据，不使用「低脂」「脱脂更彻底」等结果性表述。
:::

## 修订原则

1. **五个信息点逐一落地**：真空、低温、油炸、脱水、离心脱油各有独立画面和字幕节拍，不再只靠一个真空舱镜头带过。
2. **先环境、再作用、后结果**：舱门闭合建立真空环境；安静油面表现低温油炸；剖面水汽逸出表现脱水；离心油滴表现脱油；多孔断面与咔嚓声验证结果。
3. **字幕只做后期**：生成画面不带字、不生成仪表数字。温度数字在本产品参数确认前不出现，仅写「低温」。
4. **完整不等于塞满**：五个工艺词每个至少停留 1 秒；工艺段占全片 12.2 秒，约 61%。

## 10 镜导演分镜（列表版）

> 本节按导演执行口径将上表的剪辑镜头 2、3 合并为一个连续运镜，因此是 **10 个导演镜头、11 个剪辑落点**。总时长仍为 20 秒。

1. **镜头 01 · 原薯鲜切｜00:00–00:01.8｜1.8s**

   **景别 / 镜头**：100mm 微距，平视略俯，固定机位，结尾轻微向切面推进。**画面调度**：去皮马铃薯占画面左中部，刀刃从右上方切下最后一刀；切面露出淀粉汁水，三四根粗薯条落入前景。**光影**：右后方硬质侧逆光勾边，顶部柔光提亮湿润切面，背景压暗。**剪辑**：刀刃触底的瞬间切入下一镜舱门闭合，利用金属碰撞声做声音匹配。**字幕 / 声音**：左下角「原薯鲜切」；一下清脆切入声、薯条落板轻响。**验收**：薯条完全不带皮，边缘有自然毛刺，不出现薯片、细薯条或机械压模般的光滑边缘。

2. **镜头 02 · 建立真空｜00:01.8–00:04.8｜3.0s**

   **景别 / 镜头**：35mm 中近景起，稳定器沿设备外壳向右缓慢横移，最后落到 85mm 压力表特写。**画面调度**：圆形观察窗舱门闭合，两个金属锁扣压紧；镜头沿抽气管路移动，管路轻微震动，终点压力表指针平稳回落，表盘数字虚化不可读。**光影**：设备外部冷白工业光，观察窗内部只留一层暖黄微光。**剪辑**：横移末端直接切到观察窗内的平静油面。**字幕 / 声音**：先「真空」，镜头经过管路时替换为「真空环境」；舱门闷响、两下锁扣声、低频抽气嗡鸣。**验收**：密闭、抽气、压力变化三个信息必须都能读懂；设备不科幻，表盘不出现乱码参数。

3. **镜头 03 · 低温状态｜00:04.8–00:06.2｜1.4s**

   **景别 / 镜头**：85mm 中特写，透过同一圆形观察窗平视舱内，极慢推近。**画面调度**：浅金色油面占画面下三分之二，粗马铃薯条刚浸入油中，画面近乎静止，只允许零星微小气泡。**光影**：舱内单一暖黄顶光，四周快速衰减成暗部；油体清澈、无油烟。**剪辑**：以第一颗小气泡上升为动作点切入油炸特写。**字幕 / 声音**：左下角「低温」；抽气声渐弱，留出近乎安静的半拍。**验收**：油面不翻滚、无大量白泡，且画面必须明确是油，不拍成水煮或空气炸锅。

4. **镜头 04 · 真空油炸｜00:06.2–00:08.6｜2.4s**

   **景别 / 镜头**：100mm 微距，由薯条表面平移至油面，焦点跟随一组上升气泡。**画面调度**：薯条完全浸在清澈食用油中，细密小气泡从表面缓慢析出并在油面破裂；薯条颜色从乳白微黄轻微转为浅金。**光影**：暖黄透射光照亮油体，薯条边缘有柔和金色轮廓，背景深黑。**剪辑**：一颗气泡破裂后硬切至薯条剖面内部。**字幕 / 声音**：左下角「油炸」；细微气泡声，机械底噪保持。**验收**：必须同时证明「浸在油里」与「过程安静」，不能以健康感为由回避油炸事实。

5. **镜头 05 · 真空脱水｜00:08.6–00:11.2｜2.6s**

   **景别 / 镜头**：科学摄影式极致微距，薯条纵向剖面正对镜头，机位锁死，极缓慢推进。**画面调度**：同一剖面从致密湿润开始；细小透明水汽由中心沿组织间隙向外逸出，水分离开的位置逐渐形成相互连通的孔洞。**光影**：内部柔和透光，孔壁边缘随着脱水过程逐步被点亮。**剪辑**：孔洞完全形成时，以圆形孔洞匹配离心筒滤孔切入下一镜。**字幕 / 声音**：左下角「脱水」；轻微水汽逸出声，不做爆裂音效。**验收**：顺序必须是水分离开在先、孔洞形成在后；主体、机位与构图全程不跳。

6. **镜头 06 · 离心脱油｜00:11.2–00:13.8｜2.6s**

   **景别 / 镜头**：50mm 略俯中景起，跟随旋转方向小幅环绕，末尾切 100mm 油滴特写。**画面调度**：不锈钢内筒从慢到快旋转，浅金色粗薯条贴向滤孔筒壁；透明暖金油滴径向甩出，穿过滤孔进入外侧环形集油槽。**光影**：冷白工业顶光打出金属硬反光，油滴由一条窄暖光勾亮。**剪辑**：机械声到达最高点后骤停，硬切到纯黑背景的成品断面。**字幕 / 声音**：左下角「离心脱油」；机械加速声、少量油滴落槽声。**验收**：完整呈现「旋转 → 油滴离开 → 进入集油槽」，油滴不能变成水花、粉末或碎屑。

7. **镜头 07 · 多孔结果｜00:13.8–00:15.3｜1.5s**

   **景别 / 镜头**：100mm 微距，正面平视断面，固定机位，只做 3% 数字推近。**画面调度**：一根浅金色薯条脆竖立，断面居中；后方强光由弱到强，蜂窝状孔洞边缘依次点亮，表面细小红色调味颗粒可见。**光影**：纯黑背景，强逆光穿透断面，侧面微弱补光保持外轮廓。**剪辑**：逆光达到峰值时切到两根指尖夹住同一根薯条。**字幕 / 声音**：左下角「疏松多孔」；机械声消失，整镜留白。**验收**：浅金、干爽、孔洞真实；不能像海绵、泡沫塑料或普通炸薯条。

8. **镜头 08 · 咔嚓验证｜00:15.3–00:17.1｜1.8s**

   **景别 / 镜头**：100mm 微距，平视固定，高速摄影质感。**画面调度**：画面只进入两根指尖，夹住薯条两端；薯条在画面中心干净断裂，参差断口朝镜头，细小碎屑横向飞散。**光影**：侧硬光切出明暗交界，并照亮飞散碎屑；背景深色虚化。**剪辑**：断裂后保留 6–8 帧，让观众看清断面，再切成品落下。**字幕 / 声音**：断裂声后出现单字「脆」；全片最响的一声清脆「咔嚓」。**验收**：无多指、断指和关节异常；手部失败时改为机械夹具或无人自然折断版本。

9. **镜头 09 · 成品质感｜00:17.1–00:18.2｜1.1s**

   **景别 / 镜头**：85mm 特写，略俯，镜头缓慢后拉。**画面调度**：几根浅金色粗薯条脆从上方落到深色石质台面，轻微碰撞堆叠；红色调味颗粒和干爽哑光表面清晰。**光影**：柔和顶光负责食物色泽，右侧硬光勾边，背景压暗。**剪辑**：其中一根薯条落定后，以相同位置匹配包装落版。**字幕 / 声音**：无字幕；干爽沙沙声与两下轻脆碰撞声。**验收**：颜色浅金而非深褐，表面无浮油，产品形状与参考图一致。

10. **镜头 10 · 真实包装落版｜00:18.2–00:20.0｜1.8s**

    **景别 / 镜头**：50mm 中景，正面平视，后期做 2% 缓慢推近。**画面调度**：真实包装资产立于画面中右侧，左前景保留少量真实外观薯条脆，主标题位在左上；包装自身不发生形变。**光影**：左上 45 度柔和主光，右侧窄轮廓光，台面有克制的暖色光斑。**剪辑**：最后 12 帧全部稳定，留给品牌识别。**字幕 / 声音**：「原薯鲜切 · 脆得有依据」；音乐收束，尾音干净。**验收**：包装与 logo 只用客户真实资产，文字像素级不变，不刻意突出日文副标。

## 五个重点如何被看懂

| 客户要求 | 视觉证据 | 不能只靠什么 |
|---|---|---|
| **真空** | 舱门锁闭 + 抽气管路 + 压力指针回落 | 只拍一个金属容器，观众不会自动理解为真空 |
| **低温** | 平静油面、少量细密气泡、浅金色成品 + 独立字幕 | 不能生成不可核验的温度数字 |
| **油炸** | 薯条明确浸入清澈食用油，气泡从表面产生 | 不能为了显得健康而回避「油」 |
| **脱水** | 水汽从内部逸出，致密组织转为多孔结构 | 只给最终孔洞，缺少过程就不完整 |
| **离心脱油** | 旋转、油滴离开薯条、油滴进入集油区域 | 只拍机器旋转，无法证明甩出去的是油 |

## 制作细节与连续性

### 设备连续

- 镜头 2–7 使用同一套哑光不锈钢设备语言：圆形观察窗、冷白外部工业光、暖黄舱内光。
- 不出现实验室玻璃器皿、科幻蓝光、无功能装饰管线；设备不能在相邻镜头中改变结构。
- 真空表只表现指针运动，数字与刻度不可读，避免模型生成错误参数。

### 产品连续

- 鲜薯条从乳白微黄逐步变为浅金色，不能瞬间变深褐。
- 形状始终为较粗长条，边缘有自然毛刺；不变成细薯条、薯角或薯片。
- 镜头 8–10 统一带细小红色番茄调味颗粒，表面干爽、无浮油。

### 动作连续

- 镜头 4 与 5 必须先交代「低温」，再明确「油炸」，字幕不能同时砸进画面。
- 镜头 6 的水汽向外运动；镜头 7 的油滴径向向筒壁运动。两种液体运动方向不同，不能混成普通飞溅。
- 工艺段硬切，不用炫技转场。只用声音桥连接：抽气嗡鸣 → 气泡 → 水汽 → 离心加速。

## 字幕节奏

工艺关键词统一左下角出现，白字、无描边、每词停留 1.0–1.4 秒；使用同一字号与入场方式。只在关键词切换时做 4–6 帧淡入，不使用逐字蹦出或故障特效。

```
真空 → 低温 → 油炸 → 脱水 → 离心脱油
```

::: danger 成片红线
不出现：非油炸、更健康、低脂、0 负担、无油、不含丙烯酰胺、与传统油炸的直接对比。

若客户坚持字幕必须写「脱脂」，先请其书面确认具体工序与表述依据，再交合规审校；在此之前以「离心脱油」执行。
:::

- [ ] 五个工艺信息点均有独立画面和独立字幕节拍
- [ ] 真空油炸段无剧烈翻滚、无大量白色泡沫

- [ ] 脱水镜头能看见水分离开，而不只是出现孔洞

| 项 | 本轮反馈带来的状态 | 成片处理 |
