## A1 · 原薯鲜切

```
16:9，高端食品广告微距摄影，接近纪录片的真实质感，暖调，
轻微胶片颗粒，自然食物色彩，不过度锐化、不过度饱和，商业级布光。

同一个连续动作：一颗已经去皮的新鲜马铃薯放在深色胡桃木案板上，
厚背主厨刀干净地切下最后一刀，露出湿润、乳白微黄的切面和少量淀粉汁水；
几根切好的粗马铃薯条随即慢动作落下，完全不带皮，
边缘有真实鲜切形成的自然毛刺与轻微不规则棱角。

微距，浅景深，侧逆光勾出湿润切面，镜头固定，不切换场景。
音效：一下清脆切入声，随后是薯条落下的轻响。

不出现文字、数字、logo、品牌、包装、中文或日文；
不出现细薯条、薯片、薯角，不出现深褐色和油光，不卡通，无3D渲染感。
```

**验收**：只要「切开 → 落下」两个动作；薯条不带皮、边缘有毛刺。镜头被塞入去皮过程或多次切割，重跑。

16:9，高端食品广告片，写实工业纪录片质感，
哑光不锈钢设备，外部冷白工业光，内部暖黄微光，商业级布光。

一台食品加工用真空低温油炸设备，圆形厚玻璃观察窗，
舱门缓慢闭合，金属锁扣依次压紧；透过观察窗可见粗马铃薯条静止在舱内。

机械压力表的指针平稳向低压方向回落，表盘刻度虚化、没有可读数字。
舱门密封圈轻微收紧，明确表现密闭空间正在抽成真空。

35mm 中近景起，稳定器横移并逐渐收紧至 85mm 压力表特写，动作稳、慢，设备结构前后一致。

## A3 · 低温油炸

```
16:9，高端食品广告微距摄影，接近纪录片的真实质感，暖调，
轻微胶片颗粒，自然食物色彩，不过度锐化、不过度饱和，商业级布光。

延续上一段同一台哑光不锈钢真空设备，从圆形观察窗进入舱内视角。
清澈的浅金色食用油油面近乎完全平静，
粗马铃薯条明确浸在油中，只有极细密的小气泡从薯条表面缓慢上升并破裂，
气泡数量少、速度慢；薯条从乳白微黄缓慢变成浅金色。
这是低温条件下的真空油炸，不是水煮，不是空气炸。

中特写，舱内单一暖黄光源，四周暗，镜头极缓慢推近。
音效：持续低频机械嗡鸣，近乎安静，只有细小气泡破裂声。

油面不翻滚，不沸腾，不出现大量白色泡沫；
不出现文字、数字、logo、品牌或包装，不出现深褐色、焦黑和油腻反光，
不卡通，无3D渲染感。
```

**验收**：画面必须同时证明「在油里」和「过程安静」。生成成水煮、空气炸锅或常压沸腾，整条废弃。

## A4 · 真空脱水

```
16:9，高端食品广告微观摄影，真实科学影像与食品广告质感结合，
暖调，轻微胶片颗粒，自然食物色彩，商业级布光。

同一根粗马铃薯条的纵向剖面极致微距，机位与主体始终不变。
开始时内部组织致密、湿润、乳白微黄；
在低压环境中，内部水分形成细小透明水汽，从中心沿细胞间隙持续向外逸出，
水分离开的位置逐渐形成大小不一、相互连通的细密孔洞；
最后内部变为浅金色、疏松多孔结构。变化平缓连续，不爆炸、不碎裂。

极致微距，内部柔和透光，孔洞边缘逐渐被光点亮，镜头缓慢推近。
音效：很轻的水汽逸出声与细小气泡声。

只表现水分向外离开，不出现油滴向内灌入；
不出现文字、数字、logo、品牌、包装，不卡通，无塑料感，无夸张科幻特效。
```

**验收**：起止必须是同一根薯条、同一机位；必须看见「水分离开 → 孔洞形成」的先后关系。只有孔洞变大而没有水分逸出，不通过。

## A5 · 离心脱油

```
16:9，高端食品广告片，写实工业纪录片质感，
与前段相同的哑光不锈钢食品加工设备，冷白工业光，商业级布光。

食品离心机的不锈钢内筒中铺着一层浅金色粗薯条，
内筒从静止平稳加速到高速旋转，薯条贴向带细密滤孔的筒壁；
细小、透明、带暖金反光的油滴从薯条表面径向甩出，
穿过滤孔进入外侧环形集油槽。油滴数量克制，轨迹清晰，
成品表面逐渐由轻微反光变为干爽哑光。

先略俯视中景，再切油滴进入集油槽的微距，旋转方向保持一致。
音效：机械声由慢到快，少量油滴落入金属槽的轻响。

甩出的是油滴，不是水花、粉末或碎屑；薯条不能飞出机器、不能被打碎；
不出现文字、数字、logo、品牌或包装，不卡通，无科幻蓝光，无3D渲染感。
```

**验收**：需完整看见「旋转 → 油滴离开产品 → 进入集油槽」；只有机器旋转不算完成。产品变形或大量飞散，重跑。

## A6 · 工艺结果

```
16:9，高端食品广告微距摄影，接近纪录片的真实质感，暖调，
轻微胶片颗粒，自然食物色彩，不过度锐化、不过度饱和，商业级布光。

纯黑背景，一根浅金色粗薯条脆的断面朝向镜头，
表面带细小红色番茄调味颗粒，干爽哑光、无油光。
强逆光逐渐增强，点亮断面内部疏松多孔的蜂窝结构；
随后只入画两根指尖，将同一根薯条脆干净掰断，
参差断口和多孔结构清晰，一声咔嚓，细小干爽碎屑慢动作飞散。
最后几根同样的薯条脆落在深色石质台面上，镜头拉远，右侧留出干净空位。

极致微距转特写，浅景深，强逆光与侧硬光，动作顺序严格不变。
音效：短暂安静，一声全片最响的清脆咔嚓，随后是干爽沙沙声。

不出现文字、数字、logo、品牌或包装；
不出现深褐色、焦黑、浮油和油腻反光，不出现完整手掌或多余手指，
不卡通，无3D渲染感。
```

**验收**：先断面透光、再掰断、最后成品落下；顺序错误不要靠倒放补救。手指出错时改跑「薯条脆自行折断」版本。
