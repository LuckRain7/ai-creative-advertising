# 03g · 蜂蜜黄油味「声纹测试」互动感官片

> 阶段 3 · 当前推荐导演执行稿 ｜ 2026-08-15 ｜ 12 秒 / 9:16 竖屏 / TikTok、抖音信息流

## 结论先行

不再把「感官片」理解为光带、微粒、升格断裂与包装落版的组合，而是把整支片做成一道观众可以立即参加的**声音选择题**：

> **不看答案，你能听出哪一声是蜂蜜黄油味吗？**

同一款薯条脆用三种方式发声：单根折断、双根同时折断、真实咬下。观众先选 A / B / C，影片再揭晓：

> **答案：都是。**
>
> **味道听不见，脆可以。**

形式本身就是产品证据。观众为了作答会主动打开声音、比较、重播和评论，不需要先看完一段广告才收到卖点。

## 互动规则

观众不需要学习玩法。第一帧同时给出问题和产品口味，随后按固定节拍听三声：

| 选项 | 动作 | 声音性格 | 视觉职责 |
|---|---|---|---|
| **A** | 单根薯条脆从中央折断 | 短、亮、清晰 | 建立第一份「脆」证据 |
| **B** | 两根薯条脆同时折断 | 更厚、更密、带碎裂层次 | 与 A 形成可比较差异 |
| **C** | 真人近距离咬下一口 | 低频更完整、最接近真实食用体验 | 把测试从实验转回「想吃」 |

三声必须都来自同一批真实产品。差异只来自动作、数量与录音距离，不使用三个无关的库存音效伪装盲测。

## 分镜执行

### 镜头 01 · 出题

**优先方式：真实包装与真实产品实拍。**

- 机位：手机等效 35–50mm，正面略俯视，固定机位。
- 构图：产品杯只露出正面可读区域与杯口，避免把开场拍成传统完整落版。
- 光线：窗边自然柔光或大面积柔光箱；保留轻微桌面环境，不做纯黑棚拍。
- 动作：无。开头必须稳定，让观众在 0.9 秒内读完问题。
- 后期：问题文字直接叠加，不模拟或伪造用户评论。

### 镜头 02 · A 声纹 / 单根折断

- 使用真实样品，从同一杯中随机取一根。
- 两枚指尖只进入画面边缘，中央留出完整断裂点。
- 前 0.15 秒保持静止，随后一次完成折断；不要先来回弯折。
- 一次连续拍 8–10 条，选择断口清楚、声音短而亮的一条。
- 若手部画面不稳定，可使用两只小型食品夹具；最终声音仍录真实产品。

### 镜头 03 · B 声纹 / 双根折断

- 两根产品上下平行，间距约一根产品宽度，不能互相遮挡。
- 左右两组手指同时施力，但允许 20–60ms 的自然时间差，形成更丰富的碎裂层。
- 碎屑控制在少量，不追求爆炸效果；台面铺干净烘焙纸便于收音和清理。
- 不复制 A 的声音叠两层。B 必须独立实录。

### 镜头 04 · C 声纹 / 真实咬下

- 必须真人实拍，不用生成模型制作嘴部和咬合。
- 只露下半张脸或侧面局部，避免人物成为主角，也规避跨镜头身份连续性。
- 产品进入口中前停 0.2 秒，咬下后立即离开画面，不做夸张表情。
- 录制至少三种距离：领夹麦、近距离指向麦、环境备份轨；后期选择最真实的一条。

### 镜头 05 · 作答界面

- 波形必须由 A / B / C 的真实录音生成，不能画三条装饰性假波形。
- 三条波形长度、缩放比例一致，避免视觉上提前暗示正确答案。
- A / B / C 使用同一字号、字重与颜色，不给某一选项特殊高亮。
- 停顿至少 1 秒，让观众确实有作答时间。

### 镜头 06 · 声纹 remix

按以下节拍剪辑，不让视频模型一次生成四个动作：

```text
第 1 拍：A 单根断裂，取断裂前后各 4–6 帧
第 2 拍：B 双根断裂，取两根刚刚错开的一刻
第 3 拍：C 咬下，取产品消失在嘴边的瞬间
第 4 拍：C 的声音 + 产品断面超微距，作为最重收束
```

可在第四拍加入一段生成式超微距补镜，但它只能补充质感，不能替代真实产品证据。

### 镜头 07–09 · 揭晓与落版

- 「答案：都是」只出现 0.9 秒，不做综艺式爆炸字效。
- 断面至少清晰保留 0.5 秒，观众需要时间核对声音与结构。
- 包装只使用客户确认的蜂蜜黄油味终稿实拍、渲染图或设计源文件合成。
- 最后一声折断发生在包装旁，但碎屑不能遮挡品牌名和口味名。
- 11.6–12.0 秒的声音尾部与第一帧提示音衔接，形成自然循环。

## 声音录制表

| 声音 | 建议收音 | 录制要求 | 后期处理 |
|---|---|---|---|
| A · 单根折断 | 小振膜电容麦或指向麦，距断点 10–15cm | 连录 8–10 次，保留完整起音和碎屑落下 | 轻微去除低频环境噪声，不扩展混响 |
| B · 双根折断 | 同一支麦、同一增益，距断点 15–20cm | 独立录制，不复制 A；允许自然微时差 | 只做轻微峰值控制，保留两层结构 |
| C · 真实咬下 | 领夹麦 + 指向麦双轨 | 避免呼吸、吞咽和嘴部黏声盖过咔嚓 | 选择自然脆响，删除令人不适的口腔细节 |
| 调味颗粒 | 近距离录制少量粉末落在烘焙纸上 | 只用于 remix 的高频装饰 | 音量必须低于主咔嚓 |
| 杯体声音 | 真实产品轻放桌面 | 不敲杯、不制造塑料空响 | 只保留落版的轻接触声 |

::: danger 不使用通用薯片音效
本片的可信度来自「看到的动作」与「听到的声音」严格同步。库存音效即使更响、更爽，也会让三种声纹失去测试意义。所有主声音必须实录，并保留原始文件备查。
:::

## 字幕与版式

| 元素 | 规则 |
|---|---|
| 主问题 | 两行以内，第一帧完整出现，不逐字动画 |
| A / B / C | 固定在画面左上安全区；位置、字号、颜色完全一致 |
| 波形 | 使用真实音频生成；线条清楚，不做霓虹、金属或游戏血条效果 |
| 答案 | 只写「答案：都是。」不补解释性小字 |

主色为奶油白、自然浅金与少量黑色；A / B / C 可用三种低饱和辅助色区分，但产品颜色始终保持真实。字体选择清楚、年轻但不过度潮流化的无衬线体，不使用综艺花字。

## 实拍、生成与后期分工

| 内容 | 方式 | 原因 |
|---|---|---|
| A / B / C 三次动作 | **真实样品实拍** | 声画同步是整支片的成立条件 |
| 三次主声音 | **真实样品实录** | 不能用库存音效替代产品证据 |
| 真人咬食 | **真人局部实拍** | 生成嘴部与咬合既不稳定，也不可信 |
| 产品表面与断面 | 实拍优先；生成只补微距 | 实拍负责证据，生成负责实拍拍不到的景深和运动 |
| 波形、选项、答案 | 后期动效 | 保证信息准确、节拍可控 |
| 最终包装 | 实拍或终稿资产合成 | 保持品牌、文字、杯型与口味信息准确 |

## 发布与续拍机制

### 首发文案

```text
先选 A / B / C，再看到答案。
蜂蜜黄油味，哪一声最像它？
```

### 评论原则

- 首发片不伪造用户头像、评论内容、点赞数或消费者评价。
- 品牌可以在置顶评论里继续提问：「下一次想听一根、两根还是三根？」
- 只有真实评论出现后，才使用平台的「回复评论」功能制作后续片。
- 评论区出现「像库存音效」「是不是后配的」时，优先发布收音幕后作为证据，不争辩。

### 可续拍的四条内容

| # | 形式 | 内容 |
|---:|---|---|
| 1 | 评论回复 | 按真实高赞评论要求，把麦克风再靠近或移远重录一次 |
| 2 | 声纹加量 | 一根、两根、三根同时折断，观众继续选最喜欢的一声 |
| 3 | 咔嚓采样器 | 折断、咬下、落杯、颗粒四种真实声音组成 6–8 秒节拍 |
| 4 | 收音幕后 | 展示麦克风、真实样品和未经处理的原始声音，证明不是库存音效 |

## A/B 测试

只改变一个变量，其他镜头、声音与投放条件保持一致。

| 版本 | 变量 | 文案 |
|---|---|---|
| A | 问口味身份 | **哪一声是蜂蜜黄油味？** |
| B | 问主观偏好 | **A、B、C，哪一声最解压？** |
| C | 答案出现较早 | 5.5 秒揭晓「都是」 |
| D | 答案出现较晚 | remix 后 8.2 秒才揭晓 |

优先观察 2 秒停留、6 秒播放、完播、重播与每千次播放评论数。不能只用点赞判断：本片最重要的信号是观众是否真的参与选择，以及是否为了比较而重播。

## 内容与合规边界

1. 「蜂蜜黄油味」只作为确认后的口味名出现；在配料表未确认前，不展示蜂巢、蜂蜜罐、真实黄油块，也不表述「真蜂蜜」「真黄油」。
2. 不使用「最脆」「全网最响」等无法证明的绝对化表述。
3. 不伪造消费者评论、测评结论、点赞数或平台热度。
4. 不出现低脂、低卡、无油、0 负担、吃不胖等营养或功效暗示。
5. 最终包装必须使用蜂蜜黄油味终稿物料，不用番茄味包装改色，不让模型自行设计包装。
6. 声音测试只能使用实际交付产品录制；若不同批次质地明显变化，重新录制，不沿用旧样本。
