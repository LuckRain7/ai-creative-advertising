## 证据分级

每条结论后标注来源，避免推演被误当成事实。

| 级 | 含义 | 可否作为决策依据 |
|---|---|---|
| **A** | 包装图上可确认的事实，或客户明确告知 | ✅ 可以 |
| **B** | 品类公开常识，可查证但我方未逐条核实 | 🟡 可作参考，引用前抽查 |
| **C** | 我方假设 | ❌ **须核实后才能用** |

## 一、目标人群

### 1. 先从形态倒推约束

不猜人群，先看产品自己限定了什么。

| 产品事实 | 推出的约束 | 级 |
|---|---|---|
| **46g 单人份** | 一次吃完的量，**不是分享装、不是囤货装** | A |
| **纸杯 + 铝箔 + 塑料盖** | 包材成本明显高于枕式袋，**同克重零售价必然高于袋装薯片** | A → C |
| **杯身可立、可单手持** | 适合桌面、通勤、单手场景；不适合沙发前抓着吃 | A |
| **条状（薯条形态）** | 不掉渣、不碎屑，比薯片更适合办公桌与公共场合 | A |
| **常温预包装、无热气** | 没有「刚出锅」的信息量，食欲感只能靠声音和断面 | A |
| **抖音 + 电商详情页** | 客户口头告知的渠道判断 | A |

::: tip 这几条指向同一件事
**单人、即时、场景化消费，不是家庭零食柜。**

杯装带来的溢价，必须由「场景便利」兑现——不能由「更好吃」或「更健康」兑现，后者一个没有证据、一个不能说。
:::

### 2. 三个候选人群与取舍

| | 人群 | 判断 |
|---|---|---|
| **A** | **18–30 岁都市学生 / 初入职场者**，便利店与零食集合店随手买 | ✅ **建议为核心** |
| **B** | 25–40 岁家庭采购者，为孩子 / 零食柜囤货 | ❌ 排除 |
| **C** | 健康意识型轻食人群，为「低温油炸」买单 | 🟡 承接，但**不能作为传播对象** |

**B 为什么排除**（C 级推演）：46g 杯装的单位克重价格在薯类零食里偏高，囤货客对价格敏感，且杯装占空间、不适合多件囤放。**这个包装形态本身就把囤货客筛掉了**——广告再去够他，两头不讨好。

**C 为什么只能承接、不能喊话**：这群人是最愿意为 VF 付溢价的，但 [提案第三节](./01-proposal) 的内容边界已经写死——「更健康 / 低脂 / 0 负担」一律不能说。

::: tip 承接与喊话的区别
**能被吸引，不能被喊话。**

做法是把工艺展示做扎实（多孔断面、80~90℃、脱油离心），让这群人自己认出来。这与 [案例 04](/cases/case-04-vf-fries-crisp) 的核心结论同源：**你替他下的结论他不信，他自己下的结论他才信。**
:::

### 3. 核心人群画像

> **一个在便利店货架前站了三秒的人。**

以下除标注外均为 **C 级**，待客户校准。

| 维度 | 推演 |
|---|---|
| **年龄** | 18–28，学生 + 工作 1–3 年 |
| **性别倾向** | 略偏女性（杯装、番茄味、可复盖均偏女性偏好），但**不是女性专属产品**，不建议做成女性向调性 |
| **购买场景** | 便利店 / 零食集合店 / 校园超市；线上以尝鲜首单为主，复购靠线下 |
| **消费场景** | 下午三点的工位、自习间隙、通勤路上、宿舍夜聊 |
| **决策依据** | **形态新鲜感 > 口味 > 品牌**。新品无品牌资产可依（A：未上市） |
| **单次决策时间** | 3–5 秒 |
| **反对意见** | 「又是油炸的」「这么小一杯还这么贵」 |

::: warning 决策时间这一条直接支撑了 B 片的结构
3–5 秒的货架决策 = 信息流里 1–2 秒的划走判断。

**这是 B 片必须第一帧就撕封口的真实理由**——不是因为撕封口好看，是因为没有第二次机会。[提案第二节](./01-proposal) 的这条设定，现在有了人群侧的依据。
:::

**两条反对意见分别在哪回答**：

| 反对意见 | 在哪回答 | 备注 |
|---|---|---|
| 「又是油炸的」 | **脱油离心工序** | 工序陈述，不是营养宣称，合规。见 [00-brief 工艺资料裁定](./00-brief) |
| 「这么小还这么贵」 | **广告回答不了** | 这是定价与渠道的问题。片子里试图解决它会变成自证式辩解，反而坐实了「贵」 |

### 4. 一个需要推翻的既有假设

[00-brief](./00-brief) 写过：「可复盖 →『吃不完盖上』是一个真实使用场景」。

**这条在 46g 规格下大概率不成立**（C）。46g 是一次吃完的量，「吃不完」在这个克重上不是高频场景。

可复盖的真实价值更可能是：

- **放进包里不撒**（通勤、上课路上）
- **放在工位上不落灰**（同一天内分几次吃完）

::: warning 对创意的直接影响
如果 B 片想用「盖回去」作收尾动作，理由要从**「吃不完」换成「随身带」**——否则观众会觉得不真实（46g 谁吃不完？），一个不真实的细节会带走整支片子的可信度。
:::

## 二、竞品

### 1. 四层竞品圈

大多数人只看第一层，**真正抢走这几块钱的往往在第三层。**

```
① 同形态：杯装 / 罐装 条状薯条
   ↓
② 同品类：所有休闲薯类零食
   ↓
③ 同场景：便利店里 5–10 元的单人即食零食  ← 真正的钱包竞争
   ↓
④ 同叙事：讲工艺 / 讲「轻负担」的零食
```

### 2. 第一层 · 直接竞品（形态高度重合）

| 竞品 | 形态 | 与本品的关系 | 级 |
|---|---|---|---|
| **卡乐比 じゃがりこ / Jagariko** | 塑料杯装、条状薯条 | **形态原型，最强对标。** 包装日文副标「カリカリポテトフライ」进一步指向这个参照 | B |
| **卡乐比 Jagabee / 薯条三兄弟** | 盒装 / 袋装粗薯条 | 高端进口薯条心智的占位者 | B |
| **可比克 · 纸罐装** | 纸罐薯片（片状） | **国产杯罐装薯类的价格锚**，性价比一侧 | B |
| **乐事 Stax 罐装 / 品客 Pringles** | 罐装片状 | 形态近、内容物不同；占据「罐装薯片」心智 | B |
| 国产白牌杯装薯条 | 杯装条状 | 零食集合店与电商大量存在，**数量与价格带未知，需实地扫店** | C |

::: danger 日文副标在竞品坐标下，性质变了
在 [00-brief](./00-brief) 里，日文元素被定性为**合规风险**。放进竞品坐标后它还有第二重性质：

**它在向 Jagariko 的心智借力。** 杯装 + 条状 + 日文，三个特征叠在一起，消费者的第一联想几乎必然是那款日本零食。

**这意味着：广告一旦做日式调性，不只是虚假宣传风险，还是在替竞品做教育。**

**2026-08-06 更新**：客户已确认日文副标为**纯装饰，与日本无任何关系**。

这个答案让上面的判断从「建议」升级成了「结论」：

> **没有实质支撑的日文，只有借力效果，没有背书价值。**

它不能证明产品好——因为背后什么都没有；却会把消费者的第一联想推给已有的日式同类产品。**留着它是包装的既成事实，强调它是纯亏。**

由此形成一条执行约束：**包装出镜时不刻意突出日文副标**。已写入 [02 · 物料清单](./02-materials) 与 [决议 ③](./)。
:::

### 3. 第三层 · 场景竞品（最容易被忽略的一层）

便利店货架前，这几块钱真正的对手（均 B 级）：

| 对手 | 它赢在哪 |
|---|---|
| 小包装坚果 / 每日坚果 | 「健康」叙事完整，且**不需要合规辩解** |
| 肉脯、鱼豆腐、鸡胸肉肠 | **蛋白质叙事**，占据「吃了不心虚」 |
| 海苔、果蔬脆 | 轻负担感 + 女性偏好 |
| 现制饮品的小料 / 关东煮 | 同价位、同场景，**而且是热的** |

::: danger 这一层的战略含义最重要
**本品在「心安理得」这条赛道上是天然劣势方**——它是油炸的，且除了「不油腻」之外的健康话一句都不能说。而对手不但能说，还说得理直气壮。

**所以竞争位不能选在「更健康」，只能选在「口感体验」与「场景新鲜感」。**

这从竞品侧再次印证了 [决议 ①](./)：鲜切讲的是**原料与口感**，不是健康——方向是对的。
:::

### 4. 第四层 · 叙事竞品

| 叙事 | 谁在用 | 对本品的意义 | 级 |
|---|---|---|---|
| **非油炸 / 烘焙型** | 乐事无限烘焙型等 | **本品永远不能进这条赛道**（VF 是油炸），且已被占据 | B |
| **冻干 / 果蔬脆** | 三只松鼠、良品铺子等 | 工艺叙事的成熟范式，**做法可借鉴，主张不可挪用** | B |
| **原切 / 鲜切** | 部分中高端与进口薯片 | **本品要抢的就是这一条** | B |

## 三、本文最重要的一条结论

> **「原薯鲜切」到底是强差异还是废话，取决于直接竞品是不是鲜切的——而这一条我方目前不知道。**

| 若…… | 则「原薯鲜切」是 | 创意后果 |
|---|---|---|
| 主流杯装条状薯条多为**薯粉 / 薯泥成型** | **强差异，主张成立** | 决议 ① 站得住，且可以更用力 |
| 主流杯装条状薯条**本来就是鲜切的** | **无差异，只是品类基本盘** | **主标题要换**，VF 可能要提回主位 |

::: danger 这是最值钱、也最不确定的一条
薯**片**品类里「鲜切」是弱差异——乐事本来就是切片的。但**杯装条状薯条是另一个品类**，成型工艺在其中的占比，我方没有把握，**上表两个分支目前都不能排除**。

**核实方法（不依赖客户，我方可自行完成）**：

1. 买 3–5 款直接竞品，看配料表首位是「马铃薯」还是「马铃薯全粉 / 淀粉」——**配料表就能定案，不需要任何内部信息**
2. 顺带记录价格带与净含量，校准本品的定价与人群推测
3. 同时抓竞品详情页与短视频，看它们的广告怎么打

**成本百元级 + 半天，回报是提案核心主张的地基。** 建议在等物料的空窗期做掉。
:::

## 四、竞品广告怎么打 → 空白在哪

| 竞品 | 惯用打法 | 本品能否跟 | 级 |
|---|---|---|---|
| Jagariko | 轻松办公室 / 校园场景 + 咀嚼音 | 场景可借鉴，**日式调性不碰** | B |
| 品客 | 叠罐、潮酷、年轻化 | 新品无品牌资产，跟不了 | B |
| 乐事 | 明星代言 + 口味上新 | 预算不支持 | B |
| 可比克 | 性价比 + 明星 | 杯装成本结构不允许打性价比 | B |

**空白地带**：主流薯类广告都在讲**口味**与**代言人**，几乎没有人讲**做法**。

::: tip 这个空白同时解释了机会和成本
工艺叙事在薯类品类里是低竞争区——这是机会。它之所以空着，一部分原因是**它贵**：需要技术理解、需要合规审校（[提案第四节](./01-proposal) 里那一整天）。

**同时它也再次印证了决议 ①**：主位讲做法太重、太慢，观众没耐心；支撑位讲做法刚好填住「为什么脆」的说服缺口。**位置对了，讲做法就从成本变成资产。**
:::

### 番茄味的定位

番茄味是薯类零食的**主流口味**，不是差异点（B）。

**结论**：口味不能作为创意的差异抓手，但**红色是视觉资产**——番茄的红与包装的高饱和橙红是一套，可以在画面上用足。**用其色，不主张其味。**

## 三条可以直接用的结论

1. ⚠️ **人群是「便利店前站三秒的年轻人」**，不是家庭囤货客——**包装形态自己筛掉了后者**，广告不必去够。**（此条为推演，客户原话补入后需重判）**

2. **别在「健康」赛道上竞争。** 那里既有合规红线，前面又站着坚果和蛋白零食，本品是天然劣势方。**赛道选口感与场景。**

3. **花半天买五杯竞品看配料表。** 这是当前唯一不依赖客户、就能推进且直接关系到提案地基的事——**并且它可能推翻决议 ①**。
