# 04 · Prompt 组（A 片 demo）

> 阶段 4 · Prompt ｜ 2026-08-06 ｜ **内部工作文档，可直接粘贴使用**

::: warning A 片正式修订已转入 v2
本页对应 demo v1。客户反馈后的完整工艺版请直接使用 [04f · A 片 v2 Gemini 执行表](./04f-a-process-v2-gemini)；B 片相关 Prompt 不受影响。
:::

按[结构通法](/prompts/structure)的五段式写：主体 / 风格 / 镜头 / 光影 / 参数。**风格段全片固定**，逐镜只改主体与动作——这是保持十个镜头质感一致的主要手段。

镜头对应关系见 [03 · 分镜](./03-storyboard)。**镜头 10（产品出镜）不在此列**，它走后期合成，不经过生成模型。

::: tip 在即梦执行
全片落在即梦时，用 [04a · 即梦执行表](./04a-jimeng-v1)：Prompt 与本表一致并逐镜展开，另标明每镜配哪张参考图、粘贴到即梦哪个输入位。
:::

## 工具分工

| 环节 | 工具 | 说明 |
|---|---|---|
| 首帧图 | **即梦 / Gemini 图像** | 先把静帧调满意，再让它动 |
| 视频 | **可灵 AI** | 图生视频为主；标注「首尾帧」的镜头用首尾帧模式 |
| 镜头 10 | AE / 剪映 | 客户渲染图去背 + 后期动态，**不生成** |

## 固定风格段

**每条图像 Prompt 都拼上这一段，不要改动。**

```
高端食品广告微距摄影，接近纪录片的真实质感，暖调，
轻微胶片颗粒，自然肤色与食物色彩，不过度锐化、不过度饱和，
商业级布光，实拍感
```

## 固定负面词

**每条都带上。前四个是质感控制，后四个是防事故。**

```
深褐色，焦黑，油腻反光，表面浮油，
文字，logo，品牌标识，包装袋，包装盒，商标，日文，中文字符，
卡通，3D渲染感，塑料感，畸变，多余的手指，水印
```

::: danger 负面词里的「文字 / logo / 包装」不能删
生成模型有很强的倾向自作主张加上包装或品牌字样——**一旦出现，这条素材直接作废**，因为那必然是个假包装（见 [03 · 镜头 10 的说明](./03-storyboard#镜头-10-为什么坚持不生成)）。

这是这套 Prompt 里最容易被顺手删掉、也最不能删的一行。
:::

## 镜头 1 · 土豆落在案板上

**首帧图**

```
一整颗新鲜马铃薯放在深色胡桃木案板上，表皮微带薄土与细小凹坑，
薯皮呈自然的浅褐黄色，案板上有几粒散落的土粒，背景深色虚化，

高端食品广告微距摄影，接近纪录片的真实质感，暖调，
轻微胶片颗粒，自然肤色与食物色彩，不过度锐化、不过度饱和，
商业级布光，实拍感，

微距，浅景深 f/2.0，平视略俯，
侧逆光，一束硬光从右后方打来勾出表皮质感与轮廓，背景压暗，
16:9，高细节
```

**视频（图生视频）**

```
马铃薯从画面上方落下，接触案板后轻微弹跳一次，随即静止，
案板上的土粒被轻微震起。慢动作，整体动作幅度小。
镜头固定不动。
```

::: tip 动作写小一点
[结构通法](/prompts/structure#调试思路-出图不对时改哪一段)里说的「动作扭曲 = 写得太快太复杂」，在食物落地这类镜头上尤其明显。

**一个动作、一次弹跳、镜头不动**——比写「弹跳滚动后停下」出片率高得多。
:::

## 镜头 3 · 土豆条落下

**首帧图**

```
一把切好的马铃薯条悬停在空中，条形整齐但边缘带自然毛刺与不规则棱角，
断面呈乳白微黄，可见细微纤维纹理，
背景为深色虚化的厨房台面，

[固定风格段]

微距，浅景深 f/1.8，平视，
顶光为主，侧面补一点冷光勾边，背景压暗，
16:9，高细节
```

**视频（图生视频）**

```
马铃薯条从画面上方缓慢落下，轻微翻转，落出画面下缘。
慢动作，镜头固定。
```

::: warning 这一镜的关键是「毛刺」
**边缘带毛刺、棱角不规则 = 真土豆切的。** 薯粉压模成型的产品，边缘是绝对光滑规整的。

这个细节是「原薯鲜切」这个主张在画面上唯一的物证，Prompt 里不能省。如果出片边缘太规整，重跑。
:::

## 镜头 4 · 真空舱内的低温油炸 <Badge type="tip" text="首尾帧" />

**首帧图**

```
封闭金属舱室内部视角，透过观察窗看到清澈的浅金色食用油，
油面平静无波，几根马铃薯条刚刚没入油中，
舱壁为哑光不锈钢，环境昏暗，

[固定风格段]

中特写，浅景深，平视，
舱内单一暖黄光源从上方照亮油面，四周迅速衰减为暗部，
16:9，高细节
```

**尾帧图**

```
同一舱室内，马铃薯条悬浮在浅金色油中，
油面依然平静，只有极细密的小气泡缓慢上升，数量不多，
薯条颜色略变浅金，

[固定风格段]

中特写，浅景深，平视，
舱内单一暖黄光源，四周暗，
16:9，高细节
```

**视频（首尾帧）**

```
细密的小气泡从马铃薯条表面缓慢上升至油面破裂，
油面保持平静，无剧烈翻滚，无大量白色泡沫。
镜头极缓慢推近。
```

::: danger 这一镜最容易做错
模型对「油炸」的默认理解是**剧烈翻滚 + 大量白色气泡**——那是常压油炸。

**真空低温不是那样。** 负压下水的沸点降低，油面近乎平静，气泡细密缓慢。

如果出片是翻滚沸腾的，**这条必须废掉重跑**，不能将就——它是整支片子里唯一一个「不一样」的视觉证据，做成常规油炸就全白费了。

必要时在 Prompt 里追加：`油面平静，无沸腾，无大量气泡，无白色泡沫`。
:::

## 镜头 7 · 断面逆光透光 <Badge type="tip" text="首尾帧" />

**首帧图**

```
一根浅金色的薯条脆竖立在深色石质台面上，断面朝向镜头，
断面可见细密的多孔结构，表面干爽无油光，
背景纯黑，

[固定风格段]

微距，浅景深 f/1.8，平视，
强逆光从正后方直射，光线尚未穿透断面，背景纯黑，
16:9，极高细节
```

**尾帧图**

```
同一根薯条脆，强逆光穿透断面，
多孔结构被光点亮，孔洞边缘呈明亮的金色，
整个断面像蜂窝一样透光，表面干爽无油光，
背景纯黑，

[固定风格段]

微距，浅景深 f/1.8，平视，
强逆光穿透，断面发光，背景纯黑，
16:9，极高细节
```

**视频（首尾帧）**

```
逆光逐渐增强，光线穿透薯条脆的断面，
多孔结构由暗转亮，孔洞边缘依次点亮。
镜头极缓慢推近，其余静止。
```

::: tip 这是全片的「证据镜头」
[03 · 分镜](./03-storyboard#镜头-5-7-一个原因-一个结果)说明过：镜头 5 讲孔怎么来的，这一镜讲孔带来了什么。

**它要的不是好看，是可信。** 所以背景纯黑、镜头几乎不动、没有任何多余元素——画面里只剩一个事实。
:::

## 镜头 8 · 掰断瞬间 <Badge type="tip" text="首尾帧" />

**首帧图**

```
两只手的手指捏住一根浅金色薯条脆的两端，即将掰断，
薯条脆表面干爽，可见细微的多孔质地，
背景深色虚化，

[固定风格段]

微距，浅景深 f/2.0，平视，
侧面硬光，在薯条脆表面形成清晰的明暗交界，背景压暗，
16:9，高细节
```

**尾帧图**

```
薯条脆已断成两截，断口参差，
大量细小碎屑向四周飞散，断面露出多孔结构，
背景深色虚化，

[固定风格段]

微距，浅景深 f/2.0，平视，
侧面硬光照亮飞散的碎屑，背景压暗，
16:9，高细节
```

**视频（首尾帧）**

```
手指用力，薯条脆断裂，断口处细小碎屑向四周飞散。
高速摄影般的慢动作，断裂瞬间清晰可见。
镜头固定。
```

::: warning 手部是生成的高风险区
出现多指、断指、关节反折是这类镜头最常见的废片原因。

**降低风险的做法**：只入画两根手指的指尖，不出现完整手掌；或改为「薯条脆自然折断」不出现手。**这一镜的重点是断口和碎屑，不是手。**
:::

## 镜头 9 · 成品质感

**首帧图**

```
一堆浅金色的薯条脆散落在深色石质台面上，条形整齐边缘带自然毛刺，
颜色浅金偏黄，不是深褐色，表面干爽哑光，无油亮反光，
可见细微的多孔表面质地，

[固定风格段]

特写，浅景深 f/2.2，略俯视，
柔和顶光为主，侧面补一盏硬光勾勒边缘，背景压暗，
16:9，高细节
```

**视频（图生视频）**

```
更多薯条脆从画面上方缓慢落下，堆叠在已有的一堆上，
落下时相互碰撞、轻微弹跳。
慢动作，镜头缓慢横移。
```

::: danger 颜色是这一镜的合规要点
**浅金 ≠ 深褐。** VF 低温油炸的产品颜色明显浅于常压高温油炸，这是工艺的自然结果。

如果出片是深褐色，画面就和「低温」这条工艺链自相矛盾了——**观众不一定说得出哪里不对，但会觉得不对。**

负面词里的「深褐色、焦黑」就是防这个。
:::

## 镜头 10 · 产品出镜（不生成）

**制作方式：客户渲染图 → 去背 → AI 生成背景与光环境 → 设计软件合成 → 后期动态**

走[决策树 A1](/tools/decision-tree#a1-产品必须精确还原吗) 的链路。**包装本身不经过任何生成模型。**

背景与光环境可以生成，Prompt 如下（**画面里不放产品**，产品是后期合成上去的）：

```
纯净的深色石质台面，背景为柔和的暖调渐变，
台面上有柔和的光斑与轻微的景深虚化，画面中央留空，
无任何物体，

[固定风格段]

中景，浅景深，平视，
影棚布光，主光从左上方 45 度，右侧柔光补光，背景轻微渐变压暗，
16:9，高细节
```

**后期动态**：缓慢推近 + 一道光扫过包装表面 + 轻微景深变化。**不做变形、不做形变过渡**——任何会改变包装形状的效果都可能让文字与 logo 失真。

## 参数建议

| 项 | 值 | 说明 |
|---|---|---|
| 分辨率 | 1080p 起 | demo 够用；成片建议 4K |
| 帧率 | 24fps | 与常规广告片一致 |
| 单镜时长 | 5s | 剪进片子只用 1.5–2.5s，**留出选择余地** |
| 生成条数 | 每镜 4–6 条 | 微距与慢动作的废片率偏高，见下 |

::: tip 关于出片率，去 05 记
每一镜实际跑了多少条、采用了哪条、废的为什么废，**当场记进 [05 · 生成日志](./05-genlog)**。

事后一定记不准——这是[案例 06](/cases/case-06-kalshi-veo) 信息量最大的原因，也是这套流程里最容易被跳过的一份。
:::

## 换工具怎么办

镜头设计与五段式内容不变，只调语法：

| 工具 | 主要差异 |
|---|---|
| **Veo 3** | 英文效果更好；原生支持音频描述，可把音效写进 Prompt；「首尾帧」改用起止状态的文字描述 |
| **Runway Gen-4** | 英文；Motion Brush 可精确指定运动区域，镜头 6 的油滴飞散适合用它 |
| **即梦** | 与可灵语法接近，中文直接可用；首尾帧功能相当 |

**不要改的是**：固定风格段的内容、全部负面词、以及镜头 4 的「油面平静」与镜头 9 的「浅金非深褐」——这三处是内容正确性问题，不是工具差异。
