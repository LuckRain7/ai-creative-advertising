## 内部决议记录

> 2026-08-05 · 三条关键判断已拍板

### ① 创意核心 → 鲜切主、VF 支撑

**决议**：主标题给「原薯鲜切」，VF 作为「为什么鲜切之后还这么脆」的支撑证据。

**理由**：包装上对得上 / 消费者不需要科普就能懂 / **鲜切是消费者自己能验证的承诺**。

**被否**：
- *VF 做主（客户原话）* —— 消费者拿到包装找不到 VF，广告和包装说的不是一件事
- *两支片各讲一个* —— 没有共同记忆点，投放合力变弱；且 B 片只有 6–10 秒，装不下一个完整主张

### ② 片型分工 → A 主片 + B 开盖片

**决议**：A 片 15–20s 讲因果链；**B 片改成「开盖即食」动作片** 6–10s。

**理由**：知识库里的方案是**按袋装推演的**。杯装的撕封口动作补上了袋装零食「缺标志性动作」的死穴，同时补偿了这个产品没有热气造成的信息量缺失。

### ③ 日文元素 → 定性前一律不碰

**决议**：无书面依据则按「无日本背景」处理。片中不出现日式场景、日文字幕、日式配乐。包装出镜时日文客观存在，不受影响。

**理由**：包装印日文行业常见，通常没问题；**广告主动暗示「这是日本的」性质完全不同**，无对应关系即虚假宣传。

**2026-08-06 定性完成**：客户明确——**日文副标是纯装饰，与日本无任何技术、合作或出口关系。**

决议 ③ 不变，但性质变了：从「**待定性，暂时不碰**」变成「**已定性，确定不碰**」。这不再是一个悬着的风险，而是一条确定的约束。

::: danger 定性为「纯装饰」之后，反而多出一条执行约束
原决议写「包装出镜时日文客观存在，不受影响」——**这句现在需要补充**。

不受影响指的是「不必回避」，不等于「可以强调」。**建议在包装出镜的镜头角度与景别上，不刻意突出日文副标。**

两个理由，指向同一个动作：

| 角度 | 为什么 |
|---|---|
| **合规** | 包装印日文与广告特写日文是两回事。给日文一个特写镜头，在无实质关联的前提下，可能被理解为对来源的暗示 |
| **竞争** | 见 [01a](./01a-audience-competitors)——杯装 + 条状 + 日文，三个特征叠加，消费者第一联想几乎必然是 Jagariko。**而现在确认了它没有任何实质支撑** |

第二条现在才真正成立：**装饰性日文只有借力效果，没有背书价值。** 它既不能证明产品好，又在替竞品做心智教育——强调它是纯亏。

这条已写入 [02 · 物料清单](./02-materials)，并将在分镜阶段落到具体镜头上。
:::

::: warning 2026-08-06 补充：这条决议的理由变了，而且变强了
[01a · 竞品分析](./01a-audience-competitors) 从竞争角度给出了第二个、且更硬的理由：

**杯装 + 条状 + 日文，三个特征叠在一起，消费者的第一联想几乎必然是 Jagariko。** 广告做日式调性，等于替竞品做心智教育。

**由此，决议 ③ 的适用范围扩大**：原本是「定性前不碰」——拿到书面依据就可以碰；现在建议改为**即使客户拿出真实的日本背景，也不做日式调性**。

理由从**合规**变成了**竞争**。合规风险可以靠一纸证明解除，竞争劣势不能。
:::

### ④ VF 工艺资料 → 收下，但不当作宣称依据

> 2026-08-06 · 客户以文字形式提供 VF 技术说明后

**决议**：资料中可用的只有四条——**多孔结构、80~90℃、脱油离心、酥脆不腻**。其余一律不进片，其中「不生成丙烯酰胺」「规避致癌风险」两条即使日后拿到检测报告也不用。

**理由**：这份资料讲的是 **VF 技术在果蔬脆片上的通用应用，不是薯条脆的工艺文件**——「可泡水复水食用」这一条把它的出身暴露得很清楚。原理可信，但**通用资料不能替本产品背书**。

**由此产生的动作**：物料清单新增 2a–2d（出处、本产品参数、脱油工序、检测报告），并新增一整节向客户逐条说明哪些表述能用、哪些要数据、哪些建议不用。

**提案 v1.0 不改动。** 判断依据：这份材料的性质是**对内的产品认知口径**，客户提供它是为了让我方理解产品，不是要求这些表述进入成片。既然客户没有主张使用，提案的「内容边界」一节按原样即可——那五条红线本就覆盖了这里的风险。

::: warning 一条被撤回的推断
初稿曾判断「客户发材料 = 客户希望片中用这些话」，据此主张扩充提案的内容边界一节。

**这个推断是错的，已撤回。** 它只依据材料内容本身，没有考虑客户发送时的语境——而这一点只有直接沟通的人知道。

留档的价值在于：**从文本推断意图，在客户沟通里是高频错误。** 同一份材料，「你参考一下」和「按这个写」是两件事，文本上看不出区别。下次遇到客户主动发材料，先确认它是参考件还是要求件，再决定动不动提案。
:::

::: tip 顺带印证了决议 ①
客户给了 VF 一大堆料，最有传播力的四句（不致癌、低脂、高纤维、无添加）**没有一句能在拿到检测数据前使用**。

剩下能用的四条，回答的都是「为什么脆而不腻」，**没有一条能回答「为什么买它」**——这正是提案里给 VF 安排的支撑位。

决议 ① 从一个判断变成了事实。
:::

### ⑤ A 片反馈 → 工艺从支撑位升为主体段落

> 2026-08-10 · 客户看过 A 片 demo 后

**客户要求**：注意制作细节、节奏调整与制作完整性，重点体现**真空、低温、油炸、脱水、脱脂**。

**决议**：保留「原薯鲜切」作为开头与包装落版主张，但将中段改为一条可读的完整工艺链：

```
真空 → 低温 → 油炸 → 脱水 → 离心脱油 → 多孔 → 脆
```

这不是推翻决议 ①，而是把 VF 从一个合并镜头扩展为全片的主体段落。工艺段占 v2 约 61%，每个节点都有独立画面证据和字幕节拍。

**术语处理**：客户原话「脱脂」留档，成片建议写「离心脱油」。前者容易形成脂肪含量暗示，后者只陈述工序；在检测与书面工艺依据补齐前，不使用「低脂」或任何结果性延伸。

### ⑥ A 片 v3 → 广告为主，工艺作证

> 2026-08-15 · v2 成片方向内部复盘

**问题**：v2 虽满足了五个工艺节点的完整性，但工艺段约占 61%，前 13 秒持续解释设备与原理，观看感受接近企业工艺说明片，食欲、口味、包装和取食动作出现太晚。

**决议**：不删工艺证据，但改变它的叙事职能。v3 用成品断裂和主「咔嚓」开场，随后才以 6.4 秒压缩呈现 VF；后半段回到断面、番茄风味、真实开杯和包装落版。工艺占比降至 32%，执行见 [04h · 广告化执行稿](./04h-a-process-v3-researched)。

这不是撤销客户要求，而是重新建立信息层级：**广告负责让人想吃，工艺负责让人相信。** 真空、低温油炸、脱水、离心脱油继续有独立视觉证据，但不再各占一页式字幕节拍。

::: tip 预算为什么只写状态、不写内容
公开状态下，自我审查是唯一的控制点（见 `specs` 决策变更记录）。而那张审查表里第二条就是**「未公开的价格条款、合同细节」不写**。

预算属于双方商业关系信息，**记录它的状态足够支撑排期与制作决策，记录它的内容不增加任何工作价值**。

这是「完全公开」这个决定在日常写作中的第一个具体约束——**它不是一次性的，是此后每一次落笔都要过的一道**。
:::

这是很常见的一种反应——**给材料比做决定容易**。回复时要把「感谢资料」和「但这七条仍在等」分成两段写清楚，不能混在一起，否则等于默认这一轮的沟通完成了。
:::
