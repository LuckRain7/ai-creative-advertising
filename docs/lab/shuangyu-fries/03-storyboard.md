## demo 的用途

**不是交付样片，是撬动物料。**

客户已连续两轮回避物料问题（[项目首页](./)记录）。继续发催料邮件收益递减，**给他看见东西**是更有效的手段——而这支 demo 被有意设计成「工艺段落完整、产品段落将就」，让缺口自己说话。

| | demo 版 | 成片版 |
|---|---|---|
| 镜头 1–9 | 生成 | 同上，精修 |
| **镜头 10 · 产品出镜** | **客户渲染图做后期动态** | **必须用设计源文件重做** |
| 字幕「80~90℃」 | 打上 | **须 2b 确认本产品参数后方可保留** |
| 脱油工序呈现 | 做 | **须 2c 确认本产品确有此工序** |

::: warning 两条字幕/镜头是故意留的钩子
「80~90℃」与「离心脱油」目前都只有[通用技术资料](./00-brief#客户补充物料-vf-工艺资料)支撑，**未确认适用于本产品**（物料清单 2b、2c）。

demo 里照做——客户看到自己产品的片子里打着这个温度，会比看到催料邮件更快去问工厂要参数。**让待确认项以画面形式出现在客户眼前，是这支 demo 的第二个用途。**

但成片前必须落实。这条已写进下方每一镜的状态列。
:::

## 关键镜头的设计意图

### 镜头 4：低温油炸的视觉特征是「安静」

这一镜最容易做错。**常压油炸的画面是剧烈翻滚、大量白色气泡**——那是水在 100℃ 以上沸腾。

真空低温不是。负压下水的沸点降低，**油面近乎平静，只有细密小气泡缓慢上升**。

::: tip 这个差异本身就是最好的说服
不需要并排对比，不需要旁白解释。**观众看过无数油炸镜头，他知道油炸该是什么样子。**

当画面安静得不像油炸时，「这个不一样」的结论他自己会下——而且是[提案里说的](./01-proposal)那种「他自己得出的对比」，比屏幕上摆出来的更有说服力，也不踩对比广告的红线。
:::

### 镜头 5 + 7：一个原因，一个结果

镜头 5 讲**孔是怎么来的**（水分抽离 → 形成多孔），镜头 7 讲**孔带来了什么**（光能透过 → 所以脆）。

两镜必须成对出现，且中间隔着镜头 6。**先看见成因，再看见证据，中间隔一道工序**——这个顺序是因果链能被读懂的关键。

单放镜头 7 只是好看；有了镜头 5，它才是证明。

### 镜头 6：这个产品唯一能正面回应「油炸=油腻」的东西

见 [00-brief 工艺资料裁定](./00-brief)。它陈述的是**工序**，不是营养结论——不需要检测数据，合规成本为零。

而且它有画面、实拍拍不到，是生成技术的优势区间。

**如果 2c 确认本产品没有这道工序，这一镜必须整个删掉**，不能用「看起来像脱油」的画面糊弄。

### 镜头 10：为什么坚持不生成

[决策树 A1](/tools/decision-tree#a1-产品必须精确还原吗) 已经写死：产品需精确还原 → 不要纯生成。

包装含 logo、注册商标、中文、日文与精确品牌色。**生成模型必然画错**，而客户看到一个假包装只有两种反应，都是坏的：以为我们打算这么做，或者觉得「这个包装看着也行」。

**宁可留一个明显将就的镜头，也不填一个假的。**

demo 做法：客户渲染图 → 去背 → AI 生成背景与光环境 → 后期做推拉、光扫、景深、粒子。**包装本身像素级不变，不经过任何生成模型。**

::: warning 日文副标的镜头处理
已确认日文为纯装饰、与日本无关系（[决议 ③](./#③-日文元素-定性前一律不碰)）。

**镜头 10 的角度与景别不刻意突出日文副标**——正面平视即可，不给侧标特写。理由是合规与竞争两条，见决议 ③。
:::
