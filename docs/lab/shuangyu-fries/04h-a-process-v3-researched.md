## 先把片子定性

这首先是一支 **薯条脆食品广告**，其次才是一支 VF 工艺片。

> **从一颗原薯，到一声咔嚓。**

广告先让人想吃，再用工艺回答「为什么能这么脆」。VF 不单独承担购买理由，而是为「原薯鲜切、咔嚓酥脆」提供可信证据。

| 广告任务 | 本片答案 |
|---|---|
| 第一眼抓什么 | 成品断裂、番茄红颗粒、主「咔嚓」 |
| 消费者记什么 | 原薯鲜切，咔嚓酥脆 |
| VF 做什么 | 解释从鲜切到酥脆的过程 |
| 产品何时出现 | 第 0 秒先见成品，第 14 秒进入真实杯装产品 |
| 品牌如何收口 | 真实包装稳定停留 3.2 秒 |

::: tip 这版与上一版的根本区别
上一版沿设备流程顺讲，前 13 秒都在解释工艺，像企业工艺说明片。

本版采用 **结果钩子 → 原料 → 工艺证据 → 风味与食用 → 品牌落版**。工艺仍完整，但从约三分之二压到约三分之一；观众先看见「好吃」，再愿意相信「讲究」。
:::

## 核心创意

### 创意句

> **从一颗原薯，到一声咔嚓。**

### 落版文案

> **原薯鲜切 · 咔嚓酥脆**

「原薯鲜切」与包装现有表达一致；「咔嚓酥脆」用声音和断裂画面当场验证。VF 关键词只在中段出现，不和落版主张抢层级。

### 观看路径

```text
先听见脆       看见原薯       相信做法       看见风味       想拿一根       记住产品
咔嚓钩子  →   原薯鲜切  →   VF 工艺  →   番茄颗粒  →   开杯取食  →   包装落版
```

## 导演与剪辑执行

### 1. 开头必须像食品广告

- 第一帧直接见成品，不从土豆、工厂或设备开始。
- 前 1.6 秒只做一件事：把「咔嚓」变成注意力钩子。
- 断裂碎屑必须是食物碎屑，不能做成金属粒子、烟花或抽象能量。

### 2. 工艺段必须跟着食物走

- 镜头 3 只用 1.2 秒建立真空，不展示完整设备巡礼。
- 镜头 4 画面中心始终是薯条，设备只是环境；不让管路、压力表和控制柜抢主体。
- 镜头 5、6 用滴水与旋转做两个节奏点，不停下来讲解原理。
- 工艺外部光保持中性，罐内油色与成品统一为浅金；番茄红从镜头 7 尾部开始进入，带回品牌色。

### 3. 工艺与食欲必须互相转场

| 前镜 | 后镜 | 转场依据 |
|---|---|---|
| 成品断面 | 鲜薯切面 | 相同粗细、相同机位、干湿质感反差 |
| 冷凝水滴 | 油位下降 | 垂直下落动作匹配 |
| 料篮滤孔 | 成品断面孔隙 | 圆形结构匹配，但孔隙不能规则化 |
| 断裂碎屑 | 番茄颗粒 | 粒子方向连续，颜色由金转红 |
| 成品落下 | 杯内产品 | 下落动作匹配到真实开盖素材 |

### 4. 字幕只有两级

- **主张级**：`原薯鲜切`、`原薯鲜切 · 咔嚓酥脆`，字号最大。
- **证据级**：`真空`、`VF 真空低温油炸`、`真空脱水`、`离心脱油`，统一小字号、固定位置，不逐字蹦出。
- `疏松多孔`、`番茄味`为结果和口味提示，字号介于两者之间。
- 不把 `真空 → 低温 → 油炸 → 脱水 → 离心脱油` 做成五页 PPT 式大字卡。

## 广告验收顺序

1. **先关字幕看**：前三秒是否想继续看，14 秒后是否想拿一根；如果不成立，工艺再准确也不通过。
2. **再看产品**：粗直长条、浅金、番茄红颗粒、干爽断面必须从头到尾一致。
3. **再看品牌**：真实包装至少稳定 1.5 秒，logo、产品名、口味名不可被生成模型改写。
4. **再看工艺**：密封建立真空；油炸伴随细泡和水汽；先排油后离心，物理顺序不能错。
5. **最后看字幕**：主张大于工艺词；删掉字幕后画面仍能讲通，才不是 PPT。

## 工艺真实性护栏

以下考据服务于镜头真实性，不决定广告叙事顺序。

::: warning 使用边界
这些资料证明的是 **VF 马铃薯条的可行工艺与设备结构**，不能代替双宇本产品的工厂工艺单。

- 本片不展示尚未由客户确认的漂烫、预冷、速冻等前处理。
- 鲜切镜头与真空罐镜头是广告蒙太奇，不做成「切完立即进罐」的连续动作。
- 温度、真空度、转速和时间不进入成片，直到本产品参数获得书面确认。
- 成片写「离心脱油」，不写「脱脂」「低脂」或含油量结论。
:::

### 工艺顺序

[CN107373522A · 一种真空低温油浴脱水加工马铃薯条的方法](https://patents.google.com/patent/CN107373522A/zh) 给出的参考流程为：

```text
原料选择 → 清洗去皮 → 切条 → 漂烫 → 预冷 → 冷冻
→ 真空油浴脱水 → 真空离心脱油
```

该专利用于校正动作顺序和产品几何形态，其中参数不视为本产品参数。

### 设备结构

[CN102232498B · 批式真空油炸装置](https://patents.google.com/patent/CN102232498B/zh) 描述了真空炸腔、油加热容器、气液分离器、冷凝器、冷凝液接收罐与真空泵之间的连接关系。画面中的设备应体现 **密封罐体 + 卫生管路 + 冷凝/真空单元**，不能是一个孤立金属罐。

[CN109757535A · 多功能真空油炸干燥机](https://patents.google.com/patent/CN109757535A/zh) 描述了同一罐体内的带孔料篮与离心轴：油炸后先排油，再启动料篮旋转，把表面油甩离产品。这是镜头 6「油位下降 → 离心脱油」的动作依据。

### 低压脱水与断面

[Heat and Control Unitized Vacuum Fryer](https://www.heatandcontrol.com/sites/default/files/content/resource/pdf/2019-05/Unitized%20Vacuum%20Fryer.pdf) 的设备资料说明，密封罩内维持真空，低压使水分在较低温度下沸出，设备并集成离心脱油。因此油炸画面要有持续水分汽化，不是完全静止的油面。

[LWT 马铃薯真空油炸研究](https://doi.org/10.1016/j.lwt.2016.06.047) 将残余水分、吸油、微观结构、脆度和色泽作为关联指标。断面可以表现不规则孔隙和细胞结构变化，但不能画成规则蜂窝或海绵。

::: tip 必须守住的物理顺序
**水分先从马铃薯组织逸出，留下不规则孔隙；炸油排走后，料篮再旋转去除表面油。**

不要用「油从薯条内部被吸出来」的夸张动画。
:::
