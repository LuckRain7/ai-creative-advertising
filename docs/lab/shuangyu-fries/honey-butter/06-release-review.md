# 06 · 发布与验收

> 本页用于成片关门、发布测试与后续内容决策。

## 首发文案

```text
先选 A / B / C，再看到答案。
蜂蜜黄油味，哪一声最像它？
```

## 评论原则

- 首发片不伪造用户头像、评论内容、点赞数或消费者评价。
- 品牌可以在置顶评论里继续提问：「下一次想听一根、两根还是三根？」
- 只有真实评论出现后，才使用平台的「回复评论」功能制作后续片。
- 评论区出现「像库存音效」「是不是后配的」时，优先发布声音制作幕后并如实标注素材来源，不争辩。

## 续拍机制

| # | 形式 | 内容 |
|---:|---|---|
| 1 | 评论回复 | 按真实高赞评论要求，调整声音距离感后重新生成或录制一次 |
| 2 | 声纹加量 | 一根、两根、三根同时折断，观众继续选最喜欢的一声 |
| 3 | 咔嚓采样器 | 折断、咬下、落杯、颗粒四种真实声音组成 6–8 秒节拍 |
| 4 | 声音幕后 | 展示 Prompt、候选版本和音轨处理；使用 Foley 时再展示麦克风与真实样品 |

## A/B 测试

只改变一个变量，其他镜头、声音与投放条件保持一致。

| 版本 | 变量 | 文案 / 处理 |
|---|---|---|
| A | 问口味身份 | **哪一声是蜂蜜黄油味？** |
| B | 问主观偏好 | **A、B、C，哪一声最解压？** |
| C | 答案出现较早 | 5.5 秒揭晓「都是」 |
| D | 答案出现较晚 | remix 后 8.2 秒才揭晓 |

优先观察 2 秒停留、6 秒播放、完播、重播与每千次播放评论数。不能只用点赞判断：本片最重要的信号是观众是否真的参与选择，以及是否为了比较而重播。

## 内容与合规边界

1. 「蜂蜜黄油味」只作为确认后的口味名出现；在配料表未确认前，不展示蜂巢、蜂蜜罐、真实黄油块，也不表述「真蜂蜜」「真黄油」。
2. 不使用「最脆」「全网最响」等无法证明的绝对化表述。
3. 不伪造消费者评论、测评结论、点赞数或平台热度。
4. 不出现低脂、低卡、无油、0 负担、吃不胖等营养或功效暗示。
5. 最终包装必须使用蜂蜜黄油味终稿物料，不用番茄味包装改色，不让模型自行设计包装。
6. AI 音效不得宣传为「原声实录」或「真实盲测」；实际使用产品 Foley 时保留原始文件和对应记录。

## 总验收

### 创意与节奏

- [ ] 9:16 竖屏，成片实长 12.0 秒，重要信息不被平台 UI 遮挡
- [ ] 第一帧同时出现产品口味身份与可理解的问题
- [ ] 0.9 秒进入第一声，4.2 秒内完成 A / B / C 三次测试
- [ ] 三个选项的视觉权重一致，不提前暗示答案
- [ ] 「答案：都是」清楚可读，反转成立且不欺骗观众
- [ ] 落版文案至少清晰保留 1.2 秒，最后一声可自然循环回第一帧

### 产品与声音

- [ ] A、B、C 使用同一 P0 产品身份，动作和最终声音严格同步
- [ ] 断面与表面符合真实马铃薯条状产品参考，不像面包、威化或挤压膨化棒
- [ ] 全片无蜂蜜滴淋、黄油包裹、油光与无依据真实原料暗示
- [ ] 包装只使用客户确认的蜂蜜黄油味终稿物料
- [ ] 音效 Prompt / 原始录音、处理轨、波形来源与最终采用画面可追溯

### 发布与合规

- [ ] 不伪造评论、评分、销量、点赞或消费者证言
- [ ] 无绝对化、营养功效或未经证实的原料表述
- [ ] 取得所需包装、字体、音乐与人物生成参考的使用授权
- [ ] 主版、投放版、封面和发布文案中的品牌与口味信息一致
- [ ] 后续回复片只引用真实出现的评论
