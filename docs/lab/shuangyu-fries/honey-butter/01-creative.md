# 01 · 创意

> 本页只确认创意命题、互动机制与影片边界。通过后进入 [02 · 关键帧](./02-keyframes)。

## 一句话创意

不再把「感官片」理解为光带、微粒、升格断裂与包装落版的组合，而是把整支片做成一道观众可以立即参加的**声音选择题**：

> **不看答案，你能听出哪一声是蜂蜜黄油味吗？**

同一款薯条脆用三种方式发声：单根折断、双根同时折断、真实咬下。观众先选 A / B / C，影片再揭晓：

> **答案：都是。**
>
> **味道听不见，脆可以。**

形式本身就是产品证据。观众为了作答会主动打开声音、比较、重播和评论，不需要先看完一段广告才收到卖点。

## 为什么换格式

| 旧版问题 | 当前处理 |
|---|---|
| 20 秒横屏，主「咔嚓」到 8.8 秒后才出现 | 0.9 秒进入第一声，4.2 秒内完成三次核心感官证据 |
| 观众只是观看一组漂亮镜头 | 第一秒建立 A / B / C 选择任务 |
| 蜂蜜黄油靠光带与暖色抽象表达 | 口味只做身份线索，不用无依据原料画面解释 |
| 视觉奇观是主角，产品像特效载体 | 三组画面统一继承 P0 产品身份，声音在后期独立设计 |
| 单片看完即结束 | 可由真实评论继续生成回复片、复测片和声纹 remix |

## 影片定位

| 项目 | 内容 |
|---|---|
| 产品 | 双宇食品「薯条脆」蜂蜜黄油味 |
| 片型 | 互动感官片 / 声音盲测 / 原生短视频 |
| Big Idea | **蜂蜜黄油的味道不能隔着屏幕尝，但它有多脆，隔着屏幕也听得见。** |
| 核心钩子 | **哪一声是蜂蜜黄油味？** |
| 答案反转 | **都是。** |
| 核心文案 | **味道听不见，脆可以。** |
| 核心诉求 | 蜂蜜黄油口味身份、干爽酥脆的声音记忆 |
| 画幅 | 9:16 竖屏，1080 × 1920；重要文字避开平台顶部、右侧与底部操作区 |
| 时长 | 12 秒主版；另剪 6 秒投放版与 4 条声纹素材 |
| 制作方式 | 产品实拍只作身份参考；画面以 AI 关键帧和图生视频生成，包装、文字、波形在后期合成 |

## 互动规则

观众不需要学习玩法。第一帧同时给出问题和产品口味，随后按固定节拍听三声：

| 选项 | 动作 | 声音性格 | 视觉职责 |
|---|---|---|---|
| **A** | 单根薯条脆从中央折断 | 短、亮、清晰 | 建立第一份「脆」证据 |
| **B** | 两根薯条脆同时折断 | 更厚、更密、带碎裂层次 | 与 A 形成可比较差异 |
| **C** | 真人近距离咬下一口 | 低频更完整、最接近真实食用体验 | 把测试从实验转回「想吃」 |

三组画面必须继承同一张 P0 产品身份母版。A / B / C 的差异只来自动作与数量，不让模型在三个镜头里生成三种不同产品。最终声音在后期独立制作，不直接采用视频模型随机生成的声音。

## 创意边界

- 蜂蜜黄油只作为确认后的口味身份，不用蜂蜜滴淋、蜂巢、蜂蜜罐或真实黄油块解释风味。
- 「脆」由同一产品母版下的三种动作、断面和后期声音共同建立。
- 所有正式动态从通过审核的本镜关键帧进入图生视频，不直接用文字盲生成整片。
- Demo 只验证调性、动作顺序和节奏，不作为正式成片底料。
- 不伪造评论、点赞、测试结果或用户反馈。
- 最终包装只使用客户确认的蜂蜜黄油味终稿物料。

## 本步审核

- [ ] 「哪一声是蜂蜜黄油味」可作为第一秒钩子
- [ ] 「答案：都是」的反转清楚，不构成误导
- [ ] 「味道听不见，脆可以」可作为核心文案
- [ ] A / B / C 三种动作足以支撑互动
- [ ] 同意按 P0 母版、关键帧、Demo、正式分镜的 AI 视频流程推进
