::: warning 第 6 项定性后新增的一条执行约束
贵司已明确日文副标为装饰性使用、与日本无实质关联。据此，我方在片中不会出现任何日式元素——这一点原已写入提案。

**新增的一条是关于包装出镜镜头本身**：包装上的日文属客观存在，出镜无需回避；但**我方建议在镜头角度与景别上不刻意突出日文副标**。

两点理由：

1. **广告与包装的性质不同。** 包装印制日文属行业常见做法；但广告中给日文特写、使其成为画面重点，可能被理解为对产品来源的暗示——在无实质关联的前提下，这一点需要避免。
2. **它对本品没有好处。** 日文副标在没有日本背景支撑时，不构成任何品质背书，却会引导消费者联想到已有的日式同类产品。**强调它，等于把注意力让给别人。**

此条不影响物料需求，属分镜阶段的执行约定，先在此记录。
:::

## 工艺资料的采用说明

> 2026-08-06 新增

贵司提供的 VF 工艺资料已收到，内容详实，我方据此确定了片中四处工艺呈现，列在下方。

### 我方计划采用的

| 资料中的内容 | 片中如何呈现 |
|---|---|
| 「形成疏松多孔结构」 | 作为**断面镜头**的内容依据——光能透过薯条脆的断面，是因为内部结构疏松多孔。这也是「脆」的物理原因 |
| 「油温恒定控制在 80~90℃」 | 可作为字幕出现的**具体数字**。它陈述事实，不作任何比较，风险低 |
| 「离心工艺去除表面多余油脂」 | 呈现为一道**工序**。这是我方最看重的一条——它正面回应了消费者对油炸零食的顾虑，且不需要任何检测数据支撑 |
| 「酥脆干爽，吃完无油腻感」 | 可作为口感描述使用。属感官表述，不属营养声称 |

::: tip 第三条为什么重要
说「有一道脱油工序」和说「低脂」是性质完全不同的两句话。

**前者陈述的是生产环节，可查证；后者陈述的是营养结论，需检测数据达到国家标准的量化门槛。**

前者能达到的传播效果，其实不比后者差——观众看到离心机把油甩出去，得出的结论是他自己想的，比字幕告诉他的更可信。
:::

### 其余条目的处理

资料中涉及营养与含量的表述（低脂肪、低热量、高膳食纤维、富含维生素、保留钙铁、无添加等），**须以本产品的配料表与营养成分表核对后**，方能确定能否在片中使用——这类表述在国家标准中有明确的量化门槛。**这也是第 3 项目前最急的原因。**

另有个别条目涉及食品广告的受限范畴，我方建议不纳入成片。若贵司希望使用其中某一条，请告知，我方会就该条单独说明所需材料与可行的替代表述。

### 一处需要贵司确认的技术细节

资料中「可泡水复水食用，复水后口感接近新鲜果蔬」一条，**我方判断适用于苹果脆、秋葵脆等果蔬脆片，可能不适用于薯条脆**。

这也是我方提出补充项 2a、2b 的原因——**该资料介绍的是 VF 技术的通用应用，其中哪些条目适用于本产品，需要贵司确认。**
