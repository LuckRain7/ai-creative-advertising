## 薯条脆 · 双片提案

**双宇食品「薯条脆」（46g 杯装 · 番茄味）｜ 广告片 ×2**

---

### 一、核心主张

> **鲜切是原料，低温炸是工艺，脆是结果。**

三者构成一条完整的因果链：

```
原薯鲜切          →      VF 低温油炸       →      脆，且是土豆本来的颜色
（原料 · 看得见）        （工艺 · 讲做法）        （结果 · 吃得到）
```

**主标题落在「原薯鲜切」，VF 工艺作为支撑证据出现。**

#### 为什么这样安排

贵司提出希望突出 VF 工艺，我们建议保留这一内容，但调整它在片中的位置。三点理由：

| 理由 | 说明 |
|---|---|
| **与包装一致** | 现有包装主打「原薯鲜切」，未出现 VF 相关表述。若广告主打 VF，消费者购买后在包装上无法对应，会削弱可信度 |
| **消费者能听懂** | 「真空低温油炸」需要先科普再理解，十几秒的片子没有这个空间。「真土豆切的」不需要解释 |
| **是一个可验证的承诺** | 鲜切的对立面是薯粉压模成型，消费者吃得出差别。**他能自己验证的承诺，比他需要相信的承诺更有力** |

VF 在这条链路里承担的功能是回答「鲜切之后为什么还能这么脆、颜色还这么自然」——**它在这个位置上是有作用的，不是附加说明。**

---

### 二、两支片子的分工

| | **A 片 · 主片** | **B 片 · 开盖片** |
|---|---|---|
| **时长** | 15–20 秒 | 6–10 秒 |
| **画幅** | 16:9，另出竖版裁切 | 9:16 竖屏 |
| **回答的问题** | 为什么值得买 | 想吃 |
| **结构** | 鲜切 → 工艺 → 脆 → 产品 | 撕开 → 露出 → 咔嚓 → 产品 |
| **建议投放** | 电商详情页 / 品牌自媒体 / 线下屏 | 抖音 · 小红书信息流 |
| **开头** | 可用一秒铺垫 | 第一帧即为撕封口 |
| **声音** | 环境音为主，安静 | **音效是主角** |

#### B 片为什么围绕「撕开封口」

袋装零食在广告里有一个长期难题：**没有标志性动作。**「倒出来」「抓一把」都不够干净，不足以撑起一支片子的开头。

**杯装解决了这个问题。** 撕开铝箔封口是一个干净、有仪式感、且自带声音的动作——它是这个包装形态独有的资产。

另外，这个产品是常温预包装零食，**没有热气**。而热气是食欲镜头里最强的一条线索（热 = 刚做好 = 新鲜）。撕封口的动作加上开盖瞬间的声音，正好补上这部分缺失的信息量。

#### 素材复用

断面透光、成品掉落两组镜头 A 片 B 片共用。**先制作 A 片，B 片从中剪出**，可显著压缩工作量。

---

### 三、内容边界

食品广告 + 工艺宣称属于双重监管范畴。以下表述**不会出现在成片中**，请贵司知悉：

| 不会出现 | 原因 |
|---|---|
| 非油炸 | VF 工艺属于油炸（真空环境下的低温油炸），成品含油。此为事实层面的问题 |
| 更健康 / 低脂 / 0 负担 / 无油 | 营养声称有国家标准规定的量化门槛，须产品实测达标并按规范标示后方可使用 |
| 吃了不长胖 / 适合减肥 | 属功效宣称，普通食品不得涉及 |
| 与传统油炸产品的直接对比 | 直接对比同类产品存在被认定为贬低同行的风险 |
| 含真番茄 / 真实果肉 | 需配料表支持后方可使用 |

::: warning 关于对比结构
我们理解「左边传统、右边 VF」这类结构在传播上效果直接。但直接对比同类产品在广告法下有明确风险，**这是合规判断，不是创意偏好**，因此不纳入方案。

**替代做法**：只呈现自身工艺，不出现任何参照物。对比在消费者脑中自行完成——而且他自己得出的对比，比屏幕上摆出来的更有说服力。
:::

### 四、工期

物料齐备后，两支片子合计 **6 个工作日**：

| 阶段 | 工作日 |
|---|---|
| 分镜设计 + 贵司确认 | 1 |
| 首轮制作（全片跑通一版） | 1.5 |
| 单镜返工与优化 | 1.5 |
| 后期合成 · 调色 · 音效 | 1 |
| **合规审校与改稿** | **1** |
| 合计 | **6** |

**不含**：物料等待时间、贵司内部审批轮次。

::: tip 关于最后一天
合规审校不产出画面，但对工艺类食品广告是必需环节。**把问题拦在成片之前，成本远低于成片之后返工。**
:::

### 五、需要贵司确认的事项

| # | 事项 | 不确认的影响 |
|---|---|---|
| 1 | 核心主张采用「原薯鲜切 + VF 支撑」是否认可 | 创意方向无法推进 |
| 2 | 包装日文副标「カリカリポテトフライ」是否对应真实的日本技术、合作或出口关系 | 见下方说明 |
| 3 | 两支片子的具体投放位与优先级 | 时长、画幅、开头节奏无法最终确定 |
| 4 | 交期与预算范围 | 排期无法确定 |
| 5 | 产品是否已上市、能否提供实物样品 | 影响部分镜头的制作方式 |

#### 关于第 2 项

包装印制日文在行业内属常见做法，通常不构成问题。但**广告中主动呈现日式调性或暗示进口属性，性质不同**——若无真实对应关系，存在被认定为虚假宣传的风险。

**在贵司提供书面说明之前，我们将按「无日本背景」处理**：片中不出现日式场景、日文字幕、日式配乐等元素。包装本身出镜时，其上的日文属客观呈现，不受影响。

### 六、制作方式说明

为便于贵司理解排期与物料需求，以下说明部分镜头的制作方式：

| 镜头 | 制作方式 |
|---|---|
| **包装出镜** | **必须使用实拍或设计源文件渲染。** 包装含 logo、中文、日文与精确品牌色，生成式工具无法准确还原，此环节无替代方案 |
| **撕开封口** | 建议**实拍**。该动作涉及真实手部与不可逆形变，实拍的效率与质量均优于生成。需贵司提供实物样品 |
| 工艺过程 · 断面结构 | 生成制作。这类画面实拍难以实现（设备封闭、微观尺度），是生成技术的优势区间 |
| 成品质感镜头 | 生成制作 |

::: tip 关于「哪些用 AI、哪些不用」
我们的原则是：**生成技术不擅长的部分，不用生成技术做。**

真实手部动作、品牌文字、精确配色——这几类交给实拍或设计，成本更低、结果更可控。把生成能力用在实拍拍不到的地方（工艺内部、微观结构），才是它真正的价值所在。
:::
