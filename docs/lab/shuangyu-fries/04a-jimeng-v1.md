## 交付范围

这一版即 03 定义的 demo 版：**工艺段落完整、产品段落将就**，先交付一版完整的。

| | 本版（v1） | 成片版 |
|---|---|---|
| 镜头 1–9 | 即梦生成 | 同左，精修 |
| 镜头 10 · 产品出镜 | 客户渲染图去背 + 后期动态 | 必须用设计源文件重做 |
| 字幕「80~90℃」/ 镜头 6 | 打上 / 做（**钩子，待 2b、2c 确认**） | 确认后方可保留 |

::: warning 交付前自查

:::

::: danger 只给即梦「干净」的图
允许进即梦的参考图只有无文字的实物/产品图（`stick-product.jpg`）。**带文字的包装平面、工程文件全图、logo 图一律不能做参考图**——一旦参考，模型会学会往画面里画中文和 logo，那条素材直接作废。包装文字的像素只走合成通道。这与 04 的防事故负面词是同一道红线。
:::

**镜头 1–3 不配参考图**：要的是带薄土的写实生土豆与鲜切土豆条，包装上的土豆是艺术渲染（螺旋削皮），风格与纪录片质感冲突，文本锁定更稳。

## 粘贴位置对照

| 内容 | 即梦输入位置 |
|---|---|
| 首帧 / 尾帧 Prompt | AI 图像 → 文生图提示词 |
| 负面词 | AI 图像 → 「不希望出现的内容」，全量粘贴 |
| 主体参考图 | AI 图像 → 参考图（主体），强度中高 |
| 视频 Prompt | AI 视频 → 图生视频；首尾帧镜勾「使用尾帧」，按先首帧后尾帧上传 |
| 视频的无文字约束 | 视频无独立负面栏，已改写进每条视频 Prompt 结尾 |

参数：1080p、单次 5 秒、24fps（可选则选）；**每镜跑 4–6 条**，微距与慢动作废片率高。
