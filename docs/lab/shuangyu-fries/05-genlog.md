# 05 · 生成日志

> 阶段 5 · 生成 ｜ **边跑边记，不要事后补**

::: danger 这份文档的唯一要求：当场记
真实出片率只能当场记，**事后一定记不准**——人会记住成功的那条，忘掉废掉的十一条。

:::

跑完一镜就填一行。**废片原因写具体的**——「不好」没有价值，「油面在沸腾，成了常压油炸」才有。
