| 项目 | 内容 |
|---|---|
| 产品 | 双宇食品「薯条脆」 |
| 片型 | 感官奇观片 |
| 核心诉求 | 酥脆、健康感、分享 |

| 视觉主线 | 开罐唤醒 → 脆裂奇观 → 原料轻盈感 → 风味爆发 → 多人分享 → 产品落版 |

::: warning 本版的两个执行边界
1. **健康只做感受，不做营养承诺。** 已有营养成分不支持「低脂」「低热量」「0 负担」「无油」等表述。本版用原料画面、自然光和轻盈运动传达清新感，字幕使用「原薯鲜切 · 轻松享」。
2. **蜂蜜黄油味暂未取得包装物料。** 当前项目只能确认番茄味 46g 杯装。镜头 4、6 的双口味版本须在蜂蜜黄油味真实存在、且终稿包装到位后执行；否则采用文末的单口味替换方案。
:::

- **声音 / 音乐**：铝箔「嘶啦」贴耳声；低频逐渐蓄力，揭开后短暂静音。
- **字幕 / 卖点**：**这一口，准备脆响**

### 镜头 02 · 咔嚓奇观

- **时间 / 时长**：00:03–00:06 / 3.0s
- **画面与表演**：两根薯条脆在空中交错，其中一根从中央断开。酥松多孔的断面正对镜头，真实食物碎屑向四周炸开；时间在碎屑最密集的一刻短暂停滞。
- **摄影 / 运镜**：100mm 微距；1000fps 升格感；围绕断裂点环绕半圈。
- **视觉 / 转场**：强逆光点亮断面；金色碎屑保留大小和边缘差异，不做成烟花或金属粒子；镜头跟随一颗碎屑穿出。
- **声音 / 音乐**：瞬间静音后爆发一记近距离「咔嚓」；碎屑掠过声形成连续清脆回响。
- **字幕 / 卖点**：**酥松爽脆**

### 镜头 03 · 原薯轻盈场

- **时间 / 时长**：00:06–00:09.5 / 3.5s
- **画面与表演**：飞出的碎屑变成马铃薯切片，进入明亮原料空间。马铃薯切面、番茄与少量绿叶沿同一方向形成清爽旋流；一根薯条脆穿过旋流，表面干爽、根根分明地落向白色台面。
- **摄影 / 运镜**：顶拍起镜，转为侧面跟拍；穿越式运镜；高速渐变为常速。
- **视觉 / 转场**：黑金转为奶油黄、番茄红与清新绿；原料均保持真实尺度，不用蜂蜜滴淋，不表现油脂被神奇消除。
- **声音 / 音乐**：清新风声、切片轻落声与细颗粒声；音乐第一次进入明快节拍。
- **字幕 / 卖点**：**原薯鲜切 · 轻松享**

### 镜头 04 · 双味风暴

- **时间 / 时长**：00:09.5–00:13 / 3.5s
- **画面与表演**：蜂蜜黄油味与番茄味两款终稿包装从左右旋入。左侧奶油金色风味波浪与右侧番茄红色颗粒风暴在中央碰撞，收束成两根裹有不同调味粉的薯条脆，向镜头轻跃。
- **摄影 / 运镜**：对称构图；左右快速横移；碰撞点升格定格。
- **视觉 / 转场**：黄、红两股能量必须由真实原料和食物颗粒构成；包装正面朝向镜头，文字用终稿源文件后期合成。
- **声音 / 音乐**：左声道柔和「呼」，右声道爽快「砰」；碰撞后接两记音色不同的脆响。
- **字幕 / 卖点**：**蜂蜜黄油味 × 番茄味**

### 镜头 05 · 分享才够脆

- **时间 / 时长**：00:13–00:17 / 4.0s
- **画面与表演**：俯拍明亮聚会桌面，一杯薯条脆落在中央。三至四只手从不同方向依次抽走一根；最后两根薯条脆轻碰「干杯」，众人在画外同时咬下，金色食物碎屑形成一圈分享波纹。
- **摄影 / 运镜**：顶拍快速拉远；桌面上方轻微环绕；碰杯与咬下瞬间升格。
- **视觉 / 转场**：产品始终位于视觉中心；手的动作分拍完成，避免同一生成镜头出现过多肢体；红包装、绿植和自然肤色平衡画面。
- **声音 / 音乐**：「咔、咔、咔」逐次加入节拍；轻碰声后汇成一次多人咔嚓，叠加克制的自然笑声。
- **字幕 / 卖点**：**一起分享，快乐加倍**

### 镜头 06 · 品牌英雄镜头

- **时间 / 时长**：00:17–00:20 / 3.0s
- **画面与表演**：两款产品一立一卧形成主视觉，前景铺陈两种口味的薯条脆。最后一根薯条脆垂直落下，触发一圈金色声波；品牌标识、产品名与口味信息清晰定格。
- **摄影 / 运镜**：英雄式低机位；缓慢推进；最后 1.2 秒锁定包装。
- **视觉 / 转场**：暖奶油黄影棚背景配番茄红色块与少量清新绿；产品杯使用终稿包装后期合成，不交给生成模型重绘。
- **声音 / 音乐**：音乐重拍落点；终极「咔嚓」后尾音迅速收干净。
- **字幕 / 卖点**：**双宇食品 · 薯条脆｜咔嚓一口，分享快乐**

## 节奏结构

| 段落 | 时长 | 作用 |
|---|---:|---|
| 开罐抓人 | 0–3s | 先用铝箔撕开的近距离声音截停滑动，再揭示杯装产品 |
| 脆感打透 | 3–6s | 用断面、碎屑和第一记重「咔嚓」建立核心食欲点 |
| 轻盈转场 | 6–9.5s | 以真实原料与明亮色彩承接健康诉求，但不输出营养结论 |
| 风味记忆 | 9.5–13s | 用黄红对撞建立口味区分，并让包装完成一次正面识别 |
| 分享高潮 | 13–17s | 把单次脆响编成多人节拍，让「分享」成为动作而不是口号 |
| 品牌收束 | 17–20s | 奇观回到真实包装，留出不少于 1.2 秒的清晰识别时间 |

## 导演执行要点

1. **声音先行。** 先采集铝箔撕开、薯条掰断、片与片碰撞、入口咀嚼四组真实声音，再按音乐节拍剪画面；不要用一条通用「咔嚓」铺满全片。
2. **碎屑必须像食物。** 形状不规则、大小有层次、运动受重力影响；禁用金属火花、烟花、火焰和抽象发光粉尘。
3. **单镜只保留一个主动作。** 「包装旋入—能量碰撞—薯条飞出」应拆成可剪接素材，不要求视频模型在一次生成中完整完成。
4. **多人镜头分层制作。** 先拍或生成干净桌面与产品，再做每只手的单独动作，最后合成；避免一次生成三至四只手造成结构错误。
5. **包装后期保真。** 镜头 1、4、5、6 均以客户确认的终稿源文件或实拍产品替换生成包装，且不刻意突出无真实日本背景的日文副标。
