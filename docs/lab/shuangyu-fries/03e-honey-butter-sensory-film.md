## 核心创意

蜂蜜与黄油给人的第一感觉是柔、润、慢，薯条脆的核心感受却是干、脆、快。本片不把蜂蜜淋在产品上，也不让黄油包裹食物，而是把两种风味转译成围绕产品流动的**琥珀金光带**与**奶油色柔光**。柔软的风味运动在第 9 秒被一次近距离咔嚓突然打断，形成全片最强的感官反差。

> **创意记忆点：看起来是融融甜香，咬下去却是利落一声。**

::: warning 原料与包装边界
1. 当前没有蜂蜜黄油味的配料表，画面只使用抽象风味意象，不出现蜂巢、蜂蜜罐、黄油原料块，也不使用「真蜂蜜」「真黄油」等表述。若终稿配料表确认含对应原料，可再升级为真实原料版。
2. 当前没有蜂蜜黄油味终稿包装。所有包装镜头必须用客户确认的终稿实拍或设计源文件后期合成，禁止用现有番茄味包装改色，禁止让生成模型自行设计包装。
:::

## 声音执行表

| 声音层 | 处理方式 |
|---|---|
| 甜香层 | 极轻空气移动声，频率偏高，左右声道缓慢移动，不使用黏稠液体声 |
| 黄油层 | 温暖、柔和的低频铺底，只在 2.8–8.8 秒出现，避免持续轰鸣 |
| 颗粒层 | 近距离录制细盐或调味粉落在烘焙纸上的声音，控制在主脆响下方 |
| 主咔嚓 | 实录薯条脆近距离折断；保留短促低频冲击与高频碎裂，禁用通用薯片音效 |
| 连击层 | 三次脆响使用不同力度和距离，最后一次最厚，不复制同一个样本 |
| 音乐 | 90–100 BPM，前柔后快；主咔嚓前留 0.15 秒真空，落版不加长尾混响 |

## 验收标准

- [ ] 全片只有蜂蜜黄油味，不出现番茄、红色调味粉或其他口味包装
- [ ] 20.0 秒时间线完整，主咔嚓准确落在 9 秒附近

- [ ] 风味用琥珀金与奶油色表达，食物表面始终干爽，无蜂蜜滴淋、黄油包裹或油光
