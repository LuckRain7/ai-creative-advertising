Gemini 视频提示词：中文还是英文 ​

内部工作规范 ｜ 用于 Gemini / Veo 视频分镜的构思、Prompt 编写与迭代

直接结论 ​

用中文沟通创意，用英文执行生成；遇到中国特有文化、工艺和产品词时，保留中文原词，并补充英文可视化解释。

对本项目而言，中文更适合需求澄清、分镜讨论和团队 review；结构化英文通常更适合作为最终视频生成 Prompt，尤其是运镜、镜头语言、动作节奏、光线和排除项。

这是一条生产默认值，不是所有模型版本都成立的绝对规律。Gemini、Veo 及其不同入口会持续更新；关键镜头如果生成不稳定，应在相同输入图、时长和参数下做一次中英文 A/B 测试，用实际成片决定。

中英文优缺点 ​

语言优点缺点最适合的环节
英文影视、摄影和动态术语更标准；复杂动作与时间轴可以写得紧凑；相机运动、光线、材质和排除项通常更容易形成清晰结构直译中国文化与传统工艺词时容易失真；生硬机翻可能产生错误术语；中文团队 review 成本更高最终生成 Prompt、专业运镜、精细动作、负向约束
中文创意意图表达直接；中式审美、民俗、工艺和品牌语境保留更完整；修改和评审效率高部分专业运镜词存在多种译法；某些生成入口可能先自动翻译，细节在中间层被弱化；长句容易让动作主次不清需求输入、创意讨论、分镜调整、文化概念校准

英文提示词的优势 ​

  1. 专业术语更紧凑：rack focus、dolly-in、rim light、macro slow motion、locked-off camera 等写法比一长段解释更不容易产生歧义。
  2. 动态约束更容易结构化：用 Timing 拆分动作，再分别限定主体、相机和物理规律，便于检查每个动作是否在时长内完成。
  3. 排除项更直接：no text, no logo, no camera cut, no morphing 等短句适合放在 Prompt 末尾集中约束。

英文的优势不应简单归因于“训练集权重一定更高”或“英文一定进入更准确的潜在空间”。这些说法很难对不同模型版本逐一验证。项目中只把英文作为经验上更稳的执行语言，并保留实测纠偏。

英文提示词的风险 ​

  1. 文化词直译不等于画面定义：榫卯 只写成 mortise and tenon，模型可能生成现代木工接头；需要补充年代、材料、连接方式和可见结构。
  2. 机翻会制造伪专业词：先确认英文术语是否对应真实摄影、机械或工艺术语，不使用看似高级但含义模糊的表达。
  3. 团队可能无法快速发现偏差：最终英文 Prompt 旁边应保留一行中文意图摘要，方便核对主体、动作和红线，而不是再写一份逐字中文译文。

中文提示词的优势 ​

  1. 需求沟通损耗低：创作者可以直接说明“先看见脆，再解释工艺”“自然瑕疵要保留”等叙事判断。
  2. 文化与品牌语境更准确：传统器物、纹样、地域审美、包装文案和内部产品叫法应先用中文锁定。
  3. 修改效率高：用中文指出“油位必须先下降，料篮才能旋转”，比先翻译再讨论更快，也更适合工艺审核。

中文提示词的风险 ​

  1. 专业词可能不唯一：例如“推镜”“跟拍”“移焦”不能混写，必要时在中文后补标准英文术语。
  2. 长句容易混合多个任务：模型可能同时争夺主体、动作、运镜和风格。中文输入也必须按字段拆分，不能写成散文。
  3. 接口行为可能不同：不同 Gemini / Veo 入口对中文的处理方式会变化，不根据单次经验推断所有版本。

1. 用户用中文描述需求 ​

至少说清以下内容：

  • 这条镜头要完成什么广告任务；
  • 主体是谁，外观必须保持什么；
  • 动作先后顺序和目标时长；
  • 相机是否移动，焦点落在哪里；
  • 哪些错误绝对不能出现。

2. 先锁语义，再翻成英文 ​

不要逐字翻译。先把中文需求整理成 Duration → Subject → Action and Timing → Camera → Lighting → Physics → Constraints，再用对应的标准英文表达。

3. 最终 Prompt 以英文正文为主 ​

本项目沿用 Gemini 视频时长控制 的双重时长写法：第一行用中文锁定时长，第二行用英文重复；其余正文优先使用结构化英文。

text
视频时长：5 秒（必须生成 5 秒，不要生成默认 10 秒）。
Duration: 5 seconds. Do not generate the default 10-second clip.

Format: one continuous realistic food-commercial shot, 16:9, no cuts.
Subject: ...
Timing: 0.0–0.5s ...; 0.5–4.5s ...; 4.5–5.0s hold a stable edit handle.
Camera: ...
Lighting and material: ...
Physical constraints: ...
Exclude: no text, no logo, no morphing, no watermark.

时间轴最后一个时间点必须等于首行总时长。更完整的字段拆分见 Prompt 结构通法。

4. 中国特有概念采用“原词 + 可视化定义” ​

中文原词不够可靠的写法推荐写法
榫卯Chinese jointtraditional Chinese mortise-and-tenon joinery (榫卯), interlocking exposed hardwood parts, no nails or metal fasteners
缠枝莲纹lotus patterntraditional Chinese scrolling lotus motif (缠枝莲纹), continuous curling stems with repeated lotus blossoms
篾刀bamboo knifetraditional bamboo-splitting knife (篾刀), a short broad steel blade used to split bamboo strips by hand

原则是描述模型需要看见的 形状、材料、连接关系和动作，而不是只给一个文化名词。

什么时候直接用中文生成 ​

以下情况可以先用结构化中文直接跑一版：

  • 镜头动作简单，主要难点是中式场景、器物或工艺身份；
  • 当前入口的中文指令遵循已经过本项目实测；
  • 团队需要快速预览，尚未进入高成本正式生成；
  • 英文版反复把中国特有概念生成错误。

即使用中文，也要保留英文专业术语括注，例如 固定机位（locked-off camera）、移焦（rack focus），并继续遵守单镜时长和动作时间轴规则。

什么时候必须优先英文 ​

  • 一个镜头包含两个以上按顺序发生的动作；
  • 需要精确规定推、拉、摇、移、移焦或慢动作；
  • 产品身份、手部、机械结构或跨帧一致性要求高；
  • 需要较长的负向约束列表；
  • 中文版已经出现动作次序错误、主体变形或镜头自行切换。

A/B 测试方法 ​

不要凭印象比较中英文。只改 Prompt 语言，其他条件保持一致：

  1. 使用相同模型、入口、输入图、画幅、时长和参考素材；
  2. 中英文各生成相同次数，不能拿一条英文结果对比四条中文结果；
  3. 按主体一致性、动作完成度、物理合理性、运镜准确度和可剪辑性评分；
  4. 记录哪类指令在哪种语言下更稳定，沉淀到具体项目，而不是推广成所有模型的结论。

交付前检查 ​

  • [ ] 中文意图摘要与英文 Prompt 表达的是同一个镜头；
  • [ ] 第一行和第二行时长一致；
  • [ ] Timing 在总时长处闭合；
  • [ ] 每条 Prompt 只承担一个主镜头任务；
  • [ ] 专业运镜使用了准确英文术语；
  • [ ] 中国特有名词保留原词并补充了可视化解释；
  • [ ] 产品、包装、文字和 logo 的处理边界明确；
  • [ ] 关键镜头失败时做过受控 A/B 测试，而不是无差别重写整条片子。
