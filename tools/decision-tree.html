选型决策树 ​

不讨论"哪个工具最好"——没有这种东西。只回答一个具体问题：这个项目该配哪套工具。

第一层：先看交付形态 ​

你要交付什么？
├── 静态图（主图 / KV / 海报）      → 走 A 路线
├── 短视频（6–30 秒社媒）           → 走 B 路线
└── 完整 TVC（30 秒以上，有叙事）   → 走 C 路线

A 路线 · 静态图 ​

A1 产品必须精确还原吗？ ​

是（有 logo、有特定造型、消费者认得出）

→ 不要纯生成。

链路：实拍产品图（或官方素材）
      → 图像编辑型工具去背 / 换背景
      → AI 生成背景与光环境
      → 设计软件合成 + 加文字

工具配置：一个图像编辑型工具 + 一个通用生成型工具 + Photoshop 或同类。

否（概念图、氛围图、场景图，产品不出现或不重要）

→ 纯生成即可，走 A2。

A2 要几张？ ​

数量配置
几张一个通用生成型工具就够，手动挑选
几十张（多 SKU / 多尺寸）需要参考控制型工具锁定风格，否则每张调性都不一样。见 案例 02

A3 海报上有文字吗？ ​

有 → 文字一律在设计软件里加，不要交给生成模型。AI 生成的中文基本是乱码。

在 Prompt 里主动写负向词 文字、水印，把版面留白留出来。

B 路线 · 短视频 ​

B1 有没有人物出镜？ ​

没有（纯产品、空镜、概念画面）

→ 最省事的一条路，AI 的成功率最高。

链路：图像模型生成每个镜头的首帧
      → 图生视频让它动起来
      → TTS 配音
      → 剪辑软件串联 + 调色

关键：走图生视频而不是文生视频。先把画面调满意再让它动，可控性差一个量级。

有人物 → 走 B2。

B2 人物需要说话吗？ ​

不需要说话（有表演但用画外音）

→ 可行。注意用 人物代言 里的规避策略：少用大幅动作，多用侧脸、背影、局部特写。

需要说话

→ 口型同步是当前的薄弱环节。三个选项：

方案说明
画外音（推荐）人物出画面但不开口，旁白单独配。最稳
专门的口型同步工具效果视工具而定，必须先试再承诺给客户
实拍人物 + AI 做其余镜头混合生产，质量最有保障，成本也最高

B3 预算和时间 ​

情况建议配置
极紧（当天要，预算很低）单一平台走完全链路（国内一体化平台通常图、视频、配音都有），牺牲一些质量换速度
正常（三五天）每一环选各自最合适的工具，中间手动流转。这是最主流的做法
充裕（有排期和预算）AI 做前期探索和空镜，关键镜头实拍，走 全景 里的「探索模式」

C 路线 · 完整 TVC ​

C1 先做一个判断 ​

30 秒以上、有人物表演、有情绪递进的片子，目前不建议纯 AI 生成。

原因在 AI 创意广告全景 里说过：弱点集中在表演上——表情僵硬、动作不自然、口型对不上。片子越长，这些问题暴露得越充分。

C2 推荐的混合配置 ​

内容类型怎么做
人物表演镜头实拍
产品特写AI 生成或实拍均可，AI 在这里性价比很高
空镜、环境、氛围AI 生成，省下大量外景成本
超现实 / 概念画面AI 生成，这是 AI 优势最大的地方
分镜预览（故事板）AI 生成，成本极低，用来跟客户对齐创意

一个被低估的用法

即使最终全部实拍，用 AI 生成故事板也很划算：一个下午就能把整支片的每个镜头可视化出来，拿去跟客户对创意。比手绘分镜快，比拍样片便宜几个数量级。这是当前 AI 在高预算项目里最扎实的应用。

第二层：三种预算档的完整配置 ​

极低预算常规预算充裕预算
文案策略免费大模型付费大模型付费大模型 + 人工创意
图像一个通用生成工具通用 + 编辑型两个工具上述 + 实拍产品素材
视频一体化平台专门的视频生成工具AI + 实拍混合
配音免费 TTS付费 TTS专业配音演员
剪辑剪映专业剪辑软件专业剪辑软件 + 调色
适合内部测试、批量投放素材绝大多数商业项目品牌项目

别按预算档硬套

这张表是起点不是答案。实际项目里，把钱花在最影响成片质量的那一环比平均分配有效得多。多数情况下那一环是：图像/视频生成的重生成次数，以及剪辑调色的时间。

第三层：三个必须先确认的问题 ​

选定工具、开工之前，这三件事没确认清楚，后面可能全部作废：

  1. 商用授权。你的订阅档位允许把生成内容用于商业广告吗？条款是否覆盖客户的使用范围？**不同产品差异极大，且和订阅档位挂钩。**这是最容易翻车的一项。
  2. 客户对 AI 的态度。有些甲方明确要求不能用 AI 生成，有些要求必须标注。开工前问清楚，别做完了才发现。
  3. 投放平台的规则。部分平台对 AI 生成内容有标识要求。以平台最新规范为准。

一句话总结 ​

静态图看产品要不要精确，视频看有没有人说话，TVC 看要不要表演。 三个问题答完，工具基本就定了。
