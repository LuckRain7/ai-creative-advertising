Prompt 卡片模板 ​

记录一条调通的 Prompt。全站所有 Prompt 都按这个格式写。

为什么是这四段 ​

段回答的问题不写会怎样
适用场景什么时候用它，什么时候别用半年后你会忘记这条是干嘛的
可复制 Prompt具体敲什么——
参数说明每个词在控制什么想微调时不知道该动哪儿，只能整条重写
常见翻车点已知会出什么问题下次重新踩一遍同样的坑

**第四段最重要。**它是这张卡片和"网上随便搜的 Prompt"的区别。

骨架 ​

复制下面的内容开始写：

markdown
## NN · [一句话说清这条 Prompt 干什么]

**适用场景**
[什么情况下用。]
**不适用**：[什么情况下别用——这句话能省掉很多误用。]

**可复制 Prompt**

```
[Prompt 正文。需要替换的地方用方括号标注，例如 [产品名]]

负向：[负向词]
```

**参数说明**

| 关键词 | 在控制什么 | 想改效果时 |
|---|---|---|
| | | |

**常见翻车点**

- **[症状]**。[原因]。[怎么绕过去]。
- **[症状]**。[原因]。[怎么绕过去]。

写每一段的要点 ​

适用场景 ​

**「不适用」那一句不要省。**它比「适用」更能防止误用。

✅ 适用：电商平台主图、详情页首图。 不适用：需要氛围和情绪的品牌广告——白底图是功能性的，不负责传达调性。

可复制 Prompt ​

  • 用代码块包起来，方便一键复制
  • 需要替换的地方统一用 [方括号] 标注
  • 负向词单独一行，别混在正文里
  • 记录你实际用的那一版，不是理想化重写过的版本

参数说明 ​

三列表：关键词 | 在控制什么 | 想改效果时。

第三列是关键。「想让画面更暖 → 把 冷调 改成 黄金时刻」，这样下次微调有方向，不用整条重写。

**只列起作用的词。**把 Prompt 里每个词都解释一遍，等于没重点。

常见翻车点 ​

按「症状 → 原因 → 解法」写：

  • 反光处出现幻觉细节。金属和玻璃的反光区域是重灾区，会出现不存在的图案。放大检查，或改用哑光材质描述。

三段缺一不可。只写症状没法解决，只写解法看不懂为什么。

记录失败版本 ​

如果这条 Prompt 是试了好几版才对的，把失败版本也写下来，加在最后：

markdown
**失败版本**

| 版本 | 写法 | 问题 |
|---|---|---|
| v1 | `温馨的厨房场景` | 出图平淡——"温馨"是概念，模型不理解 |
| v2 | `温馨的厨房，暖光` | 有暖光了但依然平——顺光没有层次 |
| v3 | `厨房，侧逆光，蒸汽被逆光点亮` | ✅ 关键是把"温馨"翻译成了具体的光效 |

这张小表的价值往往高于最终版 Prompt 本身——它记录的是推导过程，而推导过程可以迁移到别的场景。
